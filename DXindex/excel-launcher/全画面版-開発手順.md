# 全画面版の開発手順

利用者は配布済み.xlsmを開くだけです。この文書は開発者向けです。

1. `scripts/build-fullscreen-template.mjs` が既存のDXアプリホーム.xlsxの登録内容を読み、artifact-toolで土台のxlsxを作ります。初期データの再生成先は専用outputsフォルダです。運用中のブックを上書きしないでください。
2. `python3 scripts/prepare-launcher-vba.py` で日本語リテラルをUTF-16の16進表現にしたASCIIの.basを作ります。日本語VBEのコードページによる破損を防ぎます。
3. 開発用Excelで土台を開き、xlsmとして保存します。標準モジュールDXLauncherを取り込み、ThisWorkbookにイベントコードを入れます。既存のセキュリティ設定のまま、VBEの通常のインポート／貼り付け操作を使います。VBAプロジェクトへのプログラムからのアクセスは不要です。
4. コンパイルしてDXAssembleを実行します。r3では未使用分を含む6スロットと補助ラベル、合計51個のホーム図形を保存します。実行時に図形を作り直さず、既存図形をTextFrameで更新します。DXNativeTestsを開発コピーへ入れ、DXRunNativeTestsで機能と図形IDの維持を確認します。非対応APIは不合格を隠さず別記録にします。
5. 試験モジュールを除去し、全画面検証版.xlsmとして保存します。実際のvbaProject.binを持つ成果物が必要です。拡張子の変更だけでは完成しません。
6. `scripts/package-fullscreen-launcher.py` がソース一致、登録値、図形のマクロ参照、保護、数式エラー、予備版の一致を検証し、利用案内と確認票を含むZIPを作ります。oletoolsが開発環境に必要です。

UTF-8のVBAソースはexcel-launcher/vbaにあります。配布ZIPには開発ツールや試験コードを含めません。活動ガイドと従来xlsxの中身はこの変更で編集していません。
