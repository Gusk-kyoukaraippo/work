# 初回で拾う利用者情報

## 目的

ゼロデータの状態から、手入力で最低限の利用者データを確保する。

入力負荷を抑えつつ、利用率低下の分析に必要な「流入」「滞在」「流出」を可視化できる状態を目指す。

## 初回入力項目

| 項目 | 内容 | 想定される値・分類 |
|---|---|---|
| 利用者ID | 個人識別。氏名よりID管理が安全 | 任意の一意ID |
| 利用者種別 | 入所、ショート、通所、退所済みなどを分ける | 入所、ショート、通所、退所済みなど |
| 利用開始日 | いつから利用しているか | 日付 |
| 利用終了日 | 退所・終了日 | 日付、利用中の場合は空欄 |
| 利用区分 | どのサービスを利用しているか | 入所、ショート、デイ、通所リハなど |
| 入所場所 | どこに入所・滞在しているか | 2F、3F、ユニット |
| 流入元種別 | どこから利用につながったか | 病院、居宅、包括、家族、法人内など |
| 流出先・退所先 | どこへ退所・移行したか | 自宅、病院、特養、有料、死亡など |

## 補足

最初は項目数を絞り、入力継続性を優先する。

この初期データで、以下を確認できるようにする。

- 利用者がどのサービス区分に偏っているか
- どの入所場所で利用率が落ちているか
- どの流入元からの利用が多いか、または減っているか
- 退所者がどこへ流れているか
- 利用開始から終了までの期間
