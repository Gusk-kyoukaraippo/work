# 病棟別 算定基準モニター MVP5.1

MVP5thをベースに、File System Access APIによる `data` フォルダの指定と起動時の自動読込みに対応した、スタンドアロンHTML資料です。4病棟の算定指標を横断比較し、人が患者配置と病棟支援を検討するために使用します。

## 画面の考え方

- アプリが患者の配置候補を決定するものではありません
- 上段には、算定判定期間の「基準未達」指標だけをまとめます
- 上段の病棟カードには「当月速報」「算定判定値」「基準値」を数字で表示します
- 基準差は、基準未達欄と病棟別の詳細画面で確認できます
- 病棟別の詳細画面には、MVP4thと同じく月ごとに1行の表で、直近6ヶ月の実績を表示します。各指標名の下には基準値を併記します
- 算定判定値は指標ごとの条件に合わせ、当月・直近3ヶ月・直近6ヶ月を明確に分けます
- 基準差は、プラスなら基準内、マイナスなら未達です
- 過去の月次グラフや、4/4・2/2のような達成数は表示しません
- 患者の治療必要性、適応、病室・空床などと合わせて、人が最終判断します

## 対象病棟と表示指標

### 3F 急性期（急性期一般入院料1）

- 必要度 基準①：必要度II 27%以上、直近3ヶ月
- 必要度 基準②：必要度II 34%以上、直近3ヶ月
- 自宅等退院割合：80%以上、直近6ヶ月
- 平均在院日数：16日以内

必要度①・②は、該当患者割合に救急患者応需係数を加えた最終的な「割合指数」をCSVの `値` 列へ入力します。

### 5F 回復期・6F 回復期（回復期リハビリテーション病棟入院料1）

- 重症患者の新規受入割合：35%以上、直近6ヶ月
- 退院実績：70%以上、直近6ヶ月

5Fと6Fは別々に集計します。退院実績は通知上の定義による指標で、単純な自宅退院率ではありません。

### 6F 地ケア（地域包括ケア病棟入院料1）

- 在宅等退院割合：72.5%以上、直近6ヶ月
- 必要度II 該当患者割合：8%以上、直近3ヶ月
- 自宅等からの入院割合：20%以上、直近3ヶ月
- 自宅等からの緊急入院受入：9人以上、直近3ヶ月

## 使い方

1. `index.html` をブラウザで開く
2. 上段で算定判定値が基準未達の指標を確認する
3. 4病棟の当月速報、算定判定値、基準値を比較する
4. 病棟カードまたは病棟タブを選び、指標の定義と集計方法を確認する
5. 実績を反映する場合は「CSVを読み込む」を開く
6. CSVフォルダまたは複数のCSVをドロップするか、「ファイルを選択」からCSVを選ぶ

CSV未読込の病棟・月はデモデータを表示します。データはブラウザ内だけで処理され、画面を閉じると消去されます。

## 自動読込みフォルダ

共有フォルダを継続して使用するPCでは、次の設定ができます。

1. 「data フォルダを指定」を押す
2. このプロジェクトの `data` フォルダ、またはCSVが入っている共有フォルダを選択する
3. 初回のCSVを読み込む

フォルダハンドルはIndexedDBへ保存されます。設定はPC・Windowsユーザー・ブラウザプロファイルごとに保持され、次回起動時は保存した権限が有効な場合に限り、そのフォルダ内のCSVを再帰的に1回自動読込みします。画面を開いている間の常時監視は行いません。CSVを更新した後は「再読み込み」を押してください。

CSVの集計結果そのものは保存しません。起動時と「再読み込み」時は表示中のCSV値をいったん消去し、その時点で `data` フォルダに存在するファイルだけから集計結果を作り直します。フォルダへ接続できない、CSVがない、またはCSVを解析できない場合、以前に読み込んだ値は残さず「データ未読込」と表示します。

ブラウザを完全に終了した後など、保存済みフォルダの権限が `prompt` に戻った場合、Web APIの制約により起動処理から権限確認画面を出すことはできません。この場合は「再読み込み」を1回押してアクセスを許可すると、以降の起動時自動読込みが再開します。

PCやブラウザのセキュリティ設定によって、フォルダ設定の保存または起動時の自動読込みが利用できない場合があります。また、共有フォルダへ接続できていない場合やアクセス権がない場合は読み込めません。その場合も、従来のフォルダドロップとファイル選択を使用できます。

フォルダドロップは、その場でフォルダ内のCSVを再帰的に読み込む機能です。ドロップしただけでは継続アクセスの設定は保存されません。

## 統合CSV

画面の「統合CSVのサンプルを保存」から入力テンプレートを取得できます。

```text
病床区分,対象月,指標コード,分子,分母,値,基準日
```

`病床区分` は次のいずれかを使用します。

- `acute3f`
- `recovery5f`
- `recovery6f`
- `community6f`

主な `指標コード` は次のとおりです。

| 病床区分 | 指標コード |
|---|---|
| acute3f | `acute_need1`, `acute_need2`, `acute_home_discharge`, `acute_los` |
| recovery5f | `recovery5_severe`, `recovery5_discharge` |
| recovery6f | `recovery6_severe`, `recovery6_discharge` |
| community6f | `community_home_return`, `community_nursing`, `community_home_admission`, `community_emergency` |

割合は `分子` と `分母` から計算できます。必要度①・②は救急患者応需係数を反映済みの割合指数を `値` に入力してください。平均在院日数は `値`、緊急入院受入は月ごとの人数を `値` に入力できます。

## 既存の地ケアCSV

次の既存CSVセットも引き続き読み込めます。

- `病棟別人数分布表(条件指定)_YYYY-MM.csv`
- `病床稼働報告_YYYY-MM最終結果.csv`
- `地ケアマスタ_YYYY-MM入院者.CSV`

既存CSVから集計できる値は6F 地ケアへ反映されます。3F急性期、5F回復期、6F回復期は統合CSVで入力します。

文字コードはUTF-8を優先し、Shift_JIS（CP932）へフォールバックします。日付は西暦と `R8.2.17` 形式に対応しています。

## 基準資料

- `令和8年度_回復期リハビリテーション病棟入院料1_算定要件.md`
- `令和8年度_入院料算定要件.md`

本画面は主要な定量実績を監視するためのものです。人員配置、設備、届出、データ提出などを含む施設基準への適合を、この画面だけで証明することはできません。
