# 美原記念病院 リハビリテーション部 物品管理

この一式は **MVP8thの実機検証用** です。業務運用とは別の場所・検証用データで確認してください。Windows・JUST Calc・Edge、共有先、2台での利用確認は未実施です。

## 最初に行うこと

1. ZIPを展開し、フォルダ一式を新しい検証場所へ置きます。ブックだけを取り出さず、既存のブックやdataに上書きしません。
2. 一つ上のフォルダにある「美原記念病院 リハビリテーション部 物品管理.xlsm」をJUST Calcで開き、「初回設定」を行います。詳細は一つ上の「導入手順.md」にあります。
3. ブックの「編集する」を押します。Edgeのログイン画面で「管理者ログイン」を開き、元アプリの管理者パスワード `admin` で入ります。
4. 管理設定の「職員」で4桁の職員IDと氏名を登録します。「物品」で分類・物品名・管理番号・保管場所を登録します。
5. 以下の確定保存を行い、ブックから開き直して登録内容が残ることを確認します。

## 入力した内容を確定保存する

画面上部のExcelゲートに保存者名を入力し、**「アプリを終了して保存作業に移る」** を押します。その場に出る案内に沿って、Edgeの作業タブとブックを閉じます。ブックの保存ボタンは **「保存して閉じる」** です。詳しい順番は配布フォルダの「試作の使い方.md」にあります。

ブラウザで「登録」「反映」と表示されても、ブックへの保存はまだ完了していません。入力ダイアログは登録するか閉じてから出力します。ファイルの読込中は完了を待ちます。出力できなかった場合も入力内容を残して理由を表示します。

途中保存は「途中保存・再出力」内の「途中保存の準備」→ブックの「保存して続ける」です。

## 日常の操作

- 職員IDでログインし、物品一覧から対象を選びます。検索・分類・状態で絞り込めます。
- 貸出時は使用者名を入力して登録します。元アプリと同様、返却期限は貸出日から30日です。
- 返却時は対象の「詳細・返却」を開き、清拭・点検の完了を確認して返却します。
- 期限の延長は理由を添えて申請し、管理者が「管理設定 → 延長申請」で承認・却下します。
- 「貸出・返却履歴」で過去の記録を確認します。
- 「閲覧する」で開いた場合、検索や履歴の確認はできますが、登録・変更・復元はできません。

操作後は上記の確定保存を行います。編集は一人ずつで、他の人は最後に正式保存された内容を閲覧します。

## 以前のアプリのデータを引き継ぐ場合

元アプリで取得した業務JSONバックアップを、管理者として「管理設定 → データ → バックアップから復元」で選択します。内容を確認して復元し、ブックへ確定保存します。Excelゲートの受渡しJSONは、この取込用バックアップとは別の形式です。

元アプリのブラウザ保存データは自動では引き継ぎません。今回のHTML自体には登録済みの業務データは含まれていないため、初回は空の状態です。元のデータを残して、まず検証場所で移行結果を確認してください。

## 職場PCでの短い確認

1. 検証用の職員・物品を登録し、貸出・返却して確定保存。ブックから開き直して内容を確認。
2. 途中保存後に入力を続け、終了保存した内容を確認。
3. 「閲覧する」で登録・変更できないことを確認。
4. 2台から同じ検証用共有ブックを開き、同時編集が防がれ、保存後に編集を交代できることを確認。

使ったWindows・JUST Calc・Edgeの版、共有先、各操作の結果を知らせてください。一つ上の「実機試験.md」には保存失敗時などの確認項目もあります。
