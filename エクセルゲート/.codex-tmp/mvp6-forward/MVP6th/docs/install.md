# 導入担当者向け

## HTMLを受け取り、適合させる

HTML作成者は、JavaScriptを内包した業務HTMLを通常どおり用意します。導入担当者はそのHTMLをAIへ渡し、「Excelゲートに組み込み、動作確認と配布準備まで」と依頼します。
AIが原本を保管し、コピー内のデータ読込・書出し・閲覧制御・ブラウザ保存・未確定入力を調べて接続し、アプリ固有の試験と配布物作成を行います。導入担当者へコード編集、コマンド入力、設定JSON編集、ハッシュ転記を依頼しません。導入担当者は、業務上の内容と画面操作の確認を行います。

AI向けの手順は、プロジェクトの `.agents/skills/excel-gate-integrate/SKILL.md` にあります。適合済み・実機検収済みのアプリ一式が用意されている場合は、次の配置手順から始められます。
共通のマクロ組み込み済みブックは、Excelゲート本体の提供物として用意する方針です。アプリごとに別の導入担当者へ組み立てを依頼する工程はありません。

## 適合済みのアプリを初めて配置する

HTMLの適合・検証を行った同じ導入担当者が、続けて実施します。

1. 検収済みの配布フォルダ一式を、全員で使う共有場所へ置きます。
2. フォルダ内の **MVP6th.xlsm** を開きます。職場で認められたマクロ実行設定を使います。
3. 操作パネルの **初回設定**を押し、表示された共有ブックの場所を確認します。
4. 「編集する」からテスト入力し、「入力を終える」→「保存して終了」で保存します。開き直して閲覧できることを確認します。
5. 全員へ同じ共有ブックの場所と「使い方.md」を案内します。

この配置・初回設定の段階では、VBAの貼り付け・モジュール取り込み・コマンド入力は不要です。
初回設定は最終の共有場所で行います。設定後の移動・名前変更・各PCへのブックのコピーでは利用できません。

## 配布物を見分ける

`release-manifest.json` の `mode` が `release`、`targetPlatformValidation` が `passed` のものを利用者へ配布します。
「最初に読む_検証用です.txt」があるものは開発・実機試験用です。完成ブックがあっても検収済みとは限りません。
`MVP6th.xlsm` がない場合は、通常の導入用パッケージではありません。利用者に組み立てを依頼しません。

## PCごとの確認

- Windows・JUST Calc・Edgeの製品名と版を記録する。
- 全員が同じUNC表記の共有場所を使用する。
- Edgeのダウンロード先がWindowsの「ダウンロード」と一致するか確認する。通常保存でファイル選択が出るPCは、職場の設定方針に従って調整する。
- 二台で編集排他・閲覧・編集者の交代を確認する。

## 更新

全員が終了した時間にフォルダ一式をバックアップします。稼働中の `.xlsm` と `data` を新品で上書きしません。
MVP4thからの既存データ移行は自動実行しません。同じ導入担当者がアプリID・業務データ版とバックアップを確認し、検証用コピーで復旧・往復試験を行ってから切り替えます。
HTMLアプリの更新時は、新しい元HTMLと同じアプリの更新であることをAIへ伝えます。AIが保存済みの組み込み記録を使い、IDを維持して再適合・試験・配布準備を行います。
完成ブックの更新はExcelゲート本体の開発担当者の作業です。利用者へVBA更新を依頼しません。
