# DXアプリホーム 全画面検証版

Windows／JUST Calcでの表示制御を確認するための検証版です。職場での確認が終わるまでは正式配布版として扱いません。

## 最初に開くファイル

ZIPをすべて展開し、`DXアプリホーム-全画面検証版.xlsm` を開きます。VBAは組み込み済みです。コードの追加、追加ソフトのインストールは不要です。マクロの利用は職場の既存の運用に従ってください。

マクロを利用できない場合は、同梱の `DXアプリホーム.xlsx` を開きます。こちらは従来のマクロなし版です。職場のセキュリティ設定を変更する必要はありません。

`DX活動ガイド.html` はブックと同じフォルダに置きます。進め方・進行状況はこのHTMLで管理します。

## ホームの操作

- アプリは1ページ6件、3列×2段。最大24件を「前へ」「次へ」で切り替えます。
- 登録済みアプリはカードの余白、アイコン、名前、説明のどこからでも起動できます。
- 起動先が空欄のアプリは「準備中」です。押しても起動しません。
- 「活動ガイド」で別HTMLを開きます。
- 「管理」で登録シートへ移ります。
- 「通常表示」で表計算ソフトの表示を元に戻します。「全画面にする」で再開できます。
- 「閉じる」はこのランチャーだけを閉じます。変更があれば表計算ソフトの通常の保存確認に従います。

全画面表示ではリボン・数式バー・行列見出し・シートタブ・スクロールバーを隠し、ホームのセル選択を禁止します。表示制御に失敗した場合は、適用済みの設定を戻して原因を案内します。通常表示でもカードは利用できます。

アプリ起動、別ブックへの移動、管理画面、保存、終了の前に表示を復元します。別ブックからホームへ戻ると専用表示を再開します。ただし、自分で通常表示に戻した場合やエラー後は「全画面にする」を押して再開します。

## アプリの登録

「管理」を押し、「アプリ登録」シートの黄色い欄を編集します。

| 場所 | 内容 |
| --- | --- |
| B13:B36 | アプリ名。28文字まで。空欄の行は表示しません |
| C13:C36 | できること。50文字まで |
| D13:D36 | 分類 |
| E13:E36 | 起動先。配置済みの元ブックのパス、HTMLファイル、http/https URL |
| F13:F36 | アイコンの1文字。空欄ならアプリ名の先頭文字 |
| C5 | 委員会からの一言。100文字まで。空欄なら表示しません |
| C8 | 活動ガイドのパス。初期値はDX活動ガイド.html |

初期登録は「引継ぎメモ」「地ケア・病床機能 指標モニター」の2件です。職場の起動先はまだ空欄のため、両方とも「準備中」です。

起動先の例：

```text
アプリ\引継ぎメモ\引継ぎメモ.xlsm
C:\業務ツール\引継ぎメモ.xlsm
\\server\share\引継ぎメモ.xlsm
https://intranet.example/app
```

相対パスの基準はランチャーブックの保存先です。Excelゲートの場合は配置済みのアプリ用ブックを指定し、runtime内のHTMLやZIPを指定しません。アプリ自体の必要ファイルも元の配置のまま使います。

「ホームに戻る」で表示を確認し、管理担当者が保存します。入力規則は貼り付け操作で回避される場合があるため、長い名前・説明を貼り付けたときはカードの収まりも確認してください。

同梱のマクロなし版とは登録内容を自動同期しません。運用開始後に予備版も更新する場合は、両方の登録シートの同じ欄を更新してください。既存の登録済みブックを初期データで上書きしないでください。

## 職場での確認

まず2アプリの実際のパスを登録し、同梱の「全画面版-実機確認.txt」を実施します。Windowsの版、JUST Calcの製品名・版・ビルドを記録してください。

今回のMac版Excelでは全画面APIが機能せず、通常表示へ戻ることを確認しました。Macでの活動ガイド起動もファイル検出に失敗しました。これらはWindows／JUST Calcの動作結果を示すものではありません。職場の実機で全画面化・図形クリック・起動・復元を確認してから配布版へ進めます。
