# C_VBA待機の試し方

同梱の「美原記念病院 リハビリテーション部 物品管理.xlsm」をJUST Calcで開きます。初回は「導入手順.md」に沿って、検証用の新しい場所で初回設定を行います。ブックと付属フォルダは一緒に置きます。

「編集する」で一件入力し、入力欄や小窓を確定します。操作は画面下部の二段バーにまとまっています。終了ボタンを押した後、同じ下部の欄に名前入力が出たら、お名前を入力し「この名前で保存作業に進む」を押します。その後の案内も同じ欄で切り替わります。この編集作業で入力した名前は、途中保存と終了で引き続き使います。

1. Edgeで「アプリを終了して保存作業に移る」を押します。
2. 「終了の準備中」が出たら、そのまま待ちます。
3. 「保存の準備ができました」に変わったら「この作業タブを閉じる」を押します。
4. 開いているブックの「保存して閉じる」を押します。
5. 「保存しました」が出たらOKを押します。ブックも閉じます。

閉じた後に同じブックから開き直し、入力が残ることを確認します。途中保存は「使い方.md」の手順を使います。進まない場合はEdgeとブックを開いたまま、表示された案内に沿って再試行します。ファイルを選ぶ必要はありません。

この方式は設定済みです。設定ファイルの編集やVBAの貼り付けは不要です。Windows / JUST Calc / Edgeでの成否・待ち時間は未実測です。親フォルダの「実機比較・記録.md」に結果を記入してください。
