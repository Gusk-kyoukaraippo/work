# 訪問診療 巡回ルート MVP 1st

訪問診療向けに機能を絞った、ブラウザで直接開ける単体HTMLアプリです。サーバーやインターネット接続なしで動作します。

## 主機能：1台の巡回ルート

1. `index.html`をChrome、Edge、Safariなどで開きます。
2. 「訪問先CSV」を選択するか、「8件デモ」を押します。
3. 住所の確認メッセージを読み、「1台の巡回ルートを作成」を押します。
4. 太田町366を出発・帰着地とした訪問順、概算道路距離、巡回地図を確認します。
5. 必要に応じて「結果CSV」を出力するか、「印刷」からA4で印刷します。

印刷時はA4縦で、ルート概要と地図の下に患者一覧を配置します。患者ごとに手書き用のメモ枠が付き、一覧が1ページに収まらない場合は次ページへ続きます。

入力CSVは「住所」列が必須です。「訪問先ID」「訪問先名」「緯度」「経度」は任意で、最大32件まで読み込めます。

```csv
訪問先ID,訪問先名,住所,緯度,経度,座標情報元,座標取得時住所,座標代表住所
P001,患者1,群馬県伊勢崎市上諏訪町1625-1,,,,,
P002,患者2,群馬県伊勢崎市宮子町3471-3,36.340352,139.152037,確認済み座標,群馬県伊勢崎市宮子町3471-3,
```

## 追加機能：A/B振り分け

画面上部の「追加：A/B振り分け」から利用します。

- A.csvの訪問先はAルートに固定
- B.csvの訪問先はBルートに固定
- C.csvは任意。入力した訪問先だけをA/Bのどちらかへ自動配分
- A/Bとも太田町366を発着地として訪問順を再作成
- 合計道路距離を優先しながら、A/Bの距離差も評価

A.csvとB.csvは必須、C.csvは任意です。3ファイルの合計は32件までです。

## サンプル

- `samples/訪問先_1台.csv`: 主機能用
- `samples/A.csv`、`samples/B.csv`、`samples/C.csv`: A/B振り分け用

## 前提と注意

- 発着地：群馬県伊勢崎市太田町366
- 伊勢崎市と周辺のOpenStreetMap道路網、公的住所データをHTML内に収録
- 一方通行を考慮した道路距離で訪問順を作成
- ルートは検討用の概算です。リアルタイム通行止め、時間帯規制、右左折禁止、車幅・高さ、私道、駐車位置、診療時間は別途確認してください。
- 患者情報を入力する場合は、院内の個人情報取扱ルールに従ってください。アプリ自体は入力内容を外部送信しません。
