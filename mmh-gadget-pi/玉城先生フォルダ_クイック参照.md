## よく使う操作の型

### 一覧だけ（存在確認）

対象PC上:

```bat
dir "\\10.4.144.75\miharaDB\004研究室\01 研究室\常勤医師\玉城先生"
dir "\\10.4.144.75\miharaDB\004研究室\01 研究室\常勤医師\玉城先生\転記無用"
```

### ファイル1つを D: 経由で回収する流れ

1. Pi に PS1/bat を載せる（パスは**スペース入り**）
2. 対象PCで `D:/j.bat` 実行 → 共有から `D:\outbox_json\` へ copy
3. `retrieve` 相当で Pi の SD（`/home/admin/usb-work/outbox/`）へ
4. 必要なら手元へ scp

取得済み例（手元）:

```text
~/Downloads/gadget-retrieve/scanscribe-ocr-diagnostic.json
```
