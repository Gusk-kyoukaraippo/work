# 造船所資材発注予測アプリ（ローカルHTML版）

単一の `index.html` だけで動作するローカルWebアプリです。データはブラウザのLocalStorageに保存され、ネットワーク通信は行いません。3ドックの造船計画を入力すると、週別の資材必要量を自動集計します。

## 主な機能（詳細）

### 1. 3ドック並列入力UI
- ドック1〜3を同時に表示し、各ドックに計画を追加できます。
- 船種選択（ドロップダウン）と、Phase 1〜3の開始日／終了日を入力します。
- 1ドックに複数船が順次入る想定で、計画を何件でも追加可能です。
- 入力日付は `input[type="date"]` を使用し、6ヶ月先まで入力できます。

### 2. 造船計画の追加・編集・削除
- `Add / Update` で新規追加または編集を確定します。
- 一覧の `Edit` で既存データをフォームに読み込み、修正できます。
- `Delete` で対象計画を削除できます。

### 3. LocalStorage自動保存／復元
- すべての計画は `shipyard_plans_v1` に自動保存されます。
- ページ再読み込み時に自動復元されます。

### 4. 週別資材必要量の自動集計
- 週の開始は**月曜日**で固定しています。
- 今日から6ヶ月先までの週ごとに集計します。
- Phaseの期間中は、該当資材の固定量をそのまま加算します。
- Phaseが重複する場合は合算されます（按分はしません）。

### 5. 集計結果の2種類表示
- **資材別表示**: 週×資材の表形式で必要量を表示します。
- **ドック別表示**: 週×ドックの表形式で合計量を表示します。

### 6. 現状の予定一覧
- 入力済み計画をドック別・時系列で一覧表示します。
- 各行から編集・削除が可能です。

### 7. データエクスポート／インポート
- `Export JSON` でLocalStorageの内容をJSONとしてダウンロードできます。
- `Import` でJSONを読み込むと、計画を復元できます。
- ドラッグ＆ドロップによる読み込みにも対応しています。

### 8. サンプルデータ投入／全データクリア
- `サンプルデータを読み込む` でデモ用データを一括投入します。
  - クリック時に確認ダイアログが出ます。
  - 既存データは削除され、サンプルが投入されます。
- `すべてクリア` で全データを削除して初期化できます。

## 使い方
1. `index.html` をブラウザで開きます（file://でOK）。
2. ドックごとに船種とフェーズ期間を入力し、`Add / Update` を押します。
3. 「Current Plans」や週別集計結果を確認します。

## 注意点
- 外部CSS/JS/JSONは一切使用していません。
- LocalStorage容量の上限を超える大量データには対応していません。
- ES6構文を使用しているため、最新のChrome/Edge/Firefox推奨です。
