# 本体を保守するとき

**通常のHTML組み込みでは、この手順を実行しません。** [共通原本](../../workbook/MVP6th.xlsm) はマクロ組み込み・照合済みです。アプリ追加は [専用スキル](../../.agents/skills/excel-gate-integrate/SKILL.md) から進めます。

| 必要になった作業 | 手順 |
| --- | --- |
| VBA変更後の共通ブック更新・再作成 | [共通ブックの保守](build-workbook.md) |
| Mac版Excelでコードを組み込む | [Macでの作業手順](build-workbook-mac.md) |
| Macへの貼り付けで構文エラーが出た | [貼り付け時の対処](mac-compile-fix.md) |
| Windowsの本体・アプリ・導入先の検収 | [対象環境での試験と記録](target-tests.md) |

VBAを変更したら、UTF-8ソース、CP932の取込用ファイル、Mac用貼り付け素材、実際のxlsmを一致させ、照合記録を更新します。ソースだけ直して古いxlsmを配布しないでください。

MVP6.1の本体はMVP6th最終修正版と同一です。説明書だけの変更で動作検証を失効させません。本体を変えた場合は本体・アプリ・導入先、アプリを変えた場合はアプリ・導入先の確認が必要です。
