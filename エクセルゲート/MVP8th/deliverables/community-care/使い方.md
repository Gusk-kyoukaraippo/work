# 地ケア・病床機能指標モニター — 日常の使い方 — Excelゲート MVP8th

Excelゲートは、共有場所の地ケア・病床機能指標モニター.xlsmをJUST Calcで開き、そこからEdgeの業務画面を使います。初回設定済みのブックを使ってください。「初回設定」だけが表示される場合は、導入担当者が [導入手順](導入手順.md) に沿って設定します。

「最新CSVで開く」があるアプリはCSV閲覧型、「編集する」「保存して終了」があるアプリはブック保存型です。自分のアプリに対応する手順を使います。

## CSV閲覧型：地ケアなど

1. 共有場所の地ケア・病床機能指標モニター.xlsmを開きます。
2. 「最新CSVで開く」を押します。登録したフォルダ直下のCSVを毎回取得し、Edgeが開きます。
3. 読込日時と対象ファイルを確認します。地ケアでは「読込内容を確認」から更新日時や不足も確認できます。
4. 対象月や病床区分を切り替えて閲覧します。
5. 終わったら、そのEdgeタブとブックを閉じます。保存者名の入力や保存操作はありません。

CSV更新後は、出力が完了してからブックの「最新CSVで開く」をもう一度押します。新しい画面の読込日時を確認し、古いタブを閉じます。開いたままの自動更新や、Edgeの再読み込みによるCSV再取得は行いません。

CSVにない月・区分・指標は「データなし」です。必要月数がそろわない期間集計も同じ表示になり、「0」やデモ値では補いません。未対応CSVは名前を表示して対象外にします。サブフォルダの中は読まず、上限は1,000ファイル・合計50MiBです。地ケアの対応形式は配布フォルダ内のruntime/CSV形式.mdにあります。

初回設定済みなら読み取り専用のブックでも閲覧できます。読込先の変更は、導入担当者がブックを編集可能で開き「読込先の設定」で行います。元CSVや集計結果を、この画面から保存・変更する操作はありません。

## ブック保存型：進捗ボード・引継ぎメモなど

### 入力して終了する

1. 共有ブックを編集可能な状態で開き、「編集する」を押します。作業中はブックを開いたままにします。
2. Edgeで入力します。保存者名の欄がある場合は入力します。
3. Edgeの「入力を終える」を押し、保存用ファイルのダウンロード完了を確認します。
4. 開いているブックへ戻り、「保存して終了」を押します。
5. ブックの保存完了通知を確認します。ブックが閉じたら、残っているEdgeの作業タブも閉じます。

ダウンロードされるJSONは、画面からブックへデータを渡すテキスト形式のファイルです。**Edgeで出力しただけでは正式保存は終わりません。ブック側の完了通知で確認します。** JUST Calcの通常の保存やCtrl+Sだけでは、Edgeの入力を取り込めません。

保存用ファイルが見つからない場合はダウンロード完了を確認し、別の場所へ保存した場合だけブックの案内で今回のファイルを選びます。古いファイルや別作業のファイルを代用しません。

### 途中で保存して続ける

Edgeの「途中保存・再出力」を開き、「途中保存の準備」を押します。ダウンロード完了後、ブックの「保存して続ける」を押して保存完了を確認し、同じEdge画面で作業を続けます。

終了するときは、改めてEdgeの「入力を終える」→ ブックの「保存して終了」です。途中保存用と終了用のボタンを対応させます。

### 閲覧と交代

「閲覧する」は最後に正式保存された内容を表示します。入力途中の内容は共有されません。ほかの人が保存した最新の結果を見るときは、共有ブックと閲覧画面を開き直します。

編集は一人ずつです。読み取り専用で開いた人は閲覧に使い、編集者が保存して閉じてから開き直して交代します。作業中のEdgeタブは複製・再読み込みせず、そのまま使います。

## 困ったとき

| 状況 | 対応 |
| --- | --- |
| ボタンが動かない | JUST Calcで開いているか、マクロが実行できる状態かを確認し、職場の管理担当者へ相談します |
| CSV接続・権限のエラー | 登録したフォルダのパス、共有先への接続、利用者の読み取り権限を確認します |
| CSV読込中の変更 | CSV出力の完了後に「最新CSVで開く」を押します。前から開いていた画面を今回の結果として扱いません |
| データなし | 対象月・区分・必要ファイル・期間がそろっているか、「読込内容を確認」で調べます |
| ブック保存が失敗 | ブックとEdgeを閉じず、エラー文と直前の操作を導入担当者へ伝えます。JSONとdataを残します |
| 「保存が完了していません」 | 接続を確認して案内どおり同じ保存ボタンで再試行します。解決しなければ開いたまま相談します |
| 保存後に終了だけ失敗 | 「保存して終了」で終了を再試行します |

CSV閲覧型の問題はCSV出力元・読込先を調べます。ブック保存型の復旧が必要な場合は、元のブック・data・ダウンロードJSONを保全します。[管理者向け復旧](管理者向け復旧.md) は保存型の手順です。
