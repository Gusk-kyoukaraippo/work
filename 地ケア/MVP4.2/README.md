# 地ケア MVP4.2

`file://` 直接起動を前提に、`MVP4.2/index.html` から見て並列にある `data/` フォルダ内CSVを相対パスで読みに行く版です。

## 配置

次の形で配置してください。

```text
地ケア/
├── MVP4.2/
│   └── index.html
└── data/
    ├── 病棟別人数分布表(条件指定)_2025-08.csv
    ├── 病床稼働報告_2025-08最終結果.csv
    ├── 地ケアマスタ_2025-08入院者.CSV
    └── ...
```

`files.json` のような一覧ファイルは使いません。

## 使い方

1. `MVP4.2/index.html` をダブルクリックして開く
2. 画面が `../data/` のCSVを相対パスで自動読み込みします
3. ブラウザ制限などで読めない場合は、画面上部の `CSVをここにドロップ` へ `data` フォルダをドラッグ＆ドロップします
4. 読み込み後、一時的に別データを見る場合は画面下部の `今回だけ使うCSVをここにドロップ` を使います

## 読み込み方式

- `../data/ファイル名.csv` を `fetch()` で直接読みに行きます
- サーバー上のフォルダ一覧やJSON一覧は使いません
- 命名規則から直近18ヶ月分の候補ファイル名を作ります
- 対象CSV3種が揃った月だけダッシュボードに表示します
- `file://` 直接起動では、ブラウザ設定によって相対読み込みが失敗することがあります
- 相対読み込みが失敗しても、ドラッグ＆ドロップ読み込みは使えます

## 対応CSV

- `病棟別人数分布表(条件指定)_YYYY-MM.csv`
- `病棟別人数分布表(条件指定)_YYYYMM.csv`
- `病棟別人数分布表(条件指定)_YYYY-MM-DD.csv`
- `病床稼働報告_YYYY-MM最終結果.csv`
- `病床稼働報告_YYYYMMDD.csv`
- `病床稼働報告_YYYY-MM-DD.csv`
- `病床稼働報告_YYYY-MM-DD最終結果.csv`
- `地ケアマスタ_YYYY-MM入院者.CSV`
- `地ケアマスタ_YYYY-MM-DD入院者.CSV`
- `地ケアマスタ_YYYYMM.csv`
- `地ケアマスタデータ_YYYYMM.csv`

## 注意

`file://` 直接起動で相対読み込みが動くかは、ブラウザの扱いに依存します。  
動かない場合でも、ユーザー操作で渡されたフォルダは読めるため、`data` フォルダをドラッグ＆ドロップしてください。
