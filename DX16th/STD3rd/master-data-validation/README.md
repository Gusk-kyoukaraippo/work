# 標準データ検証アプリ 2.0（Streamlit）

マスターデータ（`baseAmount × coefficient × S-curve`）と実績（月次納入）を突合して、**月別・累積・船種/フェーズ別・S-curve観点**で精度を見える化する検証アプリです。  
複数船が同時進行し、同一船内でフェーズが重複するケースも「タイムライン」で把握できます。

---

## できること（ざっくり）

- 複数船の工程（phase1/2/3）をガントチャートで表示し、**同一船内の重複期間**を強調表示
- 月別に **予測（predicted） vs 実績（actual）** を比較（材料/フェーズ/月で絞り込み可、合計表示つき）
- タイムラグ（納入タイミングのズレ）を複数パターンで比較
- 期間累積（バッファ別）で総量誤差を比較
- 船種×フェーズ×材料の誤差をヒートマップで俯瞰（※実績は按分推定）
- 予測累積 vs 実績累積（合成S-curve）で“形”のズレを見る
- 統計サマリー（MAPE/RMSE/MAE/R²）で比較
- **係数最適化タブ**で、船種×フェーズの係数を探索し、適用して全タブに反映・JSON出力

---

## セットアップ / 起動

```bash
cd DX16th/STD3rd/master-data-validation
pip install -r requirements.txt
streamlit run app.py
```

> PDF出力は `fpdf2` が入っている場合のみ有効です（未インストールでもアプリは動きます）。

## 入力データ

既定では `data/` 配下のサンプルを読み込みます。サイドバーからアップロードすると、そのデータで再計算します。

### 1) 船スケジュールJSON（複数ファイル）

`data/actual/ship_*.json` と同形式：

```json
{
  "船名": "64BC-1",
  "船種": "64BC",
  "phases": [
    {"phase": 1, "開始日": "2021-04-10", "終了日": "2021-07-20"},
    {"phase": 2, "開始日": "2021-06-15", "終了日": "2021-10-01"},
    {"phase": 3, "開始日": "2021-09-01", "終了日": "2022-01-15"}
  ]
}
```

- `船種` はマスターデータの `shipTypes[].id` と一致している必要があります。

### 2) 材料納入量JSON（phase1/2/3別）

`data/actual/material_phase*_*.json` と同形式：

```json
[
  {
    "phase": 2,
    "月次納入": [
      {"月": "2021-04", "資材": {"DW100": 1234.0, "DW200": 567.0}}
    ]
  }
]
```

### 3) マスターデータJSON

`data/master/master_data_v1.0.json` と同形式：

- `shipTypes[].phases[].materials.{material}.baseAmount`
- `shipTypes[].phases[].materials.{material}.coefficient`
- `shipTypes[].phases[].sCurve`（日次重み配列）
- `holidays`（祝日リスト）

---

## 予測（predicted）の計算ロジック

アプリ内の「月別検証」タブの **デバッグ: 計算式** に表示されます。要点は以下です：

- **営業日** = 土日 + `holidays` を除外
- `S-curve` を **実工期（営業日数）に合わせて補間**し、合計が1になるよう正規化
- 予測（日次）= `baseAmount × coefficient × S-curve_resampled[day_index]`
- 予測（月次）= 対象月に含まれる営業日の予測（日次）を合計

---

## 実績（actual）の扱い

- 月次納入JSONの値を月単位で扱います。
- 「月別検証」では **月×材料** で合算して比較します（タイムラグで実績が複製されても、最終的に月×材料で1本化）。
- 「累積検証」では、バッファに含まれる月の実績を材料別に単純合算します（phaseは合算）。

---

## タブ解説（見どころ）

### 概要
読み込み件数（船/予測/実績）などの状態確認。

### タイムライン
- ガントチャートで船×フェーズを可視化
- **同一船内でフェーズが重複している期間**をパターン（斜線）で表示
- 月別稼働船数、重複サマリーも表示

### 月別検証
- 材料/Phase/月をプルダウンで絞り込み（`(全て)` あり）
- 予測、実績、誤差率を可視化
- 表の合計（現在の絞り込み条件の合計）も別枠で表示
- タイムラグ：
  - 同月
  - 前1ヶ月（先行納入）
  - 後1ヶ月（遅延納入）
  - 前後±1ヶ月平均
  - 前2-4ヶ月平均

### 累積検証
選択期間に対して、前後の月を含めた“バッファ”を変えながら誤差率を比較。

### 船種・Phase
船種×フェーズ×材料の誤差をヒートマップ表示。  
※実績はphase合計から予測比率で按分した推定値です（個別実績がないため）。

### S-curve
予測累積と実績累積を同じ軸で表示し、どのタイムラグが良いかの目安を出します。

### 総合評価
タイムラグ別の統計（MAPE/RMSE/MAE/R²）を比較し、推奨パターンを表示。CSV/HTML/PDF（任意）も出力できます。

### 係数最適化
船種×フェーズ（3×3想定）の係数を探索し、MAPEや実数誤差を改善するためのタブです。

- 対象（船種/フェーズ/固定係数）の選択
- 目的関数（MAPE/実数誤差/重み付き）
- 係数の範囲、相関下限、変化率制限、最大試行回数、タイムアウト
- 実行ログ（CSV出力）、履歴
- 係数変化率ヒートマップ
- 最適化前後の月次比較（学習期間/テスト期間のサマリー表示）
- 「この係数でシミュレーション」で全タブに即時反映（リラン）
- エクスポートで `master_data_optimized.json` をダウンロード

> 現状の探索はランダム/簡易グリッド中心の“ベース実装”です。アルゴリズム選択UIはありますが、内部実装は段階的に強化していく前提です。

## よくあるつまずき

- **船種が一致しない**：実績JSONの `船種` とマスターデータの `shipTypes[].id` を揃えてください。
- **PDFが出ない**：`fpdf2` をインストールしてください。
- **係数を適用したのに数値が変わらない**：「この係数でシミュレーション」押下後に自動リランされます。適用後のタブ表示が更新されているか確認してください。
