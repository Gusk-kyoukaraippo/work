# 美原記念病院 リハビリテーション部 物品管理 — 日常の使い方 — 終了UI試作

配置場所の美原記念病院 リハビリテーション部 物品管理.xlsmをJUST Calcで開き、「編集する」からEdgeの業務画面を使います。作業中はブックを開いたままにします。「初回設定」だけが表示される場合は、導入担当者が [導入手順](導入手順.md) に沿って設定します。

編集中は画面下部の薄い一段バーを使います。保存を始めると案内欄が上へ広がり、進む・再試行・閉じるの主ボタンは同じ位置と大きさを保ちます。

## 入力を終える

Edgeで入力欄や小窓の内容を確定し、画面下部の「アプリを終了して保存作業に移る」を押します。同じ下部の欄に名前入力が出たら、お名前を入力し「この名前で保存作業に進む」を押します。この編集作業で一度入力した名前は、途中保存と終了時に引き続き使われます。その後の案内も同じ欄で切り替わります。

### A：通常のUI改善

1. Edgeは開いたまま、開いているブックの「保存して閉じる」を押します。
2. 「保存しました。Edgeの作業タブを閉じてから、こちらのOKを押してください」が出たら、Edgeの作業タブを閉じます。
3. ブック側のOKを押します。ブックも閉じます。

### B・C：自動で終了の準備をする試作

1. 「終了の準備中」が出たら、そのまま待ちます。
2. 「保存の準備ができました」に変わったら、「この作業タブを閉じる」を押します。閉じられない場合は、表示される案内に沿ってタブの×を押します。
3. 開いているブックの「保存して閉じる」を押します。
4. 「保存しました」が出たらOKを押します。ブックも閉じます。

ファイルを探す操作や、受け取りの完了を自分で調べる操作はありません。B・Cの「保存の準備ができました」は、ブックへ渡す準備ができたという意味です。ブックで「保存して閉じる」を押すと正式保存が完了します。

## 途中で保存して続ける

画面下部の「途中保存」を押します。初めてなら同じ欄でお名前を入力します。下部の案内に沿ってブックの「保存して続ける」を押し、保存完了の案内でOKを押します。Edgeの「保存後、入力画面に戻る」を押して編集を続け、最後は上の終了手順で閉じます。

## 閲覧と交代

「閲覧する」は最後に保存された内容を表示します。別の人が保存した最新の内容を見るときは、ブックと閲覧画面を開き直します。編集は一人ずつです。終了手順で作業タブとブックを両方閉じて交代します。

## 困ったとき

| 表示・状況 | 次の操作 |
| --- | --- |
| 「準備を続けています」 | Edgeとブックを開いたまま「もう一度準備する」を押します。進まなければ管理担当に連絡します |
| ブックに「終了の準備を再開」がある | そのボタンを押し、Edgeの案内が変わるまで待ちます |
| 保存の準備がまだできていない | 開いたまま少し待ち、同じ保存ボタンを押します |
| 保存が失敗した | 表示された案内を管理担当に伝え、ブック・入力内容・ファイルをそのまま残します |
| 保存後にブックだけ閉じられない | 「保存して閉じる」をもう一度押します。保存は重複しません |

次の作業は共有ブックから始めます。作業中のタブは複製・再読み込みせず、そのまま使います。復旧が必要な場合は管理担当が [管理者向け復旧](管理者向け復旧.md) を使います。

## CSV閲覧型

「最新CSVで開く」があるアプリは閲覧用です。登録先のCSVを読み、Edgeに表示します。更新後はブックの「最新CSVで開く」をもう一度押します。読み取り専用でも閲覧できます。終わったらEdgeの閲覧タブとブックを閉じます。保存者名の入力や保存操作はありません。
