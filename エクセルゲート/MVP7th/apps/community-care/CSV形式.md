# 地ケア・病床機能指標モニターのCSV

ブックに登録したフォルダ直下のCSVを、開く時に一度だけ読み込みます。画面内の「読込内容を確認」で読込日時・ファイル名・更新日時・不足を確認できます。CSV更新後はブックの「最新CSVで開く」から開き直します。

## 統合CSV

UTF-8（BOMあり・なし）またはShift_JISに対応します。列順は任意です。

```csv
病床区分,対象月,指標コード,分子,分母,値,基準日
community,202606,community_home_return,8,10,,2026-06-30
community,202606,community_emergency,,,0,2026-06-30
```

これは架空の形式例です。病床区分は `acute`（急性期）、`disability`（障害者）、`community`（地ケア）、または括弧内の日本語で指定できます。対象月は `202606` または `2026-06`。率は分子÷分母×100、平均は分子÷分母で計算し、値だけを渡すこともできます。

| 病床区分 | 指標コード |
| --- | --- |
| 急性期 | `acute_acuity`、`acute_los`、`acute_coordination`、`acute_emergency_admit` |
| 障害者 | `disability_core`、`disability_medical_care`、`disability_los`、`disability_return` |
| 地ケア | `community_home_return`、`community_nursing`、`community_home_admission`、`community_emergency` |

指標名・計算式・基準は元の地ケアMVP4thを引き継いでいます。急性期・障害者の仮基準については画面上の試作版の説明を確認してください。

## 既存の地ケアCSVセット

同じ対象月の以下の2ファイルを組み合わせます。ファイル名の年月から対象月を決め、同じ月・種類が複数あればファイル名の日付が新しいものを使い、対象外になった名前を表示します。

- `病棟別人数分布表(条件指定)_2026-06-30.csv`：6階・Ⅱの「該当」「対象」行を使用します。
- `地ケアマスタ_2026-06-30.csv`：2行目の「今回入院日」「今回退院日」「入院経路」「転出先」「備考とSCU日数」「再入院」を使用します。元画面と同じく2列目のIDがある行を対象にします。`地ケアマスタデータ_…` と末尾の `入院者` にも対応します。

`病床稼働報告_2026-06-30.csv`（末尾の「最終結果」も可）は任意です。元画面と同じく基準日の確認にだけ使い、指標値の集計には使いません。必要な2ファイルがそろわない月はデータなしになり、不足する種類と確認したファイル名を表示します。

## 欠損・不正データの扱い

- CSVにない病床区分・月・指標をデモ値で埋めません。既存データも再利用しません。
- 在宅復帰率の判定には連続6ヶ月、その他の判定には連続3ヶ月の値が必要です。期間が不足する場合、当月値は表示し、判定値を「データなし」として不足月を表示します。
- 実測の `0` は0と表示します。分母0で率を計算できない場合はデータなしです。最古月から最新月の間に抜けた月は、月の選択と推移表でもデータなしになります。
- 未対応CSVは名前を表示して対象外にします。不正な統合CSVの行、必要列が欠けた既存CSV、不正な文字コード・引用符はファイル名と理由を表示して全体の表示を停止します。
- 同じ月・種類・基準日の既存CSVが複数ある場合も停止します。
- 同じ月・区分・指標の重複、統合CSVと既存セットの同月地ケア指標の重複は停止します。値を確認してCSVの重複を解消してから開き直します。

画面からのファイル選択・ドロップ・保存・デモ切替はありません。CSVとブックの業務データは書き換えず、ブラウザへの永続保存も行いません。
