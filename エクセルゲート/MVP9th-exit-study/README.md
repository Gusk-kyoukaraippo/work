# Excelゲート 終了UI試作

MVP9thを元に、A（通常UI）、B（Application.OnTime）、C（VBA待機）の3案を実装した作業フォルダです。3案とも編集中は高さ72pxの一段バーを使い、保存を始めたときだけ上へ案内を広げます。名前入力・準備中・次の操作・再試行を同じ下部で切り替え、主ボタンの位置と大きさを保ちます。業務HTMLは保存案内文2か所だけ修正し、画面の配置・機能・業務コードを維持しています。保存・受け取り方式はr1から変えていません。

r4ではExcel側の説明を主ボタンの直上に置き、編集開始・保存・再試行を同じ位置の大きなボタンへ集約しました。「設定を見直す」でデータ・履歴・データベースIDを残して配置場所を再登録できます。作業中・保存途中・読み取り専用では変更できません。

比較用の完成ブックは [終了UI比較一式](../outputs/終了UI比較-r4/はじめに.md)、画面の表示は [比較ページ](../outputs/終了UI比較-r4/画面を比較.html)、[Excel側の画面](../outputs/終了UI比較-r4/Excel側の画面.html) から確認できます。Windows / JUST Calc / Edgeの成否と共有ロック解除は実機検証待ちです。

ソースはshared、vba/utf8にあります。CP932の取込用コード、Mac用原稿、コンパイル済みのworkbook/MVP9th.xlsmを照合しています。workbook/upstreamは更新前の原本です。

再生成は `node exit-study/build-study.mjs 新しい出力フォルダ` を使います。既存の出力や運用データへ上書きしません。`capture-screens.mjs` は表示用通知を模擬した画面撮影、`verify-study.mjs` は配布物・検証結果・比較ページの検査です。利用者PCへ開発環境を導入する必要はありません。
