# Excelゲート MVP9th

内部版 **0.9.0**。業務画面を配置場所から直接読み込む方式を、ブック保存型の標準にしました。完成ブック、共通部品、組み込み手順、試験、通常版の配布一式を同梱しています。利用者PCへの追加ソフト・サーバーは不要です。

## 使い始める

- [リハビリ物品管理・通常版](deliverables/rehab-inventory.zip)：今回の対象アプリ。展開して同梱の導入手順を読みます。
- [引継ぎメモ](deliverables/handoff-notes.zip)：ブック保存型の組み込み例。
- [地ケア](deliverables/community-care.zip)：CSVフォルダ閲覧型の組み込み例。CSVの読み込み方式は維持しています。
- [初めての方へ](はじめての組み込みと使い方.md) / [AIの入口](AI_START_HERE.md)

通常版から計測画面・比較用ボタン・診断ログ出力を外しました。日常操作は「編集する」→「入力を終える」→ブックの「保存して終了」です。旧版や運用中のブックへ上書きせず、新しいフォルダへ展開してください。データがある場合は [移行手順](docs/migration.md) を使います。

## 確認の範囲

直接読込の比較版で **0.876秒（1回）** を記録し、利用者から合格、および「保存して終了→開き直して内容が残る」の確認を受けています。条件はJUST Calc・PC内・Edgeです。これは今回の通常版そのものの再計測値ではなく、採用した方式の実測記録です。

通常版はVBAのネイティブコンパイルと保存後の全ソース照合、共通試験、3アプリのブラウザ試験を実施して梱包します。二台交代・共有先・異常終了復旧などのWindows実機確認は未完了の項目として残します。[確認状況](docs/operational-status.md) に詳細があります。

## 保持する契約

業務JSON・appId・dataVersion、編集開始前のブック保存、受渡しファイルの検証、正式保存・履歴・中断再開・管理者復旧、閲覧制限と古いセッションの拒否を維持します。全HTMLの一時コピーは行わず、小さな起動ページだけを生成します。起動ページには受渡しデータが含まれ、従来同様、正常終了時に一時フォルダを片付けます。

通常版の梱包（operational）と、全対象環境の検収完了（release）は別に記録します。未実施の試験を合格にする記録は生成しません。
