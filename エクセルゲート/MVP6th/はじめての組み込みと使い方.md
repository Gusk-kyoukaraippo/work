# はじめてのExcelゲート — 組み込み方と使い方

Excelゲートは、**ブラウザで使う業務画面（HTMLアプリ）を、共有フォルダのブックから開き、入力結果をそのブックに保存する仕組み**です。職場では、Windowsの **JUST Calc** でブックを、**Microsoft Edge** で業務画面を開きます。「ブック」は、表計算ソフトで開くファイルのことです。

導入担当者が行うことは、**HTMLをAIへ渡す → 画面を確認する → 共有場所へ置く → 保存と編集交代を試す**、の順です。コードの修正、コマンド操作、設定ファイルの編集、確認結果の記録はAIが担当します。

> **現在の状態（2026年9月21日）**
>
> マクロ入りの共通ブック `MVP6th.xlsm` は作成・保存済みで、コードと初回設定ボタンの照合に合格しました。単体検証で見つかった問題を修正し、共通ブックも更新しました。修正前の版でWindows版JUST Calcによる保存・再読込の本人報告がありますが、修正版と二台での実機確認はこれからです。今は「1」「2」まで進められます。「3」「4」は必要な確認がそろった後の手順で、まだ配布可能・利用開始可能ではありません。

完成ブックは、本体を提供するAI・開発者が、開発用Excelでマクロ（ボタンの処理を動かすプログラム）とボタンを組み込んで用意します。HTMLの修正とは別の工程で、アプリを追加するたびに作る必要はありません。自分で作る場合は [Mac版Excelでの手作業手順](docs/build-workbook-mac.md)、作成方法の全体像は [共通ブックの作成](docs/build-workbook.md)、保存などの仕組みは [README](README.md) にあります。

## 1. HTMLをAIへ渡す

### 用意するもの

- **組み込みたいHTML**。画像や見た目の設定ファイルが付いている場合は、位置関係を変えず、アプリのフォルダごと渡します。
- **Excelゲートのプロジェクト一式**。新しいAI環境へ渡す場合は、`MVP6th` と `.agents/skills/excel-gate-integrate` を元の位置関係のまま含めます。利用者向けの配布ZIPだけでは、組み込みに必要な手順やツールが足りません。

AIには、ファイルの読み書き・コマンド実行・ブラウザ試験ができる環境を使います。この会話の履歴は不要ですが、必要な開発ツールをAI側で準備する必要があります。別PCで環境準備からブック完成まで通す確認は、まだ済んでいません。

### 依頼する

AIとの会話でHTMLを添付するか、AIが読めるファイルの場所を指定し、次のように伝えます。

> このHTMLをExcelゲートに組み込んでください。プロジェクト内の専用手順に従い、元の画面と保存データの形を保って、動作確認と配布準備までお願いします。

表示名に希望があれば添えてください。希望がなければ、AIがHTMLのタイトルから用意します。AIがファイルを開けない場合は、読める場所へコピーするか、ファイル自体を渡します。

AIは原本を保管し、コピーを修正・試験して、確認用の画面を案内します。対応できない機能や、業務上の判断が必要な点があれば、その内容を説明します。

## 2. 普段の仕事を一つ、画面で試す

AIが案内した確認画面で、いつもの業務操作を試します。

- 一件追加して、入力内容を変更する。
- 検索や表示切替を使う。
- 計算や文書表示が、仕事で期待する結果になるか確かめる。
- AIが案内するデータの出力・読み込みを試し、入力内容が戻るか確かめる。

うまく動かなければ、操作と結果をそのまま伝えてください。

> 案件名を変更しましたが、読み込み直すと変更前の名前に戻りました。

AIが原因を調べて修正します。画面を開けないときもAIへ伝えてください。配布用HTMLはブックからの起動を前提としているため、直接開くだけでは動かない場合があります。

確認後、AIが次のどの段階かを案内します。これは作業の進み具合を示す言葉です。

| AIの案内 | 次にできること |
| --- | --- |
| **開発用** | HTML側の動作を確認する。完成ブックがない間は、ブックへの保存は確認できません |
| **実機検証用** | 完成ブックを含む一式を、業務データのない検証場所で試す。利用者への配布はまだです |
| **配布可能** | 本体とアプリの実機確認が済んだ状態。「3」の配置へ進めます |
| **利用開始可能** | 配置先での確認も済んだ状態。利用者へ案内できます |

## 3. 共有場所へ置き、利用開始を確認する

**AIから「配布可能」と案内された一式を使います。** 確認用に、Windows・JUST Calc・Edgeが使えるPCを二台と、全員が読み書きできる共有フォルダを用意します。マクロは職場で認められた方法で実行できる必要があります。利用者PCへの開発ツールの追加は不要です。

### 配置して「初回設定」を押す

1. ZIPで受け取った場合は、右クリックの「すべて展開」などで中身を取り出します。
2. **取り出したフォルダ一式**を、実際に使う共有場所へ置きます。AIがその場所へアクセスできれば、配置を依頼できます。
3. フォルダ内の `MVP6th.xlsm` をJUST Calcで開き、**「初回設定」**を押します。
4. 登録先として表示された場所を確かめ、正しければ「はい」を選びます。
5. 「初回設定が完了しました」と表示され、「編集する」「閲覧する」などのボタンが出ることを確認します。

共有場所は、たとえば `\\server\業務\進捗ボード` です。全員に同じ場所を案内します。ブックだけを取り出したり、各自のデスクトップへコピーして使ったりしないでください。**利用中のブックや `data` フォルダの上に、新しい配布物を重ねないでください。**

### 保存と、二台での編集交代を試す

まず「4. 日常の使い方」の手順で試しの内容を保存し、ブックを開き直して同じ内容が表示されるか確認します。その後、二台を使って次を試します。

1. 一台目で共有ブックを開き、「編集する」で作業を始めます。
2. 二台目で同じブックを開きます。編集はできず、保存済みの内容を閲覧でき、検索や表示切替が使えることを確かめます。
3. 一台目で保存してブックを閉じます。
4. 二台目の閲覧タブとブックを閉じ、共有ブックを開き直します。今度は編集できることを確かめます。

結果をAIへ伝えてください。AIが必要なPC・ソフトの版などを確認し、記録します。調べ方が分からなければ、AIに案内させてください。

AIから **「利用開始可能」** と案内されたら、利用者へ「共有ブックの場所」「操作手順」「困ったときの連絡先」を伝えます。操作手順には、配布フォルダの `使い方.md` を使えます。

## 4. 日常の使い方

### 入力して、保存して終わる

1. **JUST Calc**：共有場所の `MVP6th.xlsm` を開き、**「編集する」**を押します。以降もブックは開いたままにします。
2. **Edge**：業務画面で入力します。編集中の小窓などがあれば、アプリの「確定」「登録」などで内容を反映します。
3. **Edge上部**：保存者名を入力し、**「入力を終える」**を押します。
4. **JUST Calc**：タスクバーなどで開いたままのブックへ戻り、**「保存して終了」**を押します。
5. **保存完了の通知**：「ブックに保存しました。このブックを閉じます。」を確認してOKを押します。ブックが閉じたら、Edgeの作業タブも閉じます。

**保存完了は、ブック側の通知で確認します。** Edgeの「入力を終える」は、ブックへ渡すファイルを出す操作です。これを押しただけでは正式保存は完了せず、その画面での編集も終了します。続けて編集したい場合は、次の途中保存を使います。

### 途中で保存して、編集を続ける

1. **Edge**：入力を確定し、保存者名が空欄なら入力します。同じ編集作業では、一度入力すれば使い続けられます。
2. **Edge上部**：**「途中保存・再出力」**を開き、**「途中保存の準備」**を押します。
3. **JUST Calc**：ブックへ戻り、**「保存して続ける」**を押します。保存完了の通知を確認したら、ブックを開いたまま、同じEdgeの作業タブで編集を続けます。

### 見るだけのとき

共有ブックの **「閲覧する」**を押します。他の人が編集中でも、最後に保存された内容を閲覧できます。検索や表示切替も使えます。

表示は自動更新されません。最新を見るときは、閲覧タブとブックを閉じて開き直します。閲覧を終えたときも、両方を閉じます。

### 保存せずにやめるとき

ブックの **「閉じる」**を押し、未保存の変更を破棄してよい場合だけ確認に答えます。その後、Edgeの作業タブも閉じます。途中保存した内容は残ります。

次の作業は、毎回共有ブックから始めます。前回のEdgeの作業タブは使い回しません。

## 5. 困ったとき・アプリを更新するとき

| 状況 | すること |
| --- | --- |
| 初回設定のボタンが動かない | 表示された内容をAIへ伝え、完成ブックと職場のマクロ設定を確認してもらいます |
| 入力を確定するよう案内される | 開いている編集欄や小窓で、登録・確定またはキャンセルを行います |
| 保存用ファイルが見つからない | Edgeのダウンロード完了を待ち、同じ保存ボタンで再試行します。別の場所に出した場合は、案内に従って今回のファイルを選びます |
| 保存に失敗した | ブックとEdgeを閉じず、共有場所への接続を確認して同じ保存ボタンで再試行します。解決しなければ表示内容を導入担当者へ伝えます |
| 保存できたがブックが閉じない | 「保存して終了」をもう一度押します |
| 別の作業のファイル・不整合・分岐などが表示される | ファイルを編集・削除せず、表示内容を導入担当者へ伝えます |

導入担当者は、起きた操作と表示内容をAIへ伝えます。保存の問題が解決するまでは、ブック・Edgeの作業タブ・保存用ファイルを残してください。詳しくは [復旧手順](docs/recovery.md) を参照します。

**アプリの更新**は、新しいHTMLと前回の組み込み作業フォルダを指定し、「このアプリを更新してください」とAIへ依頼します。保存済みデータを引き継げるかも確認させます。MVP5thからMVP6thへ保存済みデータを自動移行する機能はありません。

確認済み・未確認の範囲は [検証記録](docs/verification.md)、利用者へ渡す短い操作説明は [日常の使い方](docs/user-guide.md) にあります。
