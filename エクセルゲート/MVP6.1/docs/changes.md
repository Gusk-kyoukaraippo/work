# MVP6.1で変えたこと

**作成済みの共通ブックを使って始められるよう、ドキュメントと配布素材を整理しました。**

- 初回の入口を「HTMLをAIへ渡す」に統一。マクロ作成を導入の前提作業にしません。
- 日常の操作、配置と初回設定、実機での確認、保守担当者の作業をそれぞれの資料にまとめました。
- 新しいAIへフォルダごと渡せるよう、専用スキル・AIの入口・依頼文をキット内へ収めました。
- 実機試験を、一台でできるものと二台が必要なものに分けました。
- 配布ZIPの組み込み結果、導入手順、実機試験、画面ヘルプを更新しました。
- 試験が過去の配布フォルダを参照しないようにし、このキットだけで一時配布物を作って検証します。

完成xlsm、VBA、業務HTML、実行JavaScript、業務JSON、アプリIDはMVP6th最終修正版を引き継いでいます。保存方法や本体の仕様変更、稼働中ブックの移行は含みません。

通常の入口は [はじめての組み込みと使い方](../はじめての組み込みと使い方.md)、検証の範囲は [確認状況](verification.md) にあります。
