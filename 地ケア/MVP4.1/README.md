# 地ケア MVP4.1

地ケア向けのスタンドアロンHTMLダッシュボードです。  
MVP4.1は、会社内オンプレ環境での固定フォルダ運用を検証するための版です。

## 位置づけ

- 現在の `index.html` は、固定フォルダ登録とドラッグ＆ドロップ読み込みを両方試せます
- IndexedDBで固定フォルダを保持する実装は、会社端末・ブラウザ設定で動作可否が変わるため、環境確認用の状態メッセージを表示します
- 実装方針の詳細は `IMPLEMENTATION_PLAN.md` を参照してください

## 想定運用

1. `index.html` をChromeまたはEdgeで開く
2. `固定フォルダを登録` を押して、CSVが入ったフォルダを選ぶ
3. 読み込みに成功すると、IndexedDBにフォルダ情報を保存します
4. 次回以降は、保存フォルダから自動読み込みを試します
5. IndexedDBやフォルダ権限が使えない場合は、CSVフォルダを画面上部へドラッグ＆ドロップします
6. 一時的に別データへ入れ替えるだけなら、画面下部の `今回だけ使うCSVをここにドロップ` へフォルダをドロップします
7. 次回以降の自動読み込み先を変える場合は、最下部の `自動読み込みフォルダを再設定` を押します

## 会社環境で確認すること

- ChromeまたはEdgeで起動しているか
- `file://` 直接起動でFile System Access APIが使えるか
- IndexedDBが会社ポリシーで禁止されていないか
- ブラウザ終了後も保存フォルダ権限が残るか
- CSVフォルダがローカルドライブか、ネットワークドライブか
- ネットワークドライブの場合、ブラウザからフォルダ列挙が安定するか

## 現行読み込み仕様

- 固定フォルダ登録に対応
- 保存フォルダからの自動読み込みに対応
- 固定フォルダが使えない場合のドラッグ＆ドロップ読み込みに対応
- 複数CSVファイルのドラッグ＆ドロップに対応
- Chrome / Edge などではCSVフォルダのドラッグ＆ドロップにも対応
- フォルダ内のCSVを再帰的に探す
- 3種類のCSVが同じフォルダにある前提
- 読み込み後は集計対象月のうち最新月を初期表示
- `地ケアマスタ` のファイル名に日付がない場合、CSV内の日付から対象月内の最新日を速報基準日として表示

## 対応CSV

- ダミーデータ
  - `病棟別人数分布表(条件指定)_YYYYMM.csv`
  - `病床稼働報告_YYYYMMDD.csv`
  - `地ケアマスタデータ_YYYYMM.csv`
- 実データ
  - `病棟別人数分布表(条件指定)_YYYY-MM-DD.csv`
  - `病床稼働報告_YYYY-MM-DD.csv`
  - `地ケアマスタ_YYYY-MM-DD入院者.CSV`
  - `地ケアマスタ_YYYYMM.csv`

文字コードは `Shift_JIS(CP932)` を想定しています。UTF-8にもフォールバックします。

## ファイル構成

- `index.html`: 現行ダッシュボード本体
- `README.md`: MVP4.1の概要と検証観点
- `IMPLEMENTATION_PLAN.md`: IndexedDB固定フォルダ化の詳細設計

## 注意

IndexedDBや固定フォルダ権限は、会社のブラウザ管理ポリシーで制限されることがあります。  
そのため、MVP4.1では固定フォルダ自動読み込みを主経路にしつつ、ドラッグ＆ドロップを必ず残す設計にします。
