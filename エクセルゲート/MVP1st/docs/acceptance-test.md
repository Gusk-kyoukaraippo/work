## 必須テスト

| No. | テスト | 操作 | 期待結果 | 結果 |
|---:|---|---|---|---|
| 1 | 初期化 | 編集可能な `.xlsm` で `InitializeHtmlAppSample` を実行 | `業務データ` と `_APP_META` が作成され、保存できる | |
| 2 | 編集モード起動 | 編集可能なブックで `OpenHtmlApp` を実行 | 既定ブラウザで開き、「編集モード」と表示される | |
| 3 | 日本語表示 | 日本語、引用符、改行、`<>&` を含むセルを表示 | 文字化けやHTML崩れがない | |
| 4 | 正常取り込み | HTMLで編集しJSON出力後、`ImportHtmlJson` を実行 | シートが更新され、revisionが1増え、ブックが保存される | |
| 5 | 読み取り専用起動 | 社内システムから読み取り専用で開いて `OpenHtmlApp` | 「閲覧モード」と表示され、入力・追加・削除・出力が使えない | |
| 6 | 読み取り専用取込拒否 | 読み取り専用ブックで `ImportHtmlJson` | 取り込みを拒否し、データを変更しない | |
| 7 | 古いrevision拒否 | 同じrevisionのJSONを一度取り込んだ後、同じJSONを再度取り込む | revision不一致で拒否する | |
| 8 | 別ブック拒否 | 別の初期化済みブックへJSONを取り込む | databaseId不一致で拒否する | |
| 9 | schema不一致 | JSONのschemaVersionを変更して取り込む | schemaVersion不一致で拒否する | |
| 10 | ID重複拒否 | JSON内のidを重複させて取り込む | ID重複で拒否する | |
| 11 | キャンセル | ファイル選択または最終確認をキャンセル | シートとメタ情報を変更しない | |
| 12 | 保存確認 | 取り込み後にブックを閉じて再度開く | データと新しいrevisionが保持されている | |

## 互換API確認

次の機能が対象環境で動くことを個別に確認します。

| 機能／API | 用途 | 失敗時の症状 | 結果 |
|---|---|---|---|
| `ThisWorkbook.ReadOnly` | 編集／閲覧モード判定 | 常に閲覧モード、またはマクロエラー | |
| `Application.GetOpenFilename` | JSON選択 | ファイル選択画面が開かない | |
| `CreateObject("ADODB.Stream")` | UTF-8入出力 | HTML生成／JSON読込エラー | |
| `CreateObject("WScript.Shell")` | 既定ブラウザ起動 | HTMLが開かない | |
| `ThisWorkbook.Save` | 取込後保存 | 更新後に保存エラー | |
| `Scripting.Dictionary` | JSON解析、検証 | JSON解析エラー | |

## 排他制御の組合せテスト

1. 利用者Aが社内システムから編集可能で開く。
2. 利用者Bが同じファイルを開き、読み取り専用になることを確認する。
3. AとBがそれぞれHTMLを開く。
4. AのHTMLが編集モード、BのHTMLが閲覧モードであることを確認する。
5. AがJSONを取り込み、保存する。
6. Bの既存HTMLが自動更新されないことを確認する。
7. BがブックとHTMLを開き直し、最新データが表示されることを確認する。

## 判定

必須テストと互換API確認がすべて合格し、社内システムの排他制御と矛盾しない場合のみ、業務固有の入力チェックとバックアップ手順を追加して本番適用へ進みます。
