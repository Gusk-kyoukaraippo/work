# MVP7thで変えたこと

MVP6.1を基に、**登録したローカルまたは共有フォルダからCSVを取得して業務HTMLへ渡す機能**を追加しました。本体・共通JavaScript・配布設定の版は **0.7.1**、共通ブックは `MVP7th.xlsm` です。MVP6.1と元の地ケアHTMLは保持します。

- `dataSource` で既定の `workbook`（ブック保存型）と、新しい `csvFolder`（CSVフォルダ閲覧型）を選びます。既存の保存型アプリの識別子と業務JSONは維持します。
- CSV読込先の絶対パスを初回設定でブックに保持し、管理画面から変更できます。日常は「最新CSVで開く」で、直下のCSVを取得してEdgeへ渡します。
- 新しい標準モジュール `GateSources` を追加し、標準モジュールは8個です。CSVはバイナリで読み、ファイル名・サイズ・更新日時とともに一時的な `excel-gate-source.js` へ渡します。ブックの業務データやブラウザの常設キャッシュには保存しません。
- 共通接続に `loadSourceFiles(files, info)` を追加しました。アプリは元の文字コード判定・CSV解析を使用できます。CSV型では常に閲覧専用で、編集セッション・保存者入力・正式保存は使いません。
- 取得上限は直下1,000件・合計50MiBです。接続・権限・読込中の変更・不正な受け渡しを検出した場合は停止します。表示中の自動更新やサブフォルダの探索は行いません。
- 地ケアアプリを最初の対応例として追加しました。元HTMLの画面と集計を活かし、連携時のファイル選択・ドロップ・デモ切替を外しています。不足するデータを過去値やサンプルで補いません。
- 自動試験、配布処理、CSV型専用の実機試験・検収記録を追加しました。保存型の合格記録をCSV型へ流用せず、導入先では試験したCSV読込先との一致も確認します。

通常のアプリ追加では、完成・照合済み原本のコピーを使います。VBAを変更したときは原本も更新・再照合します。運用中のブックや保存データを上書きする移行は含みません。

実機確認の範囲と残作業は [確認状況](verification.md)、接続方法は [CSVアプリの適合ガイド](csv-adapter-guide.md) にあります。

## 0.7.1：CSV読込先の柔軟化

CSV読込先には、ローカルの `C:\業務データ\CSV`、共有の `\\server\share\CSV`、割り当て済みの `Z:\CSV` を使えます。エクスプローラーの「パスのコピー」で付く外側の引用符、前後の空白、末尾の区切り、`/` 区切りも受け付けます。相対パス（`CSV` や `C:CSV`）、URL、`%USERPROFILE%` などの省略表記は使わず、フォルダの絶対パスを入力します。

設定はブック全体で共通です。ローカルパスやドライブ文字は、開いたPCでの場所を読みます。同じ `C:\CSV` でもPCごとに別のフォルダです。全員が同じCSVを見る場合はUNCパスをおすすめします。共有ブックも全員が同じUNCパスから開きます。

読込先の存在・接続・読み取り権限と、読込中の変更の確認は継続します。パス判定39件をMac版ExcelのVBAで確認しました。Windows・JUST Calcでの実際のフォルダ読込は未実測です。
