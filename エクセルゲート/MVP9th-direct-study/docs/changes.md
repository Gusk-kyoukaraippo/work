# MVP8thの変更

MVP7thを保持し、新しいMVP8th（内部版0.8.0）を作成しました。

- AIが最終HTMLの見出し・タイトル・用途とユーザー指定を確認し、identifyでdisplayNameを確定します。新規と更新の両方で必要です。
- 照合した共通原本から「アプリ名.xlsm」を生成します。画面名を維持し、Windowsで使えない文字はファイル名だけ安全な文字へ置換します。長いファイル名は短縮して識別用ハッシュを添えます。
- 初回設定・マクロ実行前からブックの見出しにアプリ名を保存します。小さく「DX推進委員会 Excelゲート」を表示します。製品名はExcelゲートです。
- 共通設定に任意のaccentColorを追加しました。省略時は共通色です。HTML案内・保存終了メッセージ・再描画後のパネルにもアプリ名が反映されます。
- 専用生成処理は表示用XMLのみを変更し、VBAを共通原本と同一に保ちます。生成元・生成物のハッシュと変更部品をマニフェストに記録します。
- 同梱例はCSV閲覧型の地ケアとブック保存型の引継ぎメモです。READMEと初心者向け案内は、この版だけで導入できる内容に更新しました。
- 更新は既存のappId・dataVersionを保ち、新しい場所に配布物を生成します。運用中のブックやdataを改名・上書きしません。

CSVの固定フォルダ読込、ローカル・共有・割り当て済みドライブへの対応、保存用JSONの正式取込は継続しています。実施した試験と未確認の環境は[検証記録](verification.md)を確認してください。
