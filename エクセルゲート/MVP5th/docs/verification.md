# MVP5th 検証記録

実施日：2026-09-21。対象運用はWindows／JUST Calc／Edgeと共有フォルダです。

## この環境で確認したこと

- Mac上のChrome／Playwrightによるfile://起動、実際のダウンロード、業務JSONを別ページへ戻すデータ往復。
- 共通欄の「入力を終える」と補助メニューの「途中保存の準備」をクリックし、保存方法・保存者名・出力順・親ID・案内文を確認。
- 出力時点でブックへの保存完了を表示しないこと、終了用出力後は編集を止め、再出力は同じバイト列になること。
- 二つの既存アプリの未確定入力保全、閲覧制御、検索・文書移動、外部更新APIの拒否。連携中のlocalStorage読み書きは0回。
- 初回と保存済み空データの区別、非同期読込、キャンセル、例外、JSON制約、出力の二重押下。
- 配布ファイルの自動収集、接続ひな型、危険なパス・未完成アダプター・既存出力への上書きの拒否。
- 完成ブックや検収記録が不足する場合、通常配布を生成しないこと。検収記録と配布ファイルのハッシュ不一致も拒否。
- VBAの静的チェック：文字コード、文字列構文、保存方法の照合位置、PREPARED優先、最終保存失敗時のデータ・管理情報・履歴復元、対象ブックだけの終了、終了失敗時の再試行。
- 初回設定画面と操作パネルのレイアウトを描画し、二つのHTML画面のスクリーンショットとともに視認確認。

自動テストは **32件合格**。最終ログは `test-report.txt` に保存します。
