# はじめての組み込みと使い方

Excelゲートは、HTMLの業務画面を **JUST Calcのブックから開き、入力結果をそのブックへ保存する仕組み** です。画面を使うブラウザはEdgeです。

**マクロ入りブックは、このキットに入っています。作成やVBA編集から始める必要はありません。** 導入担当者が行うのは、HTMLを渡す、画面を試す、職場のPCで動きを確認することです。

## 1. キットとHTMLをAIへ渡す

この **MVP6.1フォルダ一式** と、組み込みたいHTMLをAIが読める場所に置き、次のように依頼します。画像やCSSなどの付属ファイルがあるHTMLは、元の位置関係を保ったフォルダごと渡します。

> このHTMLをExcelゲートMVP6.1に組み込んでください。同梱のAI_START_HERE.mdを読み、完成済みブックを使って、画面確認と配布準備まで進めてください。

会話の履歴がないAIにも依頼できます。ファイルの読み書き・コマンド実行・ブラウザ試験ができる環境を使ってください。[そのまま使える依頼文](AIへの依頼文.md) もあります。

AIが元HTMLを保管し、コピーを改修・試験します。表示名はHTMLから取得し、共有場所や業務上の判断など、決められないことだけ確認します。コード・設定ファイル・照合情報を自分で編集する必要はありません。

## 2. いつもの業務操作を試す

AIが案内する確認画面で、一件の入力から変更・確定まで試します。元のアプリにある検索、絞り込み、表示切替、計算なども確認してください。

おかしい点は、操作と結果を会話で伝えれば大丈夫です。

> 案件名を変更しましたが、読み込み直すと元の名前に戻りました。

AIが原因を調べて修正します。HTMLを直接開いて動かない場合も、内部の設定を自分で直さず、その状況を伝えてください。

## 3. 出来上がった一式を職場のPCで試す

AIから、ブック・HTML・必要ファイル・短い案内をまとめたフォルダまたはZIPを受け取ります。**ブックだけを取り出さず、フォルダ一式を使います。**

現在の状態は「実機検証用」です。業務データのない検証場所へ置き、[配置と初回設定](docs/install.md) に従って、同梱の `MVP6th.xlsm` をWindows版JUST Calcで開きます。「初回設定」は、そのコピーを置いた場所とアプリの情報を登録する操作です。マクロを作成する操作ではありません。

まず一台で、入力・保存・開き直し・閲覧・途中保存を試せます。二台がそろったら、同時に編集できないことと、保存後に編集を交代できることを確認します。[画面操作で進める確認手順](docs/acceptance-test.md)

結果はAIへ伝えます。記録への転記と、残っている確認の整理はAIが担当します。二台がない間は、その試験を未実施として残せます。

## 4. 利用開始後は、共有ブックから開く

AIが本体・アプリ・導入先の確認結果を照合し、**「利用開始可能」** と案内したら、全員に同じ共有ブックの場所を伝えます。毎回、そのブックから「編集する」または「閲覧する」を押します。

入力を終えるときは、**Edgeの「入力を終える」→JUST Calcの「保存して終了」** の順です。保存完了はブック側の通知で確認します。利用者には [日常の使い方](docs/user-guide.md) を渡してください。

| AIの案内 | 意味 |
| --- | --- |
| 実機検証用 | ブックとHTMLはそろっています。検証用データで試す段階です |
| 配布可能 | 本体とアプリの対象環境での確認が済んでいます。導入先の確認へ進めます |
| 利用開始可能 | 配置した共有場所での確認も済んでいます |

同梱の原本は作成済みですが、Windowsでの必要な検収がすべて完了したわけではありません。[現在の確認状況](docs/verification.md)

## 更新や問題があったとき

新しいHTMLと、このキット内の前回の組み込み記録を指定し、「同じアプリを更新して」とAIへ依頼します。運用中のブックや `data` に新品を上書きせず、保存済みデータを保つ更新方法を確認させます。

保存に失敗したらブックとEdgeを閉じず、表示された内容を導入担当者またはAIへ伝えてください。[保存で困ったとき](docs/recovery.md)
