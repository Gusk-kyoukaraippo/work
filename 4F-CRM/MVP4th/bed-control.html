性別データの準備
MVP2取込で「調整」になった患者を男性・女性へ修正します。
判定ルール
候補検索で自動的に確認する内容です。
✓ 希望期間中、同じ病床が連続して空いている
✓ 4人部屋は、部屋番号をまたぐ任意回数の転床で期間をつなぐ案も探索
✓ 転床案は、少ない転床回数を優先して最大3件の配置例を表示
✓ 共有室に異性や性別未確認の患者が重ならない
✓ 病床整備・利用不可時間と重ならない
✓ 2人部屋は、既存患者1人の転床案も探索
✓ 既存4人部屋患者の再配置は行わない
病床ボードの見方・操作
一覧画面で迷ったときに確認する早見表です

表示の見方

患者氏名
患者の予定帯氏名だけを表示。詳しい情報は帯にマウスを置くと確認できます。
入院区分の色長期療養はピンク、リハビリは灰色、レスパイトは青、療養は黄色です。左の現在患者にも同じ色を薄く表示します。
斜線の範囲退院・終了時期がまだ確定していない期間です。
転床後
帯の下の濃い線同じ入院中の転床後区間です。
小さな2色印同じ病床で退院と入院が同日にある入替です。
黄色の点重複や病室ルールなど、内容の確認が必要です。
病床横の点と氏名緑は本日10時に使用中で患者氏名を表示、白は空床で氏名欄は空白です。
入2
退1
日付下の入・退その日の入院予定数と退院予定数です。

操作方法

帯をクリック予定を選択し、日時入力・転床・配置待ちへの戻しを表示
帯をダブルクリック患者・入院予定の詳細を開く
帯の中央を横へ入退院予定をまとめて移動
帯の左右端を横へ入院期間を延長・短縮
帯を別病床へ同じ入院のまま転床を登録
日付をクリックその日の入院・退院・転床を時系列で表示

予定帯にマウスを置くと、入院ID・期間・確定状況・転床状態を確認できます。

予定日時は分単位で保存されます
空欄なら最後まで実線です。入力した日時から退院予定日時までを斜線で表示します。
病床変更は、予定変更と混同しないよう専用操作で行います。
同一病床の時間帯重複・病室ルール・整備中配置を登録前に確認します。
