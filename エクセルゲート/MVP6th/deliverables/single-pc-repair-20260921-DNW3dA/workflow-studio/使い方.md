# Excelゲートの使い方

## 入力して、保存して終わる

1. 案内された共有フォルダの **MVP6th.xlsm** を開き、**編集する**を押します。
2. Edgeで入力します。ブックは開いたままにしてください。
3. 入力欄や編集ダイアログを確定し、上部に保存者名を入力して **入力を終える**を押します。
4. 開いているブックへ戻り、**保存して終了**を押します。
5. 「ブックに保存しました」を確認してOKを押します。ブックが閉じたら、残ったEdgeの作業タブも閉じます。

保存者名は、この編集作業で一度入力すれば使い続けられます。
画面の切り替えはタスクバーなどで行います。Edgeでファイルを出力しただけでは、共有データへの保存は完了していません。

## 途中で保存して続ける

Edge上部の「途中保存・再出力」を開き、**途中保存の準備**を押します。
ブックへ戻り、**保存して続ける**を押します。
保存完了を確認したら、ブックを開いたまま同じEdgeの画面で続けます。
最後は「入力を終える」→「保存して終了」を使います。

## 見るだけのとき

共有ブックの **閲覧する**を押します。他の人が編集中でも、最後に保存された内容を閲覧できます。
表示中のデータは自動更新されません。最新を見るときは閲覧タブとブックを閉じ、開き直します。
閲覧を終えたら、Edgeのタブとブックを閉じます。

## 困ったとき

| 表示・状況 | 操作 |
| --- | --- |
| ファイルがまだ見つからない | Edgeのダウンロード完了を確認し、同じ保存ボタンを押す。別の保存先を使った場合だけファイルを選ぶ |
| 保存方法が違う | 表示された案内に従い、「保存して続ける」か「保存して終了」を使う |
| 保存できなかった | ブックを閉じず、接続を確認して同じ保存ボタンで再試行する |
| 保存できたが閉じられない | 「保存して終了」をもう一度押す。保存は重複しない |
| 入力を保存せずやめたい | ブックの「閉じる」を押し、入力を破棄してよい場合だけ確認に答える |
| 別の作業・ファイルの分岐などが表示された | ファイルを編集・削除せず、導入担当者へ連絡する |

ブックを閉じた後の古いEdgeの画面は使い回さず、次回も共有ブックから始めてください。
