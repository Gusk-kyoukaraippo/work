# はじめてのExcelゲート — HTMLの組み込み方と使い方

この説明書は、プログラムに詳しくない人が「何を準備して、どの順に操作すればよいか」を知るためのものです。

対象としている環境は **Windows 10・JUST Calc・Microsoft Edge** です。画面に「Excel」と表示される箇所がありますが、この説明書では、データを保存する表計算ファイルを「ブック」と呼びます。

> **いまの完成状況（2026年9月21日）**  
> HTML側の組み込みと、保存を行うプログラムは作成済みです。  
> ただし、そのプログラムを入れた完成版の `MVP4th.xlsm` は、まだ配布できていません。今あるのは、組み込み前のテンプレートとプログラムです。  
> また、JUST Calcの実機では動作を確認できていません。以下は導入と確認のための手順であり、この環境で動作確認済みの操作説明ではありません。途中で進めない場合、あなたの操作ミスとは限りません。

## まず、自分が読む場所を選んでください

| やりたいこと | 読むところ |
| --- | --- |
| 準備済みのものを使って、入力・保存したい | 「1. 仕組み」と「5. 普段の使い方」 |
| 同梱の進捗ボードや改善ワークフローを使えるようにしたい | 「2. 用意済みアプリの準備」→「4. 保存用ブックの準備」 |
| 自分で持っているHTMLに保存・閲覧機能を付けたい | 「3. 自分のHTMLを組み込む」→「4. 保存用ブックの準備」 |
| エラーが出た、保存できたか分からない | 「6. 困ったとき」 |

**「初めて使えるようにする準備」と「毎日の操作」は別です。** 準備は担当者が一度行います。利用者が毎回プログラムを貼り付ける必要はありません。

## 1. 何をする仕組みなの？

たとえば、職場で一つの進捗表を使う場面を考えてください。

- **Edgeの画面**：文字を入力したり、内容を見たりする場所です。
- **共有フォルダのブック**：みんなが使う正式なデータの保存場所です。
- **受け渡しファイル**：Edgeで入力した内容を、ブックへ運ぶためのファイルです。

使う順番は、次のとおりです。

```text
共有フォルダのブックを開く
        ↓
「編集する」を押す
        ↓
Edgeで入力する
        ↓
受け渡しファイルを出力する
        ↓
ブックへ戻って、正式保存する
        ↓
正式保存できたことを確認して、ブックを閉じる
```

**Edgeからファイルがダウンロードされただけでは、みんなが使うデータは更新されません。ブックに戻って「正式保存」するところまでが一組です。**

誰かが編集のためにブックを開いている間、ほかの人は正式保存済みの内容を閲覧する構成です。ほかの人がいま入力している途中の内容は見えません。二人が同時に正式データを書き換えないことは、導入時に実機で確認します。

### この説明書に出てくる言葉

| 言葉 | 意味 |
| --- | --- |
| HTML | Edgeなどで表示するアプリのファイル。例：`index.html` |
| 共有フォルダ | 職場の複数のPCから同じファイルを開ける場所 |
| 正本 | 全員で使う、正式な保存先のブック。各自のPCへコピーしたものとは区別します |
| JSON（ジェイソン） | 入力した内容を運ぶデータファイル。普段は中を編集しません |
| VBA／マクロ | ブックのボタンを押したときに動くプログラム |
| 組み込み | HTMLやブックから、Excelゲートのプログラムを使えるようにする準備 |
| 初期設定 | どのアプリを、どこにあるブックで管理するかを登録する、最初の一回の操作 |

## 2. 用意済みのアプリを使う場合

### 2-1. どちらを使うか選ぶ

MVP4thには、次の二つが入っています。

| アプリ | 用途 | 開発フォルダ内での場所 |
| --- | --- | --- |
| プロジェクト進捗ボード | プロジェクトの進み具合を一覧で管理 | `MVP4th/dist/progress-board` |
| 改善ワークフロー | 改善活動の文書を作成・管理 | `MVP4th/dist/workflow-studio` |

**この二つのHTMLは、すでにExcelゲートにつなぐ修正を済ませています。「3」のHTML編集は不要です。**

ZIPを使う場合は、`MVP4th/releases` にある該当アプリのZIPを展開してください。ZIPの中で直接作業せず、展開後のフォルダを使います。

### 2-2. フォルダを丸ごと共有場所へ置く

例として、進捗ボードを使います。

1. `progress-board` フォルダを見つけます。
2. フォルダを丸ごと、職場の共有フォルダへコピーします。
3. コピー先のフォルダを開きます。
4. 次のファイルやフォルダがあることを確認します。

```text
progress-board/
├─ MVP4th-template.xlsx    ← 保存用ブックのひな型
├─ gate.config.json       ← どのアプリかを書いた設定
├─ runtime-files.txt      ← 必要なファイルの一覧
├─ runtime/               ← 組み込み済みHTMLと共通プログラム
├─ shared/                ← 使い方などの共通ファイル
├─ vba/                   ← ブックへ入れるプログラム
└─ data/                  ← 正式保存や復旧のための保管場所
```

ほかにも手順書などのファイルがあります。そのまま一緒に置いてください。

**`index.html` だけ、またはブックだけを取り出して配布しないでください。** ブックと同じフォルダにある設定・プログラムも使います。

ここまでできたら、「4. 保存用ブックの準備」へ進みます。

## 3. 自分のHTMLを組み込む場合

この章は、用意済みの二つ以外のHTMLを使う人向けです。

### 3-1. 何を変更する必要があるか

自分のHTMLをフォルダに入れるだけでは、保存する内容や、編集を禁止するボタンがExcelゲートには分かりません。そのため、HTMLに次の接続を作ります。

| 接続するもの | 具体的にすること |
| --- | --- |
| 読み込む | ブックから受け取ったデータを、アプリの入力欄や一覧に表示する |
| 書き出す | アプリで入力・変更したデータを、一つにまとめて渡す |
| 閲覧だけにする | 入力・追加・削除・ファイル読込など、データを変更する操作を止める |

さらに、アプリが以前の入力をブラウザ内へ自動保存している場合、その処理を連携中は止めます。ブックのデータを読み込んだ後に、ブラウザ内の古いデータで置き換えてしまわないためです。

**この部分はアプリごとに違い、プログラムの修正が必要です。** HTMLを作った人に頼む場合も、次の作業内容をそのまま渡せます。

### 3-2. 元のHTMLをコピーして作業場所を作る

ここでは、新しいアプリの作業フォルダ名を `my-app` とします。

1. 元のHTMLと、付属の画像・CSS・JavaScriptを別の場所へバックアップします。
2. **MVP4th全体がある開発用フォルダ**を開きます。配布ZIPだけでは、この章に使う `scripts` フォルダは含まれていません。
3. `apps` の中に `my-app` フォルダを作ります。
4. そこへ元のHTMLをコピーし、入口のファイル名を `index.html` にします。
5. 付属ファイルも、元と同じ位置関係になるようにコピーします。

```text
MVP4th/
├─ apps/
│  ├─ progress-board/
│  ├─ workflow-studio/
│  └─ my-app/             ← 新しく作る
│     ├─ index.html       ← あなたのHTML
│     ├─ style.css        ← 元から使っていれば入れる
│     └─ images/          ← 元から使っていれば入れる
├─ shared/
└─ scripts/
```

`style.css` や `images` を使っていないアプリなら、それらを作る必要はありません。

### 3-3. HTMLに共通プログラムの読み込みを追加する

ここからは、HTMLを**文字を編集するソフト**で開きます。Edgeで表示する操作とは違います。文字化けしないよう、保存時の文字コードはUTF-8にします。

`<head>` 内の `<meta charset="utf-8">` の後などに、次を追加します。**元のアプリの `<script>` より前**に置いてください。一つのHTMLに一回だけ入れます。

```html
<!-- EXCEL_GATE_START -->
<script src="../../shared/standalone-boot.js"></script>
<script src="../../shared/excel-gate-core.js"></script>
<script src="../../shared/excel-gate.js"></script>
<!-- EXCEL_GATE_END -->
```

これは、上の `apps/my-app/index.html` という配置で使う記述です。フォルダの深さが違う場合、そのままではファイルを見つけられません。

ここで読み込む三つのファイルは、MVP4thにすでに入っています。中身をHTMLへ全部貼り付ける必要はありません。前後の `EXCEL_GATE_START` と `EXCEL_GATE_END` も削除しないでください。配布用のフォルダを作るときの目印です。

### 3-4. そのアプリの「読込・書出し・閲覧」を接続する

前の手順だけでは、まだ組み込み完了ではありません。次の形で、アプリ自身の処理をつなぎます。

**次は考え方を説明するコードです。そのまま貼れば動く完成コードではありません。** 「ここで〜する」の部分を、実際のアプリのプログラムに合わせて実装します。

```js
ExcelGate.connect({
  load: function (data, info) {
    // ここで、受け取ったdataを画面へ表示する。
    // info.hasPayloadがfalseのときだけ、初回の空データを用意する。
  },
  exportData: function () {
    // ここで、画面の入力を含む保存対象データを作り、returnで返す。
    // 入力を確定できていない場合は、理由を示して出力を止める。
  },
  setReadOnly: function (readOnly) {
    // readOnlyがtrueなら、追加・変更・削除できないようにする。
    // 検索や表示の切替は使えるように残す。
  }
}).catch(function (error) {
  console.error(error);
});
```

`load` は「受け取って表示」、`exportData` は「保存する内容を渡す」、`setReadOnly` は「見るだけにする」と読めば十分です。

この接続は、アプリのデータや関数にアクセスできる場所へ、一回だけ置きます。HTMLの一番下へ貼れば必ず動くとは限りません。データの読み込みに時間がかかるアプリは、その完了を待つ接続も必要です。担当者は [技術者向けの接続説明](docs/adapter-guide.md) を併せて確認してください。

保存者名の欄、受け渡し用の保存ボタン、Excelへ戻る案内は、共通プログラムが表示します。アプリ側で同じ画面を作り直す必要はありません。

### 3-5. アプリの設定ファイルを作る

`apps/my-app` の中に、`gate.config.json` という名前でファイルを作ります。`gate.config.json.txt` になっていないか確認してください。

**HTMLが一つだけのアプリ**なら、次を出発点にできます。

```json
{
  "displayName": "わたしの業務アプリ",
  "appId": "my-business-app",
  "dataVersion": 1,
  "entry": "index.html",
  "files": ["index.html"],
  "runtimeVersion": "0.4.0",
  "viewPolicy": "view",
  "authorRequired": true
}
```

| 項目 | 何を書くか |
| --- | --- |
| `displayName` | 人に見せるアプリ名。日本語で構いません |
| `appId` | アプリを区別する名前。半角英小文字・数字・ハイフンを使い、別アプリと重複させません |
| `dataVersion` | 保存データの形の版。新しいアプリでは1から始めます |
| `entry` | 最初に開くHTMLの名前 |
| `files` | このアプリが使うファイルをすべて列挙します |
| `runtimeVersion` | このMVP4thでは `0.4.0` のままにします |
| `viewPolicy` | 今回は閲覧を使うので `view` のままにします |
| `authorRequired` | 保存者名を入力するので `true` のままにします |

CSSや画像も使うなら、たとえば `files` の行を次のようにします。

```json
"files": ["index.html", "style.css", "images/logo.png"]
```

フォルダ名だけを書くのではなく、必要なファイルを一つずつ書きます。共通の `excel-gate.js` などは自動で追加されるので、この一覧へ入れません。

### 3-6. 配布するフォルダを作る【準備担当者の作業】

この作業には、Node.jsというプログラム実行用ソフトが必要です。普段アプリを使う人のPCへ入れる必要はありません。

Node.jsを利用できる開発用PCで、`MVP4th` フォルダを作業場所にして、PowerShellなどのコマンド入力画面を開きます。「コマンド」とは、PCへ文字で作業を指示するものです。

まず、次を入力してEnterキーを押します。

```powershell
node --version
```

版番号が表示されたら、次へ進めます。「認識されません」と出る場合は、この準備をプログラム担当者へ依頼してください。

続けて、次の一行を入力します。

```powershell
node --input-type=module -e "import { buildApp } from './scripts/package.mjs'; await buildApp('my-app', './dist-my-app');"
```

この命令は、`apps/my-app` を基に、配布用の `dist-my-app/my-app` を作ります。元の業務データを変換・移行する命令ではありません。

出来上がった `dist-my-app/my-app` を**フォルダごと**共有場所へコピーし、「4」へ進みます。

`Output already exists` と出た場合は、前に作った出力先が残っています。命令中の `./dist-my-app` を `./dist-my-app-2` など、新しい名前へ変えてください。利用中のブックや `data` を消して作り直さないでください。

### コードの修正を依頼するときに渡す文章

次の文章と、元のHTML・付属ファイル・MVP4th一式を担当者へ渡すと、依頼内容が伝わります。

```text
このHTMLをExcelゲートMVP4thへ接続してください。
利用環境はWindows 10、JUST Calc、Microsoft Edgeです。
ほかの人が編集中でも、正式保存済みデータは閲覧できるようにします。

元の画面と業務データの形を保ち、次を対応してください。
・ブックから受け取ったデータを画面に反映する。
・未確定の入力を落とさず、保存対象データを返す。
・閲覧時は入力、追加、削除、ファイル読込、外部からの変更を止める。
・連携中はブラウザ内の古いデータを復元せず、自動保存を止める。
・共通の保存画面を利用し、アプリ内に保存管理を作り直さない。
・gate.config.jsonと必要な付属ファイルを用意する。
・共通VBAをこのアプリ専用に書き換えない。

完成物として、修正HTML、設定、配布フォルダ、変更箇所の説明、
確認できたことと未確認のことを渡してください。
仕様の詳細はMVP4th/docs/adapter-guide.mdを参照してください。
```

## 4. 保存用ブックの準備【最初の一回・準備担当者向け】

HTMLを組み込む作業と、保存用ブックへプログラムを入れる作業は別です。用意済みの二つのアプリでも、この章の準備が必要です。

**JUST Calcの版によって利用できる機能や画面が異なるため、この説明書では未確認のメニュー名を指定していません。** VBAの編集・取り込み機能が見つからない、または下記のプログラムを扱えない場合は、その版で動かせるかを担当者が確認する必要があります。Excelの操作名をJUST Calcにもあるものとして探し続ける必要はありません。

### 4-1. 共有場所を決める

全員が使う共有場所を一つ決め、配布フォルダ一式を置きます。

例：`\\職場のサーバー\共有\進捗ボード\`

これは例なので、そのまま入力するパスではありません。実際の職場の場所に置き換えてください。

初期設定後にブックを移動したり名前を変えたりすると、登録した場所と違うため使えなくなります。**先に場所とファイル名を決めます。**

### 4-2. テンプレートをマクロ付きブックとして保存する

1. 配布フォルダの `MVP4th-template.xlsx` を表計算ソフトで開きます。
2. 「名前を付けて保存」に相当する操作をします。
3. マクロを保持できる `.xlsm` 形式を選びます。
4. **テンプレートと同じフォルダ内**へ、`MVP4th.xlsm` という名前で保存します。

ファイル名の末尾だけを `.xlsx` から `.xlsm` に書き換える操作ではありません。表計算ソフトで保存形式を選んでください。この時点では、まだボタンのプログラムは入っていません。

### 4-3. 七つのプログラムを取り込む

ブックのVBA編集画面を開き、配布フォルダの `vba` にある次の七つを、標準モジュールとして取り込みます。「標準モジュール」は、プログラムを入れる入れ物の種類です。

```text
GateConfig.bas
GateJson.bas
GateDeployment.bas
GateStorage.bas
GatePanel.bas
GateMain.bas
GateRecovery.bas
```

`vba/utf8` の中にも同名のファイルがありますが、**取り込みに使うのは `vba` 直下の七つ**です。ファイルの文字コードを取り込み用に調整してあります。

二回取り込んで同名のプログラムを増やさないようにしてください。現在の配布物から新しく作ったブックで作業するのが出発点です。

### 4-4. ブックを開いたときの処理を登録する

1. `vba/ThisWorkbook.txt` を文字の編集ソフトで開きます。
2. 中の文章を全部コピーします。
3. VBA編集画面で **`ThisWorkbook`** のコード欄を開きます。
4. そこへ貼り付けます。
5. VBAのコンパイル、つまりプログラムの構文確認を行います。
6. エラーがなければ、ブックを保存します。

貼り付け先はセルでも、`Sheet1` でも、新しい標準モジュールでもありません。`ThisWorkbook` は、そのブックを開く・保存する・閉じる際の処理を書く場所です。すでにコードがある場合は、同じ処理を重ねて貼らず担当者に確認してください。

この段階でコンパイルエラーが出たら、画面のエラー文と強調された行を記録します。そのまま利用開始へ進みません。

### 4-5. 最初の設定を行う

1. ブックが、全員で使う最終の共有場所にあることを確認します。
2. マクロ実行画面から **`InitializeGate`** を選び、一度実行します。
3. 「操作パネル」に「閲覧する」「編集する」「受け渡しファイルを正式保存する」などのボタンが表示されることを確認します。
4. ブックを閉じ、同じ場所から開き直します。

`InitializeGate` は、初期設定をするプログラムの名前です。アプリの種類と正式な保存場所を登録します。毎日の起動時に実行するものではありません。

マクロを実行できない場合は、職場で決められた設定方法を担当者に確認してください。

### 4-6. 本当のデータを入れる前に、一往復試す

1. 「編集する」を押し、Edgeでアプリが開くことを確認します。
2. 「動作確認用」と分かる内容を一つ入力します。
3. 次の「5」の手順で、出力→正式保存→終了まで進めます。
4. ブックを開き直し、「閲覧する」で同じ内容が残っていることを確認します。
5. 別のPCでも同じ正本を開き、一人が編集中の間はもう一人が閲覧だけになることを確認します。
6. 編集していた人がブックを閉じ、次の人が開き直すと編集できることを確認します。

初回の空ブックへ、以前ブラウザで使っていたデータが自動的に移るわけではありません。既存データを引き継ぐ場合は、元データを保全してから、担当者が移行方法を確認します。

準備担当者は、保存失敗などを含む詳しい [実機試験表](docs/acceptance-test.md) も確認してください。

## 5. 普段の使い方【利用者向け】

ここからは、準備と動作確認が済んだブックを使う人向けです。プログラムの編集は必要ありません。

### 5-1. 入力して、保存して、終わる

| 順番 | 操作する画面 | すること | 確認すること |
| --- | --- | --- | --- |
| 1 | 共有フォルダ | 担当者から案内された `MVP4th.xlsm` を開く | 各自のPCにコピーしたブックではなく、全員で使うものか |
| 2 | ブック | **「編集する」** を押す | Edgeで業務画面が開く。ブックは開いたままにする |
| 3 | Edge | 必要な内容を入力する | 編集ダイアログなどを開いた場合は、アプリの確定ボタンで入力を確定する |
| 4 | Edge | 上部の **「保存者名」** に自分の名前を入力する | 空欄ではないか |
| 5 | Edge | **「出力してExcelへ戻る」** を押す | 受け渡し用ファイルがダウンロードされる。まだ正式保存ではない |
| 6 | ブック | 開いたままのブックへ自分で画面を切り替える | ボタン名の「戻る」は、自動で画面が切り替わる保証ではない |
| 7 | ブック | **「受け渡しファイルを正式保存する」** を押す | 見つかったファイルの名前・出力日時・保存者が、今の作業のものか |
| 8 | ブック | 内容が合っていれば、保存の確認に答える | 正式保存を完了した旨のメッセージが出る |
| 9 | ブック | **「終了する」** を押し、終了を確認する | これで次の人が編集できる状態になる。残ったEdgeの作業タブも閉じる |

「ブックへ戻る」は、WindowsのタスクバーでJUST Calcを選ぶなど、いつもの画面切替で構いません。

**終わったかどうかは、Edgeの表示ではなく、ブックの「正式保存しました」という確認で判断します。**

### 5-2. ファイルを選ぶ画面が出たら

通常は、ダウンロードフォルダから今回の受け渡しファイルを探します。見つからない場合などには、自分でファイルを選ぶ画面が出ます。

1. 今回Edgeから出力したファイルを探します。
2. ファイル名は `Excelゲート受け渡し_` で始まり、末尾は `.json` です。
3. Edgeのダウンロード一覧でも、保存先とファイル名を確認できます。
4. そのファイルを選びます。
5. ブックに表示される結果を確認します。

昨日のファイルや、別の人・別のアプリのファイルを、名前だけ変えて使わないでください。以前から使っている普通のJSONバックアップと、Excelゲートの受け渡しJSONは別のものです。

### 5-3. 途中で一度保存し、続けて作業したい

1. Edgeで **「受け渡し用に出力」** を押します。
2. ブックへ戻り、**「受け渡しファイルを正式保存する」** を押します。
3. 「作業途中の内容を正式保存した」旨のメッセージを確認します。
4. ブックを開いたまま、同じEdgeの画面で編集を続けます。
5. 最後は「出力してExcelへ戻る」を使い、もう一度ブックで正式保存して終了します。

| Edgeのボタン | 使う場面 |
| --- | --- |
| 受け渡し用に出力 | 途中まで保存し、このあとも同じ画面で編集を続ける |
| 出力してExcelへ戻る | 今回の編集を終える。出力後はブックで正式保存する |
| 同じファイルを再出力 | 直前と同じ受け渡しファイルをもう一度ダウンロードする |

正式保存が済むまで、途中で出した受け渡しファイルを削除しないでください。出力が正しい順番につながっているか確認する際に使うことがあります。

### 5-4. 見るだけのとき・ほかの人が編集中のとき

1. 同じ共有ブックを開きます。
2. 読み取り専用で開かれた場合は、そのまま閲覧に使います。
3. **「閲覧する」** を押します。
4. Edgeで正式保存済みの内容を確認します。
5. 終わったら、Edgeのタブとブックを閉じます。

閲覧中は内容を変更できません。検索や表示切替など、読むための操作は使えます。

ほかの人が保存しても、いま開いている閲覧画面は自動更新されません。最新を見たいときは、自分の閲覧タブとブックを閉じて、共有ブックから開き直します。

初めて使うブックで、まだ誰も正式保存していない場合は、表示するデータがありません。

### 5-5. 入力を保存せずにやめたい

必要な入力が本当に残っていないか確認してから、ブックの「終了する」を押します。未保存の作業について確認が出た場合、破棄してよいときだけ「保存せずに終了」を選びます。

ブックを閉じたあと、古いEdgeの画面をそのまま次の作業に使わないでください。次回は共有ブックを開き直し、「編集する」から始めます。

## 6. 困ったとき

| 状況 | まずすること |
| --- | --- |
| HTMLを開いたら「起動を停止しました」と出る | 配布フォルダのHTMLを直接開いた場合は閉じ、共有ブックの「編集する」か「閲覧する」から開く。それでも出るなら担当者へ |
| `MVP4th.xlsm` が見つからない | 現在の配布物には完成ブックが入っていません。「4」の組み込み作業が必要です |
| 編集ボタンが使えない／読み取り専用と表示される | ほかの人の編集中、またはフォルダの書込権限不足などが考えられます。まず閲覧を使い、編集者が終了してからブックを開き直す。解決しなければ担当者へ |
| 「入力を確定してから」と案内される | 開いている入力ダイアログや編集欄を確定、またはキャンセルしてから、もう一度出力する |
| Edgeから出力したのに、次回は古い内容になっている | ブック側の正式保存まで完了したか確認する。残った受け渡しファイルを消さず担当者へ相談する |
| 受け渡しファイルが見つからない | Edgeのダウンロード一覧で保存先を確認する。直前の出力が必要なら「同じファイルを再出力」を使う |
| 「正式保存が未完了」と出る／共有フォルダが切れた | ブックと作業画面を閉じず、接続を確認して正式保存ボタンをもう一度押す。解決しなければエラー文を記録して担当者へ |
| 「別のExcel用」「前回の編集作業」などと出る | 別ブック・古い画面・古いJSONの可能性があります。手作業でJSONを直さず、ファイルを残して担当者へ |
| 「初期化済み」と出る | 初期設定は一度だけです。普段は `InitializeGate` を実行せず、操作パネルのボタンを使う |
| JUST CalcでVBA編集や取り込みが見つからない | その製品版で利用できるか未確認です。製品名・版と表示内容を担当者へ伝える |

保存中のエラーが出た場合は、`data` の中身を消したり、ブックを新品で上書きしたりしないでください。復旧に使う情報が入っています。

## 7. 利用者へ配る短い説明

準備が終わったら、次の文章の「ここに実際の場所を書く」を職場の正本の場所に置き換えて配れます。

```text
【このアプリの使い方】

開く場所：ここに実際の場所を書く

1. 共有ブックを開き、「編集する」を押します。
2. Edgeで入力します。ブックは開いたままにしてください。
3. 入力を確定し、保存者名を書きます。
4. 「出力してExcelへ戻る」を押します。
5. ブックへ戻って「受け渡しファイルを正式保存する」を押します。
6. 正式保存できた表示を確認し、「終了する」でブックを閉じます。
7. 残ったEdgeの作業タブも閉じます。

見るだけなら「閲覧する」を使います。
Edgeで出力しただけでは正式保存になりません。
保存エラーが出たときはブックを閉じず、担当者へ連絡してください。
```

詳しい技術資料が必要な担当者は、[HTMLの接続仕様](docs/adapter-guide.md)、[ブック導入手順](docs/install.md)、[障害からの復旧手順](docs/recovery.md) を参照してください。
