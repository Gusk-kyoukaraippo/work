# 終了UI試作の確認状況

A（通常UI）、B（Application.OnTime）、C（VBA待機）の比較用です。3案ともWindows / JUST Calc / Edgeでの実機検証待ちです。

Mac版Excelで10標準モジュールとThisWorkbookをコンパイルし、保存した未初期化ブックのVBAをソースと照合しています。配布ブックの生成時もVBAと共通原本の同一性を検査します。

ブラウザ試験ではfile://の実際の受け取り通知、別作業・古い通知の拒否、待機中の画面を閉じる警告、同じ内容での再試行、受け取り後の案内切り替えを確認します。通知の書き込みは試験用に模擬しています。VBAによるダウンロード検出や共有ロック解除の実証ではありません。

今回の3案に、通常版の過去のWindows実測・保存確認を流用しません。詳細な結果は比較一式の「確認結果.md」、未実施の項目は「実機比較・記録.md」にあります。配布物は検証用で、運用中のブックやdataへ上書きしません。
