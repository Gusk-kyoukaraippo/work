# DXダッシュボード Windows起動設定

この一式は、HTMLの「ブックを開く」から、共有元のブックをJUST Calc／Excelで開くためのものです。ブックのコピーやパスの貼り付けは、通常の起動操作には不要になります。

現在の配布物は**Windows実機検証用**です。Windows・Edge・JUST Calcでの一連の起動は、この開発環境では未確認です。

## 用意するもの

- Windows 10／11、.NET Framework 4.8以降、Microsoft Edge。
- ExcelゲートMVP8thではJUST Calc。通常のExcelブックならMicrosoft Excelも指定できます。
- 配置・初回設定済みのExcelゲートのアプリ一式。ブックだけを移動しません。
- アプリのリンク先を登録し、共有先に配置したDXダッシュボード.html。

利用者PCにNode.js、.NET SDK、追加サーバーは不要です。インターネット接続も起動には使いません。起動プログラムは未署名です。組織の実行制限がある場合は、管理担当者の配布・承認手順に従ってください。

## 導入担当者：先にダッシュボードを登録する

1. 配布ZIPを展開します。運用中のHTMLを空の配布HTMLで上書きしません。
2. 既存のダッシュボードを使っている場合は、旧版でJSONバックアップを取り、新しいHTMLの初期設定後に「JSONから復元」します。復元にはバックアップの内部向けパスワードを使います。
3. ダッシュボードにアプリを登録します。起動方式は「ブックから使う（Excelゲートなど）」、リンク先は配置済みのアプリ名.xlsmです。
4. 全員が同じ共有先を見る場合は `\\server\share\アプリ\引継ぎメモ.xlsm` のような共有パスを推奨します。Windowsの「パスのコピー」を貼り付けられます。HTMLを共有フォルダから開く場合は相対パスも使えます。
5. 「更新したHTMLを出力」で保存し、正式な共有先へ配置します。ダウンロードフォルダにある更新途中のHTMLを次のPC設定に指定しないでください。

配布HTMLには架空のアプリや業務データを登録していません。ブックが未登録のHTMLでは、PC設定に取り込めるアプリもありません。

## 各PCで一度行う設定

1. そのPCを普段使うWindowsユーザーで、`Windows起動設定/初回設定.cmd` を実行します。`DXWorkbookLauncher.exe` をダブルクリックしても同じ設定画面が開きます。
2. 「HTMLを選ぶ」で、正式な共有先にある登録済みDXダッシュボード.htmlを選びます。
3. アプリ名と元ブックの場所が一覧に出ます。ボタンから開けるようにするブックにチェックを付けます。
4. 通常は「Windowsで設定されている表計算ソフトを使う」を選びます。Excelゲートは、.xlsmがJUST Calcで開く関連付けになっている必要があります。
5. 別のソフトが起動する場合は「JUST Calc／Excelを指定する」→「ソフトを選ぶ」で、そのPCに入っているJUST Calc／Excelの実行ファイルを選びます。実行ファイルの場所が分からない場合は導入担当者が設定します。
6. 「このPCに登録」を押します。完了表示を確認し、ダッシュボードをEdgeで開き直します。

設定対象は現在のWindowsユーザーです。同じPCを別のWindowsユーザーで使う場合は、そのユーザーでも設定が必要です。通常は管理者として起動する必要はありませんが、組織のPC設定によっては管理担当者の作業が必要です。

## 毎日の操作

1. ダッシュボードの「ブックを開く」を押します。
2. Edgeに外部アプリの起動確認が出た場合は、内容を確認して開きます。
3. JUST Calc／Excelに共有元のブックが開きます。最初の動作確認では、ブックの保存場所が元の共有パスになっていることを確認します。
4. Excelゲートでは、ブックの「最新CSVで開く」、または「編集する」「閲覧する」を押します。

この起動機能が自動で行うのは**ブックを開くところまで**です。Excelゲートのマクロの実行許可、業務画面の起動、正式保存は従来どおりです。ブック保存型では、Edgeの「入力を終える」→ブックの「保存して終了」→保存完了通知まで確認します。

HTMLは起動用リンクをWindowsへ渡しますが、開いたかどうかを読み戻す仕組みはありません。「起動を要求しました」は保存や起動の成功通知ではありません。

## アプリを追加した・ブックの場所を変えた

ダッシュボードを編集して更新HTMLを共有先に配置した後、各PCで「初回設定.cmd」を再実行し、最新HTMLを選んで登録を更新します。既存の登録一覧を、その設定画面でチェックしたブックの一覧に置き換えます。

アプリ名や説明だけの変更では更新は不要です。新しいアプリID、ブックの場所の変更、別の場所へのダッシュボード移動で相対パスの解決先が変わった場合は更新が必要です。古い登録のまま新しいリンクを押しても、別の場所のブックへ勝手に戻して起動しません。

Excelゲートで初回設定済みのブック自体を移動・改名する場合は、MVP8thの手順に従ってください。この起動設定だけを更新しても、ブック内の正本パス設定は変わりません。

## 開かないとき

| 表示・状態 | 対応 |
| --- | --- |
| このリンクを開くアプリがない／何も起きない | 同じWindowsユーザーで初回設定を実行します。カード下の「開かないとき・初回設定」から手順を確認できます |
| このアプリはこのPCに未登録 | 最新の共有HTMLを選び、該当ブックにチェックを付けて登録し直します |
| ブックの場所が登録時と変わっている | 最新HTMLでPC設定を更新します。以前のブックは自動で開きません |
| 同じファイルのはずなのに場所の変更と判定される | `Z:\...` と `\\server\share\...` のように表記が異なっていないか確認します。ダッシュボードのリンク先を同じUNC共有パスにそろえて登録し直します |
| 共有ブックが見つからない・アクセスできない | 共有先への接続、権限、ファイルの場所を確認します |
| 指定した表計算ソフトが見つからない | 初回設定で実行ファイルを選び直します |
| ExcelゲートなのにMicrosoft Excelが開く | 初回設定でJUST Calcを指定するか、管理担当者がファイルの関連付けを確認します |
| Web URLが登録できない | 元ブックのUNC共有パスをダッシュボードに登録します。Web配信したHTMLでは相対パスもWeb URLになるため、UNCパスが必要です |
| Macで開いたHTMLの相対ブックリンク | 自動起動はWindows専用です。Windowsで正式配置したHTMLを開いてください |

緊急時は「開かないとき・初回設定」→「手動で元ブックを開く」から元パスをコピーできます。旧版の「直接リンクで開く」や「通常のファイルリンクを試す」はブックのダウンロードになるため、今回の画面から削除しました。既にダウンロードされたコピーをExcelゲートの正本として使わないでください。

## Edgeの確認画面について

このセットアップはEdgeのポリシー、マクロの実行許可、SmartScreenを変更しません。確認が省略できるかは職場の設定によります。

Microsoftの `AutoLaunchProtocolsFromOrigins` は、起動用プロトコルと許可したサイトの組み合わせに対して確認省略を設定できます。ただし `file://*` では期待どおり動かないとされています。「常に許可」の設定にもHTTPSの条件があります。完全に確認なしの1クリックを必須とする場合は、社内HTTPSでのダッシュボード配信と、対象サイト・`dx-workbook`だけへの許可設定を管理担当者が検討します。この配布物が自動で許可範囲を広げることはありません。

- [Edgeの外部アプリ起動の設定](https://learn.microsoft.com/en-us/deployedge/microsoft-edge-policies/autolaunchprotocolsfromorigins)
- [「常に許可」の設定](https://learn.microsoft.com/en-us/deployedge/microsoft-edge-policies/externalprotocoldialogshowalwaysopencheckbox)
- [JUST Calc／Excelの関連付け](https://support.justsystems.com/faq/1032/app/servlet/qadoc?QID=058436)

## 設定を解除する

同じWindowsユーザーで `登録を解除.cmd` を実行し、解除を確認します。共有ブックとダッシュボードは変更しません。解除後、`%LOCALAPPDATA%\DXWorkbookLauncher` に残る本体は削除できます。

## 職場PCでの確認記録

検証用のブックで、次を確認してください。

1. Windows・Edge・JUST Calcの版、Windowsユーザー、共有先、実施日を記録する。
2. 設定前のクリック時の表示、初回設定、設定後のクリックを確認する。
3. 正式な共有ブックが開き、コピーを作らず、保存場所が変わっていないことを確認する。
4. 相対パスとUNCパス、日本語・空白を含むファイル名で試す。
5. ブックの場所を変更した検証用リンクが、登録更新まで拒否されることを確認する。
6. 別PCまたは別Windowsユーザーでも設定し、同じ共有元が開くことを確認する。
7. CSV閲覧または入力・正式保存まで、MVP8th側の受け入れ試験を行う。
8. 登録解除後にこの起動リンクが使えなくなることを確認する。

## 管理・開発情報

本体と設定：`%LOCALAPPDATA%\DXWorkbookLauncher`。プロトコル登録：`HKCU\Software\Classes\dx-workbook`。HTML・ブック・データはPC設定処理で書き換えません。

起動リンクはアプリIDと元パスのSHA-256を含みます。起動先はPCに登録した一覧から取得し、リンク側の照合値と一致する場合だけ開きます。リンクに実行コマンドや任意の起動先を指定することはできません。照合値はパス変更の検出用で、パスワードや利用者認証ではありません。

同梱のsourceは実行ファイルのソースです。.NET SDKがある開発PCでは `dotnet build DXWorkbookLauncher.csproj -c Release` で再ビルドできます。利用者PCでのコンパイルは不要です。
