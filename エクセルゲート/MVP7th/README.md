# Excelゲート MVP7th

**Excelゲートは、HTMLの業務画面をJUST CalcのブックからEdgeで開くための、組み込み・導入キットです。** 入力結果をブックへ保存するアプリと、ローカルまたは共有フォルダのCSVを読み取って表示するアプリに対応します。

マクロ入りの共通ブックを同梱しています。導入担当者がブックを作ったり、VBAというマクロのコードを編集したりする必要はありません。自分のHTMLを使う場合は、AIが画面と共通機能を接続し、試験して配布一式を作ります。同梱アプリを試す場合は、完成済みの配布フォルダから始められます。

このREADMEはMVP7thだけで使い始められる案内です。操作を順番に確認したい方には、同じ版の [はじめての組み込みと使い方](はじめての組み込みと使い方.md) も用意しています。

## 二つの使い方

| 方式 | 向いている用途 | 正式なデータの場所 | 日常の操作 |
| --- | --- | --- | --- |
| CSVフォルダ閲覧型 | 別システムが出力したCSVを集計・閲覧する | 登録したフォルダのCSV | ブックの「最新CSVで開く」→ Edgeで確認 |
| ブック保存型 | 進捗管理や引継ぎメモなど、画面で入力・変更する | 共有場所のブック | 「編集する」→ Edgeで入力 →「入力を終える」→ ブックの「保存して終了」 |

方式はアプリの組み込み時に決めます。利用者が毎回選ぶ操作ではありません。CSV閲覧型では元CSVを変更せず、集計結果を保存する操作もありません。ブック保存型では、**Edgeから保存用ファイルを出しただけでは正式保存は完了せず、ブック側の保存完了通知が必要です。**

## 必要な環境

- WindowsのPC、JUST Calc、Microsoft Edge。JUST Calcでブックのマクロを実行できることが必要です。
- 利用者全員がアクセスできる共有フォルダ。初回設定にはブックの保存権限、ブック保存型の編集にはブックと同梱のdataフォルダへの書き込み権限が必要です。
- CSV閲覧型では、CSVがあるローカルまたは共有フォルダへの読み取り権限と、その場所の絶対パス。

CSV読込先には、ローカルの `C:\業務データ\CSV`、共有の `\\server\share\CSV`、割り当て済みの `Z:\CSV` を使えます。エクスプローラーの「パスのコピー」で付く外側の引用符、前後の空白、末尾の区切り、`/` 区切りも受け付けます。相対パス（`CSV` や `C:CSV`）、URL、`%USERPROFILE%` などの省略表記は使わず、フォルダの絶対パスを入力します。

設定はブック全体で共通です。ローカルパスやドライブ文字は、開いたPCでの場所を読みます。同じ `C:\CSV` でもPCごとに別のフォルダです。全員が同じCSVを見る場合はUNCパスをおすすめします。共有ブックも全員が同じUNCパスから開きます。

日常の利用者PCにNode.jsや追加サーバーは不要です。Excelゲートの標準処理はAIへ問い合わせません。AIは組み込み・改修・試験・結果の整理を担当します。元のHTMLに外部サービスへの依存がある場合は、組み込み時に確認します。

## 同梱アプリを初めて試す

現在の配布物は **実機検証用** です。まず業務運用と分けた検証場所・検証用データで進めます。

1. 上の表から使いたいアプリのZIPを選び、Windowsで展開します。ZIPの中から直接ブックを開きません。
2. 展開したアプリのフォルダを、全員がアクセスできる新しい共有場所へ一式で置きます。MVP7th.xlsm、gate.config.json、runtime、sharedを元の位置関係で保ちます。
3. 配置したMVP7th.xlsmを、編集可能な状態でJUST Calcから開きます。マクロは職場の運用に沿って実行できる状態にします。
4. 「初回設定」を押し、表示されたブックの場所が今後使う共有場所であることを確認して進めます。
5. CSV閲覧型では、CSV読込先の入力欄に実際のフォルダの絶対パスを入力します。ブックを置いた場所とCSVの場所は別でも構いません。ブック保存型ではCSV読込先の登録はありません。
6. 完了通知を確認します。CSV閲覧型なら「最新CSVで開く」、ブック保存型なら「編集する」「閲覧する」などのボタンが表示されます。

初回設定は配置場所とアプリ情報をブックに保存する操作です。完了後にブックだけ移動・改名せず、配置変更が必要なら導入担当者へ相談します。

## 毎日の操作

### CSVを閲覧する

共有ブックを開き、「最新CSVで開く」を押します。登録フォルダ直下のCSVを取得し、Edgeで表示します。画面の読込日時・対象ファイルを確認してから、対象月や病床区分を切り替えます。日常のフォルダ選択、保存者名の入力、保存操作はありません。

CSVが更新されたら、出力完了後にもう一度ブックの「最新CSVで開く」を押します。開いたタブの自動更新や、Edgeの再読み込みによるCSV再取得は行いません。新しい画面の読込日時を確認し、古いタブは閉じます。終了時は使ったEdgeタブとブックを閉じます。

初回設定済みなら、ブックが読み取り専用でもCSVを閲覧できます。読込先を変える場合だけ、編集可能な状態でブックを開き、「読込先の設定」で新しいフォルダの絶対パスを登録します。キャンセルでは変更しません。

### 入力してブックへ保存する

1. 共有ブックの「編集する」を押し、ブックを開いたままEdgeで入力します。保存者名の欄がある場合は入力します。
2. 作業が終わったらEdgeの「入力を終える」を押し、保存用ファイルのダウンロード完了を確認します。これはJSONというテキスト形式の受け渡しファイルです。
3. 開いているブックへ戻り、「保存して終了」を押します。ブックが今回のファイルを確認して正式保存します。
4. ブックの保存完了通知を確認します。ブックが閉じたら、残っているEdgeの作業タブも閉じます。

途中で保存して作業を続ける場合は、Edgeの「途中保存・再出力」を開いて「途中保存の準備」→ ダウンロード完了 → ブックの「保存して続ける」です。保存完了後、同じEdge画面で続けます。JUST Calcの通常の保存ボタンやCtrl+Sだけでは、Edgeの入力内容を取り込めません。

見るだけの場合は「閲覧する」を使います。表示するのは正式保存された内容で、他の人の入力途中の内容ではありません。最新の保存結果を見るときは共有ブックと閲覧画面を開き直します。編集は、一人が保存して閉じてから交代する運用です。

## 自分のHTMLを組み込む

MVP7thフォルダ全体と元HTMLを、ファイルの読み書き・コマンド実行・ブラウザ試験ができるAIへ渡します。画像やCSSなどがあれば、元の位置関係を保ったアプリ専用フォルダごと渡します。依頼文は、例えば次のとおりです。

> このHTMLをExcelゲートMVP7thへ組み込んでください。同梱のAI_START_HERE.mdを読み、完成済みの共通ブックを使ってください。用途は「共有フォルダのCSVを読む閲覧型」です。元の画面と集計処理を保ち、元HTMLを保管して、改修・試験・配布フォルダとZIPの作成まで進めてください。未実施の職場PCでの確認は未確認として記録してください。

入力結果を保存する用途なら、用途を「入力結果をブックへ保存する型」に置き換えます。AIが用意した画面で、いつもの表示・検索・計算・入力を確認し、できあがった一式を上の初回設定手順で試します。利用者が設定JSONやマクロを手編集する必要はありません。

## CSV読込の範囲

CSVの解析・集計は各アプリが担当します。Excelゲートはファイル名・元のバイト列・更新日時・読込日時を画面へ渡します。任意のCSVを、すべてのアプリで集計できるわけではありません。

地ケア版はUTF-8／Shift_JISの統合CSVと、対象月の「病棟別人数分布表」「地ケアマスタ」を組み合わせる形式に対応します。「読込内容を確認」で対象ファイルと不足を確認できます。列やファイル名の詳細は、同梱の [CSV形式](apps/community-care/CSV形式.md) にあります。

登録フォルダの直下のみを読み、サブフォルダは探索しません。上限は1,000ファイル、CSVの合計50MiBです。空フォルダや不足した月・指標は「データなし」とし、デモ値や過去の値では補いません。未対応CSVは名前を示して対象外にします。接続・権限・不正データなどの異常は理由を表示して停止します。読込中のファイル一覧・サイズ・更新日時の変化も停止の対象なので、CSVの出力処理が終わってから開いてください。

CSVや集計結果をブックへ保存せず、元CSVも変更しません。起動用の一時ファイルはPC内に作成し、ブック終了時に削除を試みます。強制終了時には一時ファイルが残る場合があります。

## 困ったときと確認状況

| 状況 | 最初にすること |
| --- | --- |
| ボタンを押しても動かない | JUST Calcで開いているか、マクロが実行できる状態かを確認し、案内を導入担当者へ伝えます |
| 画面や設定が見つからない | アプリ一式を展開したか、ブックだけを移動していないかを確認します |
| CSVが読めない／古い画面のまま | フォルダのパス・接続・読み取り権限・出力完了を確認し、ブックから開き直します |
| 保存に失敗した | ブックとEdgeを閉じず、エラー文と直前の操作を伝えます。受け渡しファイルとdataを残します |

本体・アプリ・導入先の確認がそろってから業務利用を開始します。「実機検証用」は職場PCで試す段階、「配布可能」は本体とアプリの対象環境での確認済み、「利用開始可能」は配置した共有場所での確認も済んだ状態です。

MVP7thの本体・共通JavaScript・配布設定は0.7.1です。自動試験149件、Mac版Excelでのコンパイル・初期パネル生成、完成ブックとVBAソースの照合は確認済みです。**Windows・JUST Calc・Edge、実際の共有先、複数PCでの受け入れは未実測**です。実施した操作・PC・ソフトの版・結果を記録し、未実施は未実施のまま残します。

詳細が必要な場合は、同梱の [実機確認](docs/acceptance-test.md)、[検証記録](docs/verification.md)、[保存失敗時の復旧](docs/recovery.md)、[AI作業の入口](AI_START_HERE.md) を使います。更新時は、運用中のブックやdataを新品で上書きせず、組み込み記録と新しいHTMLをAIへ渡して同じアプリとして更新を依頼します。
