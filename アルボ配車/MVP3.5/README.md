# ALBO 配車支援 MVP 3.5

`MVP3.5/index.html`は、ブラウザで直接開ける単体HTML版の配車・訪問日程調整ツールです。実行時のサーバーやインターネット接続は不要です。

MVP 3.5では、従来の配車候補生成に加えて「訪問日程調整」を実装しています。

- A.csvの訪問先はAルートに固定
- B.csvの訪問先はBルートに固定
- C.csvは任意。入力した場合だけ各訪問先をAまたはBへ自動配分
- A/Bとも太田町366を発着地として訪問順を再作成
- 道路に沿った合計距離を優先しながら、A/Bの距離差も評価
- 結果を地図・訪問順一覧で確認し、CSVで出力

## 起動

1. `MVP3.5/index.html`をダブルクリックして、Chrome、Edge、Safariなどで開きます。
2. 初回の道路データ展開が完了するまで待ちます。
3. 起動時は「訪問日程調整」が開きます。A.csvとB.csvを選択します。追加訪問先がある場合だけC.csvも選択します。
4. 「A/Bへ割り振ってルートを再作成」を押し、結果を確認・出力します。
5. 従来機能は「通常の配車候補」タブへ切り替えて使用します。

## 訪問日程調整CSV

3ファイルとも同じ形式です。A.csvとB.csvは必須、C.csvは任意です。最低限「住所」列があれば読み込めます。

```csv
訪問先ID,訪問先名,住所,緯度,経度,座標情報元,座標取得時住所,座標代表住所
V001,訪問先A,群馬県伊勢崎市太田町366,,,,,
V002,訪問先B,群馬県伊勢崎市曲輪町,36.324218,139.190602,CSV座標,群馬県伊勢崎市曲輪町,
```

- `訪問先ID`、`訪問先名`は任意です。空欄時は自動採番・自動命名します。
- 緯度・経度は任意です。空欄時は内蔵住所データから取得可能な代表点を使います。
- 緯度・経度の片方だけを入力した行はエラーにします。
- A/B/C合計32件までです。A.csvとB.csvには1件以上の訪問先が必要です。C.csvは未選択でも生成できます。
- 同じ訪問先を重複させず、Aの既存先はA、Bの既存先はBに必ず残します。
- Cは全件をA/Bのどちらか一方へ割り振ります。
- 画面の「共通ひな形」から入力ひな形を出力できます。
- 確認用ファイルは[`visit-samples`](visit-samples/)にあります。

最適化は、Cがある場合はCの並びを変えた複数候補を作り、ルート内の訪問順変更、Cのルート間移動、C同士の交換を反復します。Cがない場合はA/Bそれぞれの訪問順だけを最適化します。評価値はA/Bの合計道路距離を主とし、片方だけが極端に長くならないよう距離差を加味します。

## 通常の配車候補

1. 「通常の配車候補」タブへ切り替えます。
2. 「当日利用者CSV」を選択します。実データがない場合は「29人架空デモ」または「模擬データ2」で操作できます。
3. 必要に応じて過去配車CSVを選択します。
4. 地図上で住所位置を確認し、必要な地点は手動で補正します。
5. 「配車候補を生成する」を押し、最大5案を比較します。
6. 採用候補をCSVまたは完全JSONで出力します。

## 当日利用者CSV

```csv
利用者ID,利用者名,住所,車いす利用,車いす代替乗車可,ミラー折り畳み必須,緯度,経度,座標情報元,座標取得時住所,座標代表住所,照合住所,住所一致レベル,未一致部分,住所情報元
U001,利用者A,群馬県伊勢崎市太田町366,いいえ,はい,いいえ,,,,,,,,,
U002,利用者B,群馬県伊勢崎市曲輪町,はい,いいえ,はい,36.324218,139.190602,現地確認,群馬県伊勢崎市曲輪町,群馬県伊勢崎市曲輪町,,,,
```

- 最大32人です。
- CSVに含まれる人を全員配車します。利用者の選定は行いません。
- `車いす利用`、`車いす代替乗車可`、`ミラー折り畳み必須`は必須です。各行に「はい」または「いいえ」を入力してください。
- 緯度・経度は任意です。空欄の場合は、内蔵した地番・街区・町字代表点から最も細かい取得可能な座標を使います。
- `座標情報元`は任意です。手動入力や別データ由来の座標を保持できます。
- `座標取得時住所`から`住所情報元`までは監査用の任意列です。画面から出力した「座標付きCSV」に自動で記録されます。
- `座標取得時住所`と現在の`住所`が異なる場合は、表記ゆれを正規化したうえで古い座標と判定し、配車計算を止めます。
- `座標代表住所`は、その座標が実際に表す地番・街区・町字を記録します。不明な旧データは空欄のままとし、推定で完全一致にしません。
- UTF-8とShift_JISに対応しています。

画面の「CSVひな形」から同じ形式を出力できます。

### 模擬データ2

画面の「模擬データ2」は、以前の座標付きCSVにあった27人分の住所をそのまま使った確認データです。

- 氏名は`模擬利用者01〜27`へ匿名化
- 車いす利用者を10人に仮設定
- 歩行可能者のうち6人を車いす代替乗車可に仮設定
- ミラー折り畳み必須は全員「いいえ」
- 8人はデジタル庁ABRの地番・枝番代表点、1人は住居表示の街区代表点を使用
- `M2-008`の13街区には公的データ上の代表点が複数あるため、画面で複数候補の警告を表示
- 残り18人は国土地理院住所検索の番地代表点を使用
- `M2-025`もABRで`田中島町1459番地18`まで照合でき、地番代表点を付与
- 過去配車履歴は付けず、住所と車両条件を中心に評価

編集可能なCSVは`MVP3.5/mock-data-2.csv`です。

住所位置は配車前の地図で確認できます。画面に「入力住所」「照合住所」「一致範囲」「未一致部分」「座標情報元」を別々に表示します。必要に応じて地図クリックで手動補正し、その結果を座標付きCSVとして出力できます。

## 住所精度

伊勢崎市の公的住所データを単体HTMLに内蔵しています。

- 地番文字情報: 288,962件。地番・枝番まで照合
- 座標付き地番: 71,895件。取得できる場合はABR地番代表点を使用
- 住居表示の街区: 200件。街区番号まで照合し、街区代表点を使用
- 町字・丁目: 134地域の代表点を内蔵
- 建物名・棟・部屋番号は文字として保持しますが、公的データで照合できない部分は「未一致部分」として表示
- 伊勢崎市の住居番号（〇番〇号の「号」）データはABRにないため、住居表示地区は街区まで

データは[デジタル庁アドレス・ベース・レジストリ](https://www.digital.go.jp/policies/base_registry_address)をビルド時に取得し、オフライン照合用に圧縮しています。現時点で町字の文字情報以外の街区・地番等は試験公開データです。地番や街区の代表点は個別建物や玄関を表すものではありません。安全な駐車位置は今回の対象外です。

## 過去配車CSV

```csv
日付,便,利用者ID,車両番号,座席区分,訪問順
2026-06-01,迎え,U001,10,通常座席,1
2026-06-01,迎え,U002,10,車いす枠,2
```

履歴は任意です。読み込んだ場合は、過去に同乗した組み合わせと利用車両を候補評価に使います。履歴がない場合も道路距離と車両条件から生成できます。

## 実装済みの制約

- 10〜14号車: 通常4席、車いす2枠
- 15号車: 通常1席＋車いす4枠、または通常4席＋車いす2枠
- 車いす利用者は車いす枠のみ
- 歩行可能者の車いす枠利用は、本人が許容し、配車成立に必要な最少人数だけ
- ミラー折り畳み必須の利用者は13号車または14号車
- 同じ利用者の重複割当を禁止
- CSVに含まれる全員を必ず割当
- 不要な車両は未使用にできる

## 地図と経路

- 発着地点: 群馬県伊勢崎市太田町366
- 伊勢崎市と周辺約2kmのOpenStreetMap道路を内蔵
- 216,933道路地点、51,465道路線、478,964有向辺
- 一方通行を反映
- 住宅道路、service、trackを含む
- 利用者地点は、発着地と往復可能で、motorway・track・privateでない最寄りの道路地点へ接続

経路は検討用の概算です。通行止め、時間帯規制、右左折禁止、車幅・高さ、私道通行可否は完全には保証しません。安全な駐車位置は今回のデータモデルに含めません。60分目標、渋滞、乗降時間も現段階では評価しません。

道路データは© OpenStreetMap contributors、ODbL 1.0です。

## 開発・再生成

次のコマンドはプロジェクトのルートフォルダで実行します。

```sh
node scripts/test-mvp-three-five-core.cjs
node scripts/test-mvp-third-road.mjs
node scripts/build-mvp-three-five-html.mjs
node scripts/test-mvp-three-five-build.mjs
```

編集元は次の3ファイルです。

- `src/mvp_three_five.template.html`
- `src/mvp-three-five-core.js`
- `src/mvp-three-five-app.js`

道路を再取得する場合は、ネットワーク接続環境で次を実行します。

```sh
node scripts/build-isesaki-road-network.mjs
```

ABR住所データを最新化する場合は次を実行し、その後に単体HTMLを再ビルドします。

```sh
node scripts/build-isesaki-abr-address-points.mjs
node scripts/build-mvp-three-five-html.mjs
```
