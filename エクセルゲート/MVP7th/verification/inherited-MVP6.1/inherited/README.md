# 引き継いだ過去の記録

このフォルダは、MVP6thで実施した検証と本人報告の原記録です。過去に実行したことと、MVP6.1で今回確認したことを分けるため、内容をそのまま保管しています。

JSONやログにある絶対パス・配布先は、当時の作業環境を示します。過去の作業用ブックや全配布物を、このキットに重複して入れているわけではありません。現在の作業場所をそれらのパスから決めないでください。

今使う原本は `workbook/MVP6th.xlsm`、新しい試験と照合の集計は [final-summary.json](../final-summary.json)、本体とアプリの引継ぎ照合は [inheritance.json](../inheritance.json) にあります。
