# MVP4.2 実装メモ

## 方針

MVP4.2は `file://` 直接起動を前提に、`../data/` のCSVを相対パスで読みに行く。  
`files.json` やサーバー側の一覧取得は使わない。

## 配置

```text
地ケア/
├── MVP4.2/
│   └── index.html
└── data/
    └── *.csv
```

## 読み込み動作

1. 起動時に直近18ヶ月分の月キーを作る
2. 命名規則から `../data/ファイル名.csv` の候補を作る
3. `fetch()` で候補CSVを読む
4. 対象CSV3種が揃った月だけ読み込む
5. 相対読み込みに失敗した場合は、ドラッグ＆ドロップへ誘導する

## 注意点

`file://` 直接起動で `fetch("../data/...")` が許可されるかはブラウザに依存する。  
そのため、相対読み込みを試すが、失敗時のドラッグ＆ドロップ経路は残す。

## 検証

- HTTP配信では相対パス候補から21CSVを取得し、`202508` から `202602` まで7ヶ月分を読み込み確認済み
- `file://` 直接起動ではブラウザ依存のため、環境で実機確認が必要
