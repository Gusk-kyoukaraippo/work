# 配置と初回設定

**AIが用意したアプリ別フォルダ一式を使います。** マクロ入りの `MVP6th.xlsm` は同梱済みです。VBAの編集やブックの組み立ては行いません。

## 置く場所を決める

「実機検証用」と案内された一式は、業務データのない新しい検証場所で使います。「配布可能」と案内されたら、実際の共有場所で導入先の確認へ進みます。どちらも初回設定の操作は同じです。

利用するPCはWindows版JUST CalcとEdge、置き場所は全員が読み書きできる共有フォルダです。例は `\\server\業務\進捗ボード`。全員が同じ共有場所を開くようにします。マクロは職場で認められた方法で実行します。

## 一式を置き、初回設定する

1. ZIPを受け取った場合は「すべて展開」で取り出します。
2. アプリのフォルダ一式を、使う共有場所へ置きます。AIがアクセスできれば配置を依頼できます。
3. そのフォルダ内の **MVP6th.xlsm** をJUST Calcで開きます。
4. **「初回設定」**を押します。表示された登録先が、今置いた場所であることを確認して「はい」を選びます。
5. 完了の案内が出て、**「編集する」「閲覧する」**などのボタンに変わったことを確認します。

初回設定は、置いたコピーに共有場所とアプリの情報を登録する処理です。キットの `workbook` にある共通原本では実行しません。既に初回設定済みのブックでは、もう一度行う必要はありません。

## 保存と交代を確認する

[実機での確認](acceptance-test.md) に沿って、一台で保存・開き直し・閲覧・途中保存を確認します。二台がそろったら、同時編集の防止と編集交代を確認します。二台の確認は後日に回せますが、その間は未実施のままです。

操作結果と表示された内容をAIへ伝えてください。AIがPCやソフトの版、共有場所、残りの本体試験を整理し、利用開始できるかを案内します。結果の記録だけを追加するために、ブックを作り直すことはありません。

「利用開始可能」になったら、利用者に同じ共有ブックの場所、[使い方](user-guide.md)、困ったときの連絡先を伝えます。

## 配置後に変えないこと

ブックやHTMLだけを取り出したり、各自のデスクトップへコピーして使ったりしないでください。**利用中のブックと `data` の上に、新しい配布物を重ねないでください。**

共有場所・アプリ・本体・対象ソフトの版を変えるときは、保存データを残したまま進める方法をAIへ相談します。MVP5thからの保存データ自動移行は含みません。
