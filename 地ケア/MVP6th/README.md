# 病棟別 算定基準モニター MVP6th

MVP5.1の4病棟一覧に、患者単位の仮配置を試せる「シミュレーション」モードを追加したスタンドアロンHTMLです。

## 目的

- 一覧モードで現在の月次実績と算定判定値を確認する
- 未達または確認したい指標を1つ選び、その指標に対する患者ごとの数値影響を確認する
- 患者を別病棟へ仮移動し、移動元・移動先を含む4病棟の月末予測を比較する

候補表示は医療上の配床推薦ではありません。病棟適応、治療必要性、病室条件、空床運用を別途確認し、人が最終判断します。

## 起動

`index.html` をブラウザで直接開きます。外部ライブラリ、Webサーバー、外部通信は使用しません。

MVP5.1と同じく、CSVファイル／フォルダのドロップ、複数ファイル選択、File System Access API対応ブラウザでの自動読込みフォルダ設定を利用できます。

## 一覧モード

MVP5.1の次の機能を維持しています。

- 3F急性期、5F回復期、6F回復期、6F地ケアの横断比較
- 当月速報と直近3か月・6か月の算定判定値
- 基準未達指標、基準値、基準差
- 病棟別詳細と月別推移
- 統合CSVと既存地ケアCSVの読込み

未達指標の「この指標でシミュレーション」から、対象指標を引き継いでシミュレーションモードへ移動できます。

## シミュレーションモード

1. 注目する病棟・指標を選択する
2. 改善方向・ほぼ中立・悪化方向・算出不可に分類された患者を確認する
3. 患者カードを移動先病棟へドラッグする
4. 4病棟の「移動なし」「仮移動後」「差分」「基準差」を確認する
5. 「試算を戻す」で解除する

タッチ操作とキーボード操作では、患者を選択して移動先ボタンを使用できます。同時に試算できる患者は1人だけです。仮移動はブラウザメモリ上だけで処理され、CSVや一覧モードの実績値を書き換えません。

候補分類は選択した1指標だけで行います。複数指標を合算した総合点や自動推薦はありません。

## 入力CSV

### 月次指標

MVP5.1と同じ統合CSVを使用できます。

```text
病床区分,対象月,指標コード,分子,分母,値,基準日
```

シミュレーションには分子・分母が必要です。値だけの指標は一覧へ表示できますが、患者差分を正確に再計算できないため「試算不可」になります。

### 病棟設定CSV

サンプル: `病棟設定_サンプル.csv`

```text
基準日,病床区分,表示名,稼働可能病床数,在棟患者数,受入可否,救急患者応需係数
```

- `病床区分`: `acute3f`, `recovery5f`, `recovery6f`, `community6f`
- `救急患者応需係数`: パーセントポイントで入力。急性期以外は0

### 患者属性CSV

サンプル: `患者シミュレーション属性_サンプル.csv`

主な列は次のとおりです。

- 識別: 基準日、患者ID、氏名、患者区分、現在病棟
- 日付: 入棟日、配床予定日、予想退院日
- 必要度: 必要度評価対象、急性期必要度①・②、地ケア必要度
- 回復期: 回復期新規入棟対象、回復期重症、回復期退院実績見込み
- 入退院: 入院元、予定外緊急、予想退院先、退院集計除外

真偽項目は `1/0`、`○/×`、`該当/非該当` に対応します。不明は空欄または `不明` とします。不明値は0として扱わず、影響する指標を「試算不可」にします。

患者区分は `在院` または `未配床`、現在病棟は4病棟コードまたは `unassigned` を使用します。

## CSV統合規則

- 患者IDは数値変換せず文字列で保持する
- データ種別ごとに最も新しい基準日のスナップショットを使用する
- 地ケアマスタの最新ファイルは6F地ケア患者一覧の補助入力として使用する
- 患者属性CSVは患者IDで正本患者へ結合し、不足するシミュレーション属性を補う
- 同一ファイル内の患者ID重複、病棟設定重複、解釈できない病棟コードを画面へ警告する
- 後日追加する正本CSVは、共通患者モデルへ変換するアダプターを追加して対応する

## 月末予測の考え方

- 読込データの基準日翌日から選択月末までを予測期間とする
- 移動なしでは現在病棟を継続、仮移動では選択患者の将来寄与だけを移動先へ付け替える
- 必要度は予測期間の患者延べ日数を分子・分母へ加える
- 回復期重症、自宅等からの入院、緊急入院は月内の新規配床イベントへ反映する
- 退院系指標と急性期平均在院日数は、予想退院日が選択月内の場合だけ反映する
- 直近3か月・6か月値は、読込済みの分子・分母に月末までの予測寄与を加えて再計算する
- 月末稼働率は、病棟設定の現在患者数から既知の退院予定と仮移動を反映する

## 対象外

- 医療上の病棟適応判定
- 複数患者の累積配置
- シナリオ保存
- 7日間の日次予測
- 正本CSVや電子カルテへの書戻し
- 施設基準適合の証明

患者情報とCSVは端末内だけで処理され、外部へ送信されません。
