# 美原記念病院 リハビリテーション部 物品管理 — 終了UI試作の変更点

- Edgeの主ボタンを「アプリを終了して保存作業に移る」、ブック側を「保存して閉じる」に変更しました。業務HTMLと業務データ形式は維持しています。
- Aはブックの保存後に、Edgeを閉じてからOKを押す順番を案内します。
- BはApplication.OnTime、CはDoEventsを含むVBA待機で、終了データを受け取る準備をします。Cの短い待機にはWindows標準のSleepを使います。
- B・Cは今回のデータと未保存の途中出力のつながりを検証し、控えを読み直してからEdgeへ準備完了を知らせます。ブックの正式保存は「保存して閉じる」で行います。
- 受け取り待ち、時間がかかった場合の再試行、準備中断後の再開を追加しました。保存失敗時は控えを残します。既存の保存・履歴・再開処理を利用します。

Windows / JUST Calc / Edgeでの3案の成否・待ち時間・共有ロック解除は、実機比較で判断します。[確認状況](確認状況.md)
