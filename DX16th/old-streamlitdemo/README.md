# 溶材会議 注文量決定支援アプリ（Phase 1）

来月（注文量決定）タブ、今月（現状把握）タブ、先月（振り返り）タブ、履歴（これまで）タブ、6ヶ月LT品タブで、6品目のダミーデータを使って注文量の入力・リスク判定・予測在庫の表示を行うデモアプリです。

## 構成

- `app.py`: Streamlitアプリ本体
- `data/master.py`: 品目マスター（6品目）
- `data/sample_data.py`: 月次ダミーデータ（今月・来月）
- `utils/calculations.py`: 推奨レンジ・リスク判定ロジック
- `requirements.txt`: 依存ライブラリ

## 起動方法

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Streamlit Cloud デプロイ手順

1. GitHubに本ディレクトリをプッシュ
2. Streamlit Cloudで新規アプリ作成
3. リポジトリ/ブランチ/`app.py` を指定してデプロイ

## 使い方

- 「来月」タブで各品目の注文量を入力
- 入力値に応じて予測在庫とリスク（欠品リスク/過剰在庫/適正）がリアルタイムに更新されます
- 推奨レンジの中央値がデフォルト入力値になっています
- 「今月」タブでリスクサマリ、6ヶ月LT品の強調表示、底打ち月を確認できます
- 「先月」タブで予測vs実績の誤差サマリ、ランキング、メモを確認できます
- 「履歴」タブで過去6ヶ月の出庫量・在庫量の推移と異常値を確認できます
- 「6ヶ月LT品」タブで特殊鋼材の長期在庫推移と発注期限を確認できます
