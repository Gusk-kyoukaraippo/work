# はじめての組み込みと使い方 — Excelゲート MVP7th

このマニュアルは、Excelゲートを初めて使う導入担当者・利用者向けです。仕組みの説明から、アプリの準備、共有場所への配置、初回設定、毎日の操作まで、この文書で順番に確認できます。過去の版や以前の会話を読む必要はありません。

## 1. Excelゲートとは

Excelゲートは、**JUST Calcで開くブックを入口にして、EdgeでHTMLの業務画面を使う仕組み**です。HTMLはブラウザに表示する画面のファイルです。ブックには、画面の起動やデータの受け渡しを行う「マクロ」が入っています。

マクロ入りブックはキットに入っているので、作成やプログラミングから始める必要はありません。自分のHTMLを組み込む場合、AIが元HTMLのコピーを改修し、設定と試験を行います。導入担当者は用途を伝え、業務画面を確認し、職場のPCで操作を試します。

| 方式 | すること | 正式なデータの場所 | 代表的なアプリ |
| --- | --- | --- | --- |
| CSVフォルダ閲覧型 | ローカルまたは共有フォルダのCSVを読み、集計結果を表示する | 元のCSV。表示結果を別に保存する操作はありません | 地ケア・病床機能指標モニター |
| ブック保存型 | 画面で入力・変更し、結果を共有ブックに保存する | 共有ブック。保存時の受け渡しファイルと復旧用記録も残します | 進捗ボード、改善ワークフロー、引継ぎメモ |

方式はアプリを準備するときに決めます。CSV閲覧型には「入力を終える」や正式保存の操作はありません。日常の利用でAIへ問い合わせる処理はなく、利用者PCにNode.jsや追加サーバーを入れる必要もありません。元HTMLが外部サービスを使う場合は、組み込み時にその依存関係をAIが確認します。

## 2. 自分の始め方を選ぶ

| 今の状況 | 始める場所 |
| --- | --- |
| 同梱の地ケアアプリを試したい | deliverables/community-care.zipを使い、4章の準備から進みます |
| 同梱の入力・保存アプリを試したい | deliverables内のprogress-board.zip、workflow-studio.zip、handoff-notes.zipのいずれかを選び、4章へ進みます |
| 自分のHTMLをExcelゲートで使いたい | 次の3章で、AIに組み込みを依頼します |
| 設定済みの共有ブックを案内された | 初回設定をやり直さず、CSV閲覧は7章、入力・保存は8章を使います |

現在、同梱アプリは「実機検証用」です。最初は業務運用と分けた場所・検証用データで試し、職場のPCと実際の共有先での確認後に利用を開始します。確認の内容は9章にあります。

## 3. 自分のHTMLを使う場合：AIに組み込みを依頼する

**MVP7thフォルダ全体**と元HTMLを、AIが読める場所に置きます。画像、CSS、JavaScriptなどの付属ファイルがあれば、元の位置関係を保ったアプリ専用フォルダごと渡します。AIには、ファイルの読み書き・コマンド実行・ブラウザ試験ができる作業環境が必要です。

CSVを読むアプリなら、例えば次のように依頼します。

> このHTMLをExcelゲートMVP7thのCSVフォルダ閲覧型に組み込んでください。MVP7th内のAI_START_HERE.mdを読み、完成済みの共通ブックを使ってください。元HTMLを保管し、画面とCSV集計を保ったコピーを改修・試験して、配布フォルダとZIPを作ってください。不足データをデモ値で補わず、職場PCで未確認の項目は未確認として記録してください。

入力内容を保存するアプリなら、次のように依頼できます。

> このHTMLをExcelゲートMVP7thのブック保存型に組み込んでください。MVP7th内のAI_START_HERE.mdを読み、完成済みの共通ブックを使ってください。元HTMLを保管し、画面と保存する内容を保ったコピーを改修・試験して、配布フォルダとZIPを作ってください。職場PCで未確認の項目は未確認として記録してください。

AIが案内する確認画面で、対象月の切替、検索、計算、入力・変更など、普段の業務操作を試します。「どの操作をして、何が表示され、どうなるはずだったか」を伝えると修正しやすくなります。コード、設定ファイル、照合用の長い文字列を自分で編集する必要はありません。

AIから受け取るのは、MVP7th.xlsmと画面・設定・案内をまとめたアプリ専用フォルダまたはZIPです。HTMLだけを直接開く手順ではなく、次の配置と初回設定へ進みます。

## 4. 職場で試すために準備するもの

| 用意するもの | 確認すること |
| --- | --- |
| WindowsのPC、JUST Calc、Microsoft Edge | JUST Calcでマクロ入りブックを実行できること。ソフトの版も控えます |
| アプリの配布ZIPまたは配布フォルダ | ブックだけでなく、画面・設定を含む一式であること |
| ブックを置く共有場所 | 初回設定をする人がブックを保存でき、利用者が同じ場所を開けること |
| CSV閲覧型：CSVの場所 | 利用者がCSVを読めること。出力先の正確な絶対パスを確認します |
| ブック保存型：書き込み権限 | 編集者がブックと配布フォルダ内のdataに書き込めること |

「UNCパス」は共有場所の住所にあたるもので、サーバー名・共有名・フォルダ名を指定します。次は架空の例です。

    アプリ一式を置く場所： \\server\share\ExcelGate\community-care
    CSVを読む場所：        \\server\share\CSV\地ケア

この二つの場所は別でも構いません。アプリの配置場所はブック・画面・設定を置く場所、CSV読込先は業務システムが出力したCSVを置く場所です。例のまま入力せず、職場の実際のパスに置き換えます。分からない場合は共有フォルダの管理担当者へ確認します。

CSV読込先には、ローカルの `C:\業務データ\CSV`、共有の `\\server\share\CSV`、割り当て済みの `Z:\CSV` を使えます。エクスプローラーの「パスのコピー」で付く外側の引用符、前後の空白、末尾の区切り、`/` 区切りも受け付けます。相対パス（`CSV` や `C:CSV`）、URL、`%USERPROFILE%` などの省略表記は使わず、フォルダの絶対パスを入力します。

設定はブック全体で共通です。ローカルパスやドライブ文字は、開いたPCでの場所を読みます。同じ `C:\CSV` でもPCごとに別のフォルダです。全員が同じCSVを見る場合はUNCパスをおすすめします。共有ブックも全員が同じUNCパスから開きます。

## 5. 配布フォルダを共有場所へ置く

1. ZIPを受け取った場合はWindowsで展開します。ZIPを開いた中から直接ブックを起動しません。
2. 展開したアプリのフォルダを、新しい共有場所へ丸ごと置きます。運用中の別アプリやブックに重ねません。
3. フォルダの中に、少なくとも次のファイルとフォルダがあることを確認します。

```text
community-care/             ← 地ケアの場合のフォルダ名
  MVP7th.xlsm               ← 利用者が開くマクロ入りブック
  gate.config.json          ← アプリの設定。手編集しません
  runtime/                  ← 業務画面と起動に必要なファイル
  shared/                   ← 共通の案内など
  導入手順.md
  使い方.md
  実機試験.md
```

ほかにも配布確認用のファイルがあります。削除せず、元の位置関係を保ちます。ブック保存型では同じ配布フォルダ内のdataに復旧用ファイルが残るため、このフォルダも一式として扱います。

キット内のworkbook/MVP7th.xlsmは、AIが配布物を作るための共通原本です。**利用するのはアプリの配布フォルダ内のブックです。共通原本では「初回設定」を押しません。**

## 6. 初回設定をする

初回設定は、今後使うブックの場所とアプリ情報を登録する作業です。マクロの作成ではありません。導入担当者が、配置先のコピーで一度行います。

1. 共有場所のMVP7th.xlsmを、編集可能な状態でJUST Calcから開きます。マクロは職場の運用に沿って実行できる状態にします。
2. 「初回設定」ボタンを押します。
3. 表示されるブックの場所を確認します。今後全員で使う場所なら進めます。違う場合は中止し、未設定の一式を正しい場所へ置いてからやり直します。
4. CSV閲覧型では、CSV読込先の入力欄に4章で確認したフォルダの絶対パスを入力します。空欄またはキャンセルでは初回設定を完了しません。ブック保存型には、この入力はありません。
5. 「初回設定が完了しました」の通知を確認します。
6. CSV閲覧型なら「最新CSVで開く」「読込先の設定」など、ブック保存型なら「編集する」「閲覧する」「保存して終了」などが表示されます。

設定はブックに保存されるので、次回から同じ入力を繰り返す必要はありません。完了通知が出ない場合はエラー文を控え、10章を確認します。設定後にブックだけを移動・改名すると登録場所と一致しなくなるため、配置変更は導入担当者またはAIへ相談します。

## 7. CSV閲覧型を使う：地ケアの例

### 開く・確認する・終了する

1. 共有場所のMVP7th.xlsmを開きます。
2. 「最新CSVで開く」を押します。登録したフォルダのCSVをブック側で取得し、Edgeが開きます。毎回フォルダを選ぶ画面は出ません。
3. CSV読込日時と対象ファイルを確認します。「読込内容を確認」から、ファイル名・更新日時・不足の内容も確認できます。
4. 対象月や病床区分を切り替え、必要な数値を確認します。
5. 終わったら、そのEdgeタブとブックを閉じます。保存者名の入力や保存操作はありません。

初回設定済みなら、他の人がブックを開いていて読み取り専用になっても閲覧できます。CSVを読む権限は、それぞれの利用者に必要です。

### CSVが更新されたら

CSVの出力・更新が終わってから、ブックの「最新CSVで開く」をもう一度押します。新しい画面の読込日時を確認し、古いタブは閉じます。画面を開いたまま待つ操作や、Edgeの再読み込みでは新しいCSVを取り直しません。

### 「データなし」や対象外の表示

地ケア版はUTF-8／Shift_JISの統合CSV、または対象月の「病棟別人数分布表」と「地ケアマスタ」の組み合わせに対応します。詳しい列・ファイル名は、配布フォルダ内のruntime/CSV形式.mdに入っています。フォルダにCSVがあるだけで、どんな形式でも集計できるわけではありません。

登録先の直下だけが対象で、年月別のサブフォルダの中は読みません。上限は1,000ファイル、元CSVの合計50MiBです。上限超過では一部だけを表示せず停止します。

空フォルダや不足した月・区分・指標は「データなし」です。必要な3ヶ月・6ヶ月分がそろわない期間集計も「データなし」になります。これは「0」とは異なり、値を計算・確認できない意味です。デモ値や以前の値で補うことはありません。未対応CSVは名前を示して対象外にし、不正な行・形式などで解析を続けられない場合は理由を示して停止します。

元CSVを画面で書き換えず、集計結果をブックへ保存したり履歴を追加したりしません。起動用の一時ファイルはPC内に作り、ブック終了時に削除を試みます。強制終了時には残る場合があります。

### CSV読込先を変える

導入担当者がブックを編集可能な状態で開き、「読込先の設定」を押します。新しいフォルダの絶対パスを入力して保存完了を確認します。空欄・キャンセルなら変更しません。「最新CSVで開く」で新しい場所を読むことを確認し、利用者のPCでも試します。読み取り専用では設定を変更できません。

## 8. ブック保存型を使う：入力・保存の例

### 入力して終了する

1. 共有場所のMVP7th.xlsmを編集可能な状態で開きます。
2. 「編集する」を押します。**作業中はブックを開いたままにします。**
3. Edgeで入力します。保存者名の欄がある場合は入力します。
4. Edge上部の「入力を終える」を押し、保存用ファイルのダウンロード完了を確認します。
5. 開いているJUST Calcのブックへ戻り、「保存して終了」を押します。通常は、今回の作業に対応するファイルをダウンロード先から見つけて取り込みます。
6. **ブックに保存した旨の通知を確認します。** この通知で正式保存の完了と判断します。ブックが閉じたら、残っているEdgeの作業タブも閉じます。

Edgeが出力するのはJSONというテキスト形式の受け渡しファイルです。業務データと、どの作業の出力かを確認する情報が入っています。ダウンロードだけではブックへの保存は完了していません。また、JUST Calcの通常の保存ボタンやCtrl+SだけではEdgeの入力内容を取り込めません。

保存用ファイルが見つからない場合は、まずダウンロード完了を確認します。別の場所へ保存した場合はブックの案内に従い、今回のファイルを選びます。古いファイルや別の作業のファイルを代わりに選びません。

### 途中で保存して続ける

1. Edgeの「途中保存・再出力」を開き、「途中保存の準備」を押します。
2. ダウンロード完了を確認します。
3. 開いているブックの「保存して続ける」を押します。
4. 途中の内容を保存した旨の通知を確認し、ブックを開いたまま同じEdge画面で作業を続けます。

最後に終了するときは、改めてEdgeの「入力を終える」→ ブックの「保存して終了」です。途中保存用と終了用は用途が異なるため、画面とブックのボタンを対応させます。

### 閲覧と編集の交代

見るだけの場合は「閲覧する」を押します。最後に正式保存された内容を表示し、入力途中の内容は共有されません。ほかの人の保存結果を見るときは、共有ブックと閲覧画面を開き直します。

編集は一人ずつ行います。ブックが読み取り専用なら閲覧に使い、編集者の保存・終了後に開き直して交代します。この動きは職場の共有環境で二台以上を使って確認します。

作業中のEdgeタブは複製・再読み込みせず、そのまま使います。誤って閉じた場合や保存に失敗した場合は、10章の案内に沿って状況を伝えます。

## 9. 職場のPCで確認してから利用を始める

まず一台で、次を検証用データで確認します。

| CSV閲覧型 | ブック保存型 |
| --- | --- |
| 設定後に開き直しても同じCSV読込先を使う | 一件入力し、終了保存後に開き直すと同じ内容になる |
| フォルダ選択を挟まず「最新CSVで開く」で表示する | 変更・削除・検索・計算などの業務操作が想定どおり |
| 日本語名、UTF-8／Shift_JIS、複数月のCSVを正しく表示する | 途中保存後に作業を続け、最後の内容も保存できる |
| CSV更新後、ブックから開き直すと反映される | 閲覧中に変更できず、正式保存された内容を見る |
| 空フォルダ・不足・未対応CSVを明示し、古い値で補わない | ブック側で保存完了を通知し、今回の入力が残る |
| 元CSVの内容・更新日時を書き換えない | 保存失敗を成功と表示せず、再試行・復旧できる |

次に二台以上で確認します。CSV閲覧型は同じ共有先・同じ対象月で結果が一致し、読み取り専用のブックからも閲覧できることを確認します。ブック保存型は同時に二人が編集できないこと、保存して閉じた後に編集を交代できることを確認します。切断・権限不足・読込中の更新などの異常系は、導入担当者が検証用の場所で確認します。

使ったPC、Windows・JUST Calc・Edgeの版、共有場所、操作、表示結果、日時を導入担当者またはAIへ伝えます。二台目がまだないなど、実施できなかった項目は未実施と伝えれば大丈夫です。

| 案内される状態 | 意味 |
| --- | --- |
| 実機検証用 | ブックと画面はそろい、職場PCで試す段階です |
| 配布可能 | 本体とアプリの対象環境での確認が済み、導入先の確認へ進めます |
| 利用開始可能 | 配置した共有場所での確認も済んでいます |

MVP7thでは自動試験149件と、Mac版Excelでのブック組み立て・コンパイル・ソース照合を確認済みです。**Windows・JUST Calc・Edge、実際の共有フォルダ、複数PCでの受け入れは未実測**です。自動試験の成功だけで職場の動作を確認済みとは扱いません。導入担当者が確認結果をそろえ、利用開始可能になったら全員へ同じ共有ブックの場所を案内します。

## 10. 困ったとき

| 困っていること | 対応 |
| --- | --- |
| 「初回設定」が反応しない | JUST Calcで開いているか、マクロが実行できる状態かを確認します。職場の設定で実行できない場合は管理担当者へ相談します |
| 読み取り専用で初回設定・読込先変更ができない | 保存権限と他の人の利用状況を確認し、編集可能な状態で開き直します。登録済みCSVの閲覧には設定変更は不要です |
| 配置場所が違う、画面や設定が見つからない | ブックだけを移動・改名していないか、一式を展開したかを確認します。設定を手編集せず導入担当者へ伝えます |
| CSVへ接続できない・権限がない | 登録したフォルダのパス、ネットワーク接続、利用者の読み取り権限を確認します |
| CSV読込中に変更があった | CSVの出力・更新完了後に「最新CSVで開く」を押します。前から開いていた古いタブを今回の結果として扱いません |
| CSVはあるのにデータなし | 直下にあるか、対象月・区分・必要ファイルと列・期間がそろうかを「読込内容を確認」の表示と照合します |
| Edgeで出力したのに保存されていない | ブックの「保存して終了」または「保存して続ける」まで行い、ブック側の完了通知を確認します |
| ブックの保存が失敗した | ブックとEdgeを閉じず、エラー文と直前の操作を伝えます。保存完了までダウンロードしたJSONとdataを残します |
| 「保存が完了していません」と表示された | 接続を確認し、案内に従って同じ保存ボタンで再試行します。解決しなければ開いたまま管理担当者へ伝えます |
| 保存後、ブックの終了だけ失敗した | 「保存して終了」をもう一度押し、終了を再試行します |
| 入力中のEdgeを閉じた・PCが異常終了した | 保存完了したか、保存用JSONが出ていたか、どこで止まったかを伝えます。関係ファイルを残して復旧を相談します |

状況を伝えるときは、例えば次の形で十分です。

> 地ケアの「最新CSVで開く」を押しました。PC Aでは表示でき、PC Bでは「読み取り権限」のエラーになりました。同じ共有ブックを開いています。表示されたエラー文は○○です。

復旧が必要な場合は別の空ブックを上書きして直そうとせず、元のブック、data、ダウンロードしたJSONを保全して管理担当者へ渡します。CSV閲覧型にはブック内の集計履歴がないため、CSV出力元と読込先の状態を調べます。

## 11. アプリや配置を変更したくなったら

新しいHTMLと、MVP7thキット内に残したそのアプリのintegrationsの組み込み記録をAIへ指定し、「同じアプリを更新して」と依頼します。運用中のブックやdataに新品を上書きせず、保存済みデータを保つ更新方法を確認させます。

CSVの場所だけの変更は、7章の「読込先の設定」を使います。アプリ一式の配置場所を変える場合は、設定済みブックを勝手に移動せず、導入担当者またはAIへ手順を確認します。変更後は、実際に使うPCと共有場所で再度動きを確認します。

この文書の操作だけで始められます。詳細な技術確認が必要になった場合の資料もMVP7th内にあります。[検証記録](docs/verification.md)、[職場PCでの確認項目](docs/acceptance-test.md)、[管理者向け復旧](docs/recovery.md)、[AIの作業手順](AI_START_HERE.md) を参照できます。
