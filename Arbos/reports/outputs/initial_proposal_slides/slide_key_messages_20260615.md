# 初回提案スライド キーメッセージ整理

作成日: 2026-06-15

## 位置づけ

アルボースの病床利用率低下について、従来の病床数・利用率分析だけでは見えにくかった利用者の流れに着目し、優先的に確認すべき利用者層と、継続運用に向けた課題を整理するための初回提案ストーリーを整理する。

## スライド構成

| Slide | タイトル案 | キーメッセージ |
|---:|---|---|
| 1 | 病床利用率低下に対するボトルネック分析 | アルボースの病床利用率低下について、利用者の流れに着目し、ボトルネックの発見とスループット向上に向けた分析を行った |
| 2 | これまでの利用率分析で見えていたこと | 病床数・利用率の分析は行われていたが、従来の流れでは、どこで利用者の流れが止まっているかまでは明確にしにくかった |
| 3 | 今回追加した分析視点 | サービス別の件数だけでなく、利用者ごとに利用履歴を時系列で追い、次の利用につながったかを確認した |
| 4 | フォローすべき利用者層 | 利用者ごとの履歴を追うことで、直近ショート利用者、ショート15日以上利用者、3F候補、デイ高頻度者など、優先的に確認すべき対象が具体化した |
| 5 | 継続運用に向けた課題 | 確認すべき利用者層は整理できた一方で、継続的に確認・対応を回すには仕組み化が必要 |
| 6 | 次フェーズの進め方 | 次フェーズでは、現場の確認・対応を回すための現場DXと、利用者追跡・フォロー管理のシステム化を並行して進める |
| 7 | 現場に根ざしたDXへ | 分析で終わらせず、現場で確認・対応・改善が回り続ける状態を目指す |

## 次のステップ

各スライドについて、以下を順に具体化する。

1. スライド内の本文構成
2. 図表・チャート・フロー図の設計
3. 経営層向けに見せる数値と、利用者単位分析から得た示唆の整理
4. 既存PPTXへの反映または新規デック化

## 修正メモ

- 旧Slide 4「利用者単位で見えたボトルネック」は削除し、利用者単位の分析視点はSlide 3に統合した。
- 旧Slide 6「今回の到達点」は削除し、Slide 4から継続運用課題へ直接つなぐ構成にした。
- 本編は、`出発点 -> 追加した視点 -> 確認対象 -> 運用課題 -> 次フェーズ -> 今後の姿勢` の流れに整理した。
