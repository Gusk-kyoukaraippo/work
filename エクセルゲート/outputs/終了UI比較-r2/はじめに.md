# 終了UIの3案を比較する

目的は、ファイルの受け渡しを知らない人でも、今見ている案内だけで保存と終了を進められることです。3案とも、説明と操作を置く下部二段バーに統一しました。名前入力、準備中、次の操作、再試行を同じ下部で切り替えます。カードや中央の終了ダイアログは使いません。業務HTMLの画面・操作・データ形式は維持し、保存案内文2か所だけ下部のボタンに合わせています。

| 試作 | 終了の流れ | 比較する点 |
| --- | --- | --- |
| A：通常UI | Edgeの終了ボタン → ブックで保存 → Edgeを閉じる → OKでブックを閉じる | 案内だけで迷わず進めるか。画面を行き来する負担 |
| B：OnTime | Edgeの終了ボタン → 自動で準備 → Edgeを閉じる → ブックで保存 → OK | Edgeを操作中にも準備が進むか。JUST CalcのOnTimeの対応 |
| C：VBA待機 | Bと同じ。準備方法をVBA待機へ変更 | 待機中の操作感、途中保存、中断・再開、PCへの負荷 |

3案ともEdgeの主ボタンは「アプリを終了して保存作業に移る」、ブック側は「保存して閉じる」です。ダウンロードの確認やファイル選択は利用者に求めません。BとCの見た目は同じで、実機で準備方法を比較します。

[画面を比較.html](画面を比較.html) で終了時の表示を切り替えられます。実際の共通UIを撮影したプレビューです。準備完了通知の書き込みを模擬しており、JUST Calcの動作を実証するものではありません。

## 試す

ZIPを展開し、A・B・Cをそれぞれ新しい検証用フォルダに丸ごと配置します。一つずつ開き、各フォルダの「試作の使い方.md」と「導入手順.md」に沿って初回設定を行います。運用中のブック・dataへ上書きしません。マクロ入りブックを同梱しているので、VBAの編集や設定JSONの変更は不要です。

各案で一件入力して、画面に出る案内だけで終了します。開き直して内容が残ることを確認し、[実機比較・記録.md](実機比較・記録.md) に、迷った場面・待ち時間・成否を記録します。

実機比較後に採用案を決めます。OnTimeやVBA待機が動くことを前提に順位は付けません。確認済みの範囲は [確認結果.md](確認結果.md)、受け取りと保存の仕組みは [実装の理屈.md](実装の理屈.md) にあります。
