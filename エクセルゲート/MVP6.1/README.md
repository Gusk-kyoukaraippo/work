# Excelゲート MVP6.1

**マクロ入りの共通ブックを同梱した、HTMLアプリの組み込み・導入キットです。** HTMLをAIへ渡すと、AIが画面と保存処理を接続し、試験して配布一式を作ります。導入担当者は、業務画面の確認と、職場のPCでの操作確認を行います。

初めて使う方は [はじめての組み込みと使い方](はじめての組み込みと使い方.md) から進めてください。新しいAIに依頼するときは、このフォルダ一式と [AIへの依頼文](AIへの依頼文.md) を渡します。

AIへ渡すのは **MVP6.1フォルダ全体**、職場のPCで試すのは **deliverables内のアプリ別フォルダまたはZIP** です。

**通常の組み込みで、VBAの貼り付けやブックの作り直しは不要です。** AIは同梱原本のコピーを配布一式へ入れます。`workbook` の原本では「初回設定」を押さず、配置したコピーで実行します。

MVP6.1は、作成済みのMVP6共通本体を使う案内・素材の改訂版です。照合済みの本体をそのまま引き継ぐため、ブック名 `MVP6th.xlsm`、画面の「MVP6」、内部の本体版 `0.6.0` は維持しています。

## 今できること

HTMLの組み込み、ブラウザでの確認、完成ブックを含む一式の作成、Windows版JUST CalcとEdgeでの試用ができます。現在の配布物は **実機検証用** です。本体・アプリ・導入先の実機確認がそろうまでは、業務利用開始とはしません。[確認済みと未確認の範囲](docs/verification.md)

Windows、JUST Calc、Edge、全員が読み書きできる共有フォルダを使います。利用者PCにNode.jsやサーバーは不要です。AI側の開発環境に必要なツールはAIが用意します。

## 技術的な仕組み

日常の処理はHTMLのJavaScriptとブックのVBAで動きます。Excelゲートの標準処理がAIへ問い合わせることはありません。AIが担当するのは、組み込み・改修・試験・結果の記録です。

1. **ブックから開く。** VBAが保存済みデータと編集・閲覧の区別を渡し、Edgeで業務HTMLを開きます。
2. **Edgeで入力する。** HTMLが入力中のデータを持ちます。共通JavaScriptが、閲覧中や入力終了後の更新を制限します。
3. **受け渡しファイルを出す。** 「入力を終える」は、業務データをJSONというテキスト形式のファイルへ出す操作です。作業の識別子や保存番号も付けます。
4. **ブックへ正式保存する。** VBAがファイルの形式、作業の所属、保存番号とつながりを確認し、ブック内の正式データを更新します。復旧に必要なファイルと記録も残します。

**保存完了は、ブックの「保存して終了」または「保存して続ける」の通知で確認します。** Edgeからファイルを出した段階では、正式保存は終わっていません。

| 部品 | 守る範囲 |
| --- | --- |
| HTMLと共通JavaScript | 初期データの読込、未確定入力の扱い、閲覧・入力終了後の更新制限 |
| 共通ブックとVBA | 正式データ、受け渡しファイルの検査、保存と復旧 |
| 共有場所のブック | 一人が編集し、他の人は保存済み内容を閲覧する運用。二台での実測確認が必要です |
| 試験と照合記録 | 試した本体・アプリ・ソフトの版・導入先を識別。別の版や未確認の環境に合格を流用しません |

壊れたJSONや所属不明のファイルを、古い正常な出力へ勝手に置き換えて保存しません。異常時は停止し、残したファイルを調べます。閲覧表示は自動更新されず、最新を見るにはブックから開き直します。
