# 実機での確認

**完成ブックを含む一式を、検証用の共有フォルダで試します。** Windows版JUST CalcとEdgeを使い、業務データは入れません。ブックの作成手順ではありません。

まだ配置していなければ、同梱の「導入手順」に沿って一式を置き、「初回設定」を済ませます。結果は会話でAIへ伝えてください。記録への転記はAIが行います。

## 一台でできる確認

### 1. 保存して開き直す

1. ブックの **「編集する」**を押し、Edgeが開くことを確認します。
2. 「動作確認」など、見分けられる内容を一件入力して確定します。
3. Edge上部に保存者名を入力し、**「入力を終える」**を押します。その後、この画面ではデータを変更できないことを確認します。
4. ブックへ戻り、**「保存して終了」**を押します。「ブックに保存しました」の通知を確認し、ブックとEdgeの作業タブを閉じます。
5. 同じ共有ブックを開き直し、**「閲覧する」**で、入力した内容が残っていることを確認します。

### 2. 閲覧で使える操作を確認する

閲覧画面で、追加・変更・削除ができないことを確認します。元のアプリにある検索・絞り込み・表示切替・詳細表示は使えることを確認します。進捗ボードには検索欄がないので、絞り込みと詳細表示を試します。

終わったら閲覧タブとブックを閉じます。閲覧表示は自動更新されません。

### 3. 途中保存して続ける

1. 同じ共有ブックを開き直して **「編集する」**を押し、試しの内容を変更・確定します。
2. Edge上部の **「途中保存・再出力」→「途中保存の準備」**を押します。保存者名が空欄なら入力します。
3. ブックの **「保存して続ける」**を押し、保存完了を確認します。
4. 同じEdgeの画面でさらに変更・確定し、**「入力を終える」→ブックの「保存して終了」**を実行します。
5. 開き直して「閲覧する」で最後の内容を確認します。

次のように伝えれば記録できます。

> Windows版JUST Calcで、保存・開き直し・閲覧を試しました。内容は残り、閲覧では変更できませんでした。途中保存後も編集を続けられました。二台確認はまだです。

うまく動かなければ、成功例に合わせず、止まった操作と実際の表示を伝えてください。保存失敗時はブック・Edge・ダウンロードしたファイルを残します。

## 二台がそろってから行う確認

1. 一台目で共有ブックを開き、「編集する」で作業を始めます。
2. 二台目で **同じ共有場所の同じブック** を開きます。二台目は編集できず、「閲覧する」で保存済み内容を見られることを確認します。
3. 一台目で「入力を終える」→「保存して終了」を行い、ブックと作業タブを閉じます。
4. 二台目の閲覧タブとブックを閉じ、共有ブックを開き直します。今度は「編集する」で作業できることを確認します。

二台がない場合は、一台での結果まで報告して止めてかまいません。同じPCの二つのタブを、二台試験の代わりにはしません。

## AIが記録・判断すること

AIは、実際のWindows・JUST Calc・Edgeの版、使用した一式、共有場所、確認日と結果を記録します。利用者にはJSONやハッシュを入力させません。

この画面確認に加え、本体には保存失敗・復旧などの検収があります。すべての本体・アプリ確認が済んで「配布可能」、導入先の確認も済んで「利用開始可能」です。障害試験と記録の詳細はキット内の保守担当者向け手順で扱います。
