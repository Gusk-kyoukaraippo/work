# Excelゲート 起動時間の比較実装

MVP8thを基にした、MVP9thへの採用判断のための検証用作業フォルダです。正式なMVP9thではありません。既存のMVP8thと運用ブックは変更していません。

利用者向け成果物は [起動時間比較一式](deliverables/起動時間比較一式/はじめに.md) です。A旧方式・B最小改修・C同じ起動操作からのHTML直開き、ローカル集計ページを同梱します。

共通コードの互換版は0.8.0のまま、appId・dataVersion・保存形式を維持しています。BのCRC表引きと読込キャッシュは一回のOpenEditHtmlの間だけ有効です。A/Bのコピー・照合・編集前保存は維持します。Cは性能の基準用で、セッション受渡し付き直接読込案の実装ではありません。

開発側の確認は [検証記録](verification/startup-study/README.md)。Windows / JUST Calc / Edgeの実測・復旧・2台交代が未確認のため、正式採用は保留です。

再生成は `node startup-study/build-study.mjs 新しい出力先`。既存の出力先には上書きしません。VBA変更時は通常の保守手順でネイティブExcelに組み込み、ソース照合をやり直します。GateStartupを加えた9標準モジュールが必要です。通常のアプリ追加にこの検証原本を使わないでください。
