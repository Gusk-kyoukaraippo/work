# アルボ配車 MVP 1st 現状記録

作成日: 2026-07-03

## 位置づけ

この状態を `MVP 1st` とする。

当初の `../docs/initial_project_memo.md` では、MVP1を「利用者CSVを読み込み、住所をもとに伊勢崎市の地図上へ点を表示する」段階として定義していた。現在の `index.html` は、このMVP1の必須要素を満たし、さらに実CSV対応、file://単体動作、拡大・移動、点重なり回避まで含む状態になっている。

## 当初構想との比較

| 項目 | 当初構想 | 現状 |
|---|---|---|
| HTML単体動作 | 必須 | 実装済み。住所DBと地図画像をHTML内に埋め込み、file://で動作可能 |
| CSV読み込み | 必須 | 実装済み。実CSVの帳票タイトル行を飛ばし、住所列を自動検出 |
| 文字コード | 未確定 | UTF-8 / Shift_JISを自動判定 |
| 地図画像表示 | 必須 | 実装済み。伊勢崎市の概略地図を内蔵 |
| 住所と座標の対応マスタ | 必須 | 実装済み。軽量住所DBを内蔵 |
| 地図上への点表示 | 必須 | 実装済み。氏名ラベル付きで表示 |
| 未対応住所の一覧 | 必須 | 実装済み |
| 点座標CSV出力 | 構想外 | 実装済み |
| 拡大・移動 | 構想外 | 実装済み。ホイール拡大、ボタン拡大、ドラッグ移動 |
| 点の重なり対策 | 構想外 | 実装済み。拡大時に点と名前を縮小し、近接点を自動で少しずらす |

## 現在できること

- `index.html` を単体で開ける。
- 外部API、Node.js、サーバーなしで動作する。
- 実際の介護サービス利用者一覧CSVを読み込める。
- 先頭に帳票タイトル行があるCSVでも、住所列を自動検出できる。
- Shift_JISのCSVを読み込める。
- 利用者名と住所を読み取り、地図上に点を表示できる。
- 住所が見つからない場合は未対応住所として一覧表示できる。
- 手入力した住所を1件だけ打点できる。
- 地図をドラッグして上下左右に移動できる。
- ホイールまたは `+` / `-` ボタンで地図を拡大縮小できる。
- 拡大時に赤い点と名前ラベルが小さくなり、位置関係を確認しやすい。
- 近すぎる点は表示上で少しずらし、完全な重なりを避ける。
- 点座標付きCSVを保存できる。

## 現在の制約

- 住所座標は概略位置であり、玄関や正確な番地位置ではない。
- 軽量DBでは町域代表点と擬似オフセットを使うため、番地単位の精度には限界がある。
- 地図画像は概略図であり、道路幅や進入可否までは扱っていない。
- ルート順の自動計算は未実装。
- 車両条件、車椅子人数、大型車可否などの制約判定は未実装。
- 印刷用レイアウトやPDF出力は未実装。

## MVP 1stとしての評価

当初のMVP1で必要とされていた以下の要素は満たしている。

- CSV読み込み
- 伊勢崎市の地図画像表示
- 住所と座標の対応マスタ
- 地図上への点表示
- マッピングできなかった住所の一覧表示
- HTML単体動作

そのため、現状は `MVP 1st 完了相当` と見なせる。
