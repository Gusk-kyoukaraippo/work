# 地ケア MVP3rd

地ケア向けのスタンドアロンHTMLダッシュボードです。  
CSVを読み込み、KPI表示を提供します。

## ファイル構成

- `index.html`: 画面・スタイル・集計ロジックを含む単一HTML
- `data/`: 検証用CSV（主にダミーデータ）
- `検証用データ/`: 実データのサンプル

## 使い方

1. `index.html` をブラウザで開く  
2. 画面上部の `ここを押してデータを読み込む` を押す
3. フォルダ選択画面で、次の順に開く
   - `miharaDB`
   - `014医療情報室`
   - `50.SUNABACO DX`
   - `チケアテスト`（このHTMLがあるフォルダ）
   - `data`
4. `data` フォルダを選択する
   - ブラウザがフォルダ選択に対応しない場合は `CSVフォルダを選択` を使用

正常に読み込めている場合、`データソース` の警告枠は表示されません。

## データ読み込み仕様

- データはユーザー操作で読み込む
- 3種類のCSVが同じフォルダにある前提
- 読み込み後は集計対象月のうち最新月を初期表示
- `地ケアマスタ` のファイル名に日付がない場合、CSV内の日付から対象月内の最新日を速報基準日として表示

## 対応CSV（命名規則）

- ダミーデータ
  - `病棟別人数分布表(条件指定)_YYYYMM.csv`
  - `病床稼働報告_YYYYMMDD.csv`
  - `地ケアマスタデータ_YYYYMM.csv`
- 実データ
  - `病棟別人数分布表(条件指定)_YYYY-MM-DD.csv`
  - `病床稼働報告_YYYY-MM-DD.csv`
  - `地ケアマスタ_YYYY-MM-DD入院者.CSV`
  - `地ケアマスタ_YYYYMM.csv`

文字コードは `Shift_JIS(CP932)` を想定しています（UTF-8もフォールバック対応）。
日付は西暦の `YYYY.MM.DD` / `YYYY/MM/DD` / `YYYY-MM-DD` と、和暦の `R8.2.17` 形式に対応しています。

## 画面表示

- 集計対象月ごとにダッシュボードを切り替え可能
- 実データ読み込み時は、総合アラート横に `2026年2月 / 2月17日時点` のように速報基準日を表示
- ファイル名に日付がない場合は、`地ケアマスタ` の中身に含まれる日付のうち、対象月内の最新日を `何月何日現在` として表示

## KPIと基準値

- 在宅復帰率
  - 表示: 当月(速報) / 直近6ヶ月(正式)
  - 集計: 退院月ベース。対象月に退院した患者を分母とし、`転出先` が在宅系の患者を分子とする
  - 基準: 75%以上（注意: 72.5%以上）
- 看護必要度
  - 表示: 当月(速報) / 直近3ヶ月(正式)
  - 集計: `病棟別人数分布表` の `6階病棟 / Ⅱ / 割合(%)` 行を使用し、月次表示は末尾の `平均` を採用
  - 基準: 12%以上（注意: 11%以上）
- 自宅等からの入院患者割合
  - 表示: 当月(速報) / 直近3ヶ月(正式)
  - 集計: 入院月ベース。対象月に入院した患者を分母とし、`入院経路` が自宅・在宅系施設等の患者を分子とする
  - 基準: 20%以上
- 自宅等からの緊急入院患者受入人数
  - 表示: 当月(速報) / 直近3ヶ月(正式)
  - 集計: 入院月ベース。`入院経路` が自宅等かつ `備考とSCU日数` に `予定外` を含む患者を件数集計
  - 緊急入院の判定: `備考とSCU日数` に `予定外` を含む患者を緊急入院として扱う
  - 基準: 直近3ヶ月で9人以上

各カードに `達成/未達` を色分け表示します。

## 実装前提

- 緊急入院は、`地ケアマスタ` の `備考とSCU日数` に `予定外` を含む患者として集計します。
- `病床稼働報告` は現状KPI計算には未使用
