# アルボース利用率低下に関するメモ

## 取り組む問題

アルボースの利用率低下。

## 何が起こっているか

- アルボース入所者の利用率が低下している
- それに対応するために、滞在者の入所延長などで対処している
- デイサービス利用者数も減っている
- 職員の休職・離職も多いが、補充されない
- 職員同士の反目によるベテランの異動などもある
- そのために、営業もできていない

## 問題の背景

アルボース全体の殿様商売、すなわち、自分達の都合のいい利用者が勝手にやってくれればいい、という姿勢がある。

実際、コロナ前、つまり6年以上前はできていた。
