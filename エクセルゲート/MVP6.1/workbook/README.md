# 共通ブックの原本

**MVP6th.xlsmはマクロ入りの完成原本です。** 通常の組み込みでは、AIがこのブックと照合記録を確認し、コピーをアプリの配布一式へ入れます。

ここにある原本では「初回設定」を押しません。業務データのない状態を保ち、配布先へ置いたコピーで初回設定します。

ファイル名のMVP6thは、照合済みの共通本体の名前です。MVP6.1でもそのまま使用します。

`MVP6th-template.xlsx` と `mac-manual` は、本体を修正・再作成するときの保守素材です。通常の導入には使いません。[保守担当者向け手順](../docs/maintainers/README.md)
