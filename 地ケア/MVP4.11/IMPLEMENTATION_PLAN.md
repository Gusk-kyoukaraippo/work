# MVP4.11 実装詳細設計

## 目的

会社内オンプレ環境で、毎回同じCSVフォルダを使う運用を楽にする。  
初回だけ固定フォルダを登録し、次回以降はIndexedDBに保存したフォルダハンドルから自動読み込みする。  
ただし、会社設定でIndexedDBやFile System Access APIが使えない可能性があるため、ドラッグ＆ドロップ読み込みを常に代替手段として残す。

## 前提

- 利用者はChromeまたはEdgeを使う
- 起動方法は `file://` 直接起動を第一候補とする
- 接続フォルダは原則として一定
- CSVフォルダには複数月分の3種類CSVが入っている
- 固定フォルダ保存が失敗しても、ダッシュボード自体は使える必要がある

## 技術判断

### IndexedDBが必要な理由

`FileSystemDirectoryHandle` は通常の文字列パスではなく、ブラウザが管理する権限付きハンドルとして扱う。  
このハンドルを保存する場所としてIndexedDBを使う。

保存する値:

- DB名: `tiiki-care-dashboard`
- Store名: `settings`
- Key名: `dataDirHandle`
- Value: `FileSystemDirectoryHandle`

### パス文字列を保存しない理由

ブラウザ上のHTML/JavaScriptから、Windowsの絶対パスを指定して任意フォルダを読むことはできない。  
そのため `C:\...` やネットワークパスを保存しても、次回読み込みには使えない。  
必ずユーザーが一度許可したフォルダハンドルを使う。

### ドラッグ＆ドロップだけでは固定化できない理由

ドラッグ＆ドロップで得たフォルダは、その場で読み込む用途には使える。  
ただし、次回起動後も再利用できる永続フォルダハンドルとして保存できるとは限らない。  
固定フォルダ化には `showDirectoryPicker()` による明示的なフォルダ登録を使う。

## 画面設計

### 初回状態

表示するもの:

- `固定フォルダを登録` ボタン
- `CSVをここにドロップ` 枠
- 状態メッセージ

状態メッセージ例:

- `固定フォルダを登録すると、次回から自動読み込みできます。`
- `登録できない場合は、CSVフォルダをドロップしてください。`

### 自動読み込み成功後

表示するもの:

- KPI
- 月別内訳
- 画面下部の再読み込み用ドロップ枠
- 固定フォルダ状態

状態メッセージ例:

- `保存フォルダから7ヶ月分を読み込みました。`
- `別フォルダを使う場合は、下の枠へドロップしてください。`

### 自動読み込み失敗後

表示するもの:

- `固定フォルダを登録` ボタン
- `CSVをここにドロップ` 枠
- 失敗理由

状態メッセージ例:

- `保存フォルダへ接続できません。CSVフォルダをドロップしてください。`
- `この環境では固定フォルダ保存が使えません。ドラッグ＆ドロップで読み込んでください。`
- `保存フォルダ内に対象CSVが見つかりませんでした。`

## データフロー

### 起動時

1. `bindEvents()` でD&Dと登録ボタンを初期化する
2. `tryAutoLoadFromSavedDirectory()` を実行する
3. IndexedDB利用可否を確認する
4. 保存済みフォルダハンドルを取得する
5. 読み取り権限を確認する
6. 権限がなければ再許可を求める
7. 許可済みならフォルダ内CSVを再帰的に収集する
8. `loadMonthDataFromFileList(files)` に渡す
9. 成功ならダッシュボードを描画する
10. 失敗ならD&Dへ誘導する

### 固定フォルダ登録時

1. `window.showDirectoryPicker({ mode: "read" })` を実行する
2. 選択されたフォルダハンドルをIndexedDBに保存する
3. そのフォルダからCSVを収集する
4. `loadMonthDataFromFileList(files)` に渡す
5. 成功ならダッシュボードを描画する
6. CSV不足なら登録は維持しつつ警告を表示する

### ドラッグ＆ドロップ時

1. ドロップされたDataTransferからファイルまたはフォルダを取得する
2. `getAsFileSystemHandle()` が使える場合はそれを優先する
3. 使えない場合は `webkitGetAsEntry()` にフォールバックする
4. CSVだけを抽出する
5. `loadMonthDataFromFileList(files)` に渡す
6. 成功ならダッシュボードを描画する

## 追加する主な関数

### IndexedDB

- `isIndexedDbAvailable()`
  - テスト用DBを開き、使用可否を判定する
- `openSettingsDb()`
  - `tiiki-care-dashboard` / `settings` を開く
- `saveDirectoryHandle(handle)`
  - `dataDirHandle` にフォルダハンドルを保存する
- `getSavedDirectoryHandle()`
  - 保存済みフォルダハンドルを取得する
- `clearSavedDirectoryHandle()`
  - 保存済みフォルダ設定を削除する

### フォルダ権限

- `supportsDirectoryPicker()`
  - `window.showDirectoryPicker` の存在を確認する
- `ensureReadPermission(handle)`
  - `queryPermission` と `requestPermission` で読み取り許可を確認する
- `registerDirectoryAndLoad()`
  - 初回登録ボタンから呼ぶ
- `tryAutoLoadFromSavedDirectory()`
  - 起動時に呼ぶ

### UI状態

- `showInitialLoader(message)`
  - 初回読み込み枠を表示する
- `showAutoLoadStatus(message)`
  - 固定フォルダの状態を表示する
- `showReloadPanel(show)`
  - 下部再読み込み枠を表示する
- `showRegisterButton(show)`
  - 登録ボタンを表示/非表示にする

## エラー分類

### IndexedDB不可

原因候補:

- 会社ポリシーでサイトデータ保存が禁止されている
- シークレットモード
- ブラウザ設定でCookie/サイトデータが制限されている
- `file://` 起動に対するブラウザの扱い

画面表示:

`この環境では固定フォルダ保存が使えません。CSVフォルダをドロップしてください。`

### File System Access API不可

原因候補:

- Chrome/Edge以外のブラウザ
- 古いブラウザ
- 会社ポリシーでAPIが制限されている

画面表示:

`固定フォルダ登録に対応していないブラウザです。CSVフォルダをドロップしてください。`

### 権限拒否

原因候補:

- ユーザーが許可しなかった
- ブラウザが保存済み権限を破棄した

画面表示:

`保存フォルダの読み取りが許可されていません。再登録するかCSVフォルダをドロップしてください。`

### CSV不足

原因候補:

- 対象フォルダを間違えた
- 3種類のCSVが同じ月で揃っていない
- ファイル名が命名規則と違う

画面表示:

`対象CSV3種が揃った月が見つかりませんでした。フォルダ内容を確認してください。`

## 実装順序

1. MVP4.1の画面に固定フォルダ登録ボタンと状態メッセージ領域を追加する
2. IndexedDBのopen/get/put/delete関数を追加する
3. `showDirectoryPicker()` による登録処理を追加する
4. 起動時の保存フォルダ自動読み込み処理を追加する
5. 失敗時にD&Dへ戻すUI分岐を追加する
6. READMEに会社環境での確認手順を追記する
7. Chrome / Edge / IndexedDB無効相当のケースを確認する

## 検証項目

### 正常系

- 初回登録で `検証用データ` フォルダを選び、7ヶ月分が読み込まれる
- ページ再読み込み後、保存フォルダから自動読み込みされる
- 読み込み後も下部D&D枠から別フォルダへ差し替えできる
- 再登録すると保存先フォルダが更新される

### 異常系

- IndexedDBが使えない場合、D&Dだけで読み込める
- `showDirectoryPicker` が使えない場合、登録ボタンを出さずD&Dへ誘導する
- 権限拒否時、画面が壊れずD&Dへ誘導する
- 保存済みフォルダ内にCSVがない場合、警告を出す
- CSVが一部月だけ不足している場合、揃っている月だけ読み込む

## 会社環境での確認手順

1. ChromeまたはEdgeで `index.html` を開く
2. 開発者ツールのConsoleで `indexedDB` が存在するか確認する
3. 固定フォルダ登録ボタンが表示されるか確認する
4. `検証用データ` フォルダを登録する
5. 読み込み成功後、ブラウザを閉じて開き直す
6. 自動読み込みされるか確認する
7. 自動読み込みされない場合、画面メッセージを記録する
8. D&Dでは読み込めるか確認する

## 採用する最終方針

MVP4.11では、固定フォルダ自動読み込みを便利機能として追加する。  
ただし、会社設定で使えない場合に備えて、ドラッグ＆ドロップ読み込みを必ず残す。  
固定フォルダ登録に失敗しても、業務上のCSV確認は継続できる構成にする。

古いEdgeや会社端末での切り分けをしやすくするため、固定フォルダ登録・保存フォルダ自動読み込み・ドラッグ＆ドロップ読み込みの失敗時に、失敗段階、推定原因、ブラウザ例外、ブラウザ機能の有無、ブラウザ情報を画面に表示する。
