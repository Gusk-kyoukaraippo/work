# MVP3rd 実機受け入れテスト

## A. 導入と保護

- [ ] Mac版Excelで `vba` 直下のCP932版 `.bas` をインポートし、日本語メッセージが文字化けしない。
- [ ] Macで作成した `.xlsm` と `html` フォルダを含む `MVP3rd` 一式をWindowsへコピーする。
- [ ] Windows側で `.bas` を再インポートせず、Macで作成した `.xlsm` のマクロが実行できる。
- [ ] `InitializeMvp2` 後、利用者に見えるシートが `操作パネル` だけである。
- [ ] `_APP_DATA`、`_APP_META`、`_APP_HISTORY` がVeryHiddenである。
- [ ] ブック構造が保護され、利用者がシート追加・再表示をできない。
- [ ] 操作パネルのセルへ数値や文字を入力できない。
- [ ] 保護中でも5ボタンが動作する。
- [ ] `閲覧する`と`編集する`が横並び、その下に`一時保存ファイルをExcelに正式保存する`、さらに下に`終了する`が表示される。
- [ ] `ログチェック（管理者向け）`が通常操作から離れた管理者用区画に表示される。
- [ ] 正式保存カードは最新版だけを表示し、`1つ前`のカードを表示しない。

## B. HTMLと利用者名

- [ ] 問題が発生したPCで、編集HTML起動時に`SCRIPT1002`が出ず、名前入力が表示される。
- [ ] 名前入力後に`SCRIPT438: Object doesn't support property or method 'replaceChildren'`が出ず、業務フォームが表示される。
- [ ] ブラウザのローカル保存領域を禁止した状態でも、同じ画面を再読み込みしなければ名前入力・編集・JSON出力ができる。
- [ ] `閲覧する` では名前入力が出ず、payloadを変更できない。
- [ ] 閲覧HTMLへ明示的な読み取りフラグが渡り、万一名前画面が表示されても `記名せず閲覧する` で抜けられる。
- [ ] `編集する` の直後、名前入力が毎回空欄で表示される。
- [ ] 空欄、51文字、制御文字を拒否する。
- [ ] 通常ヘッダーに「○○さんが編集中」を表示しない。
- [ ] 一時保存前に名前確認が出て、修正・キャンセルできる。
- [ ] `作業途中の内容を一時保存して、編集を続ける` で一時保存ファイルを作った後、同じHTMLで編集を続けられる。
- [ ] `作業終了用に一時保存して終了` で一時保存ファイルを作った後、編集欄と保存ボタンが無効になる。
- [ ] `もう一度ダウンロードする` でsaveDataId、exportSequence、本文が変わらない。
- [ ] ダウンロード後に編集すると、次の保存だけexportSequenceが増える。
- [ ] 編集後だけタブを閉じる標準警告が出る。

## B-2. 読み取り専用

- [ ] 読み取り専用で開くと、タイトル直下に `このExcelは読み取り専用で開いています。閲覧のみ利用できます。` と表示される。
- [ ] `編集する` と `一時保存ファイルをExcelに正式保存する` がグレー表示になり、クリックしても動作しない。
- [ ] `閲覧する`、`ログチェック（管理者向け）`、`終了する` は読み取り専用でも利用できる。
- [ ] `ログチェック（管理者向け）` を開くと `管理者向け 保存ログチェック` と通常利用者は操作不要である旨が表示される。
- [ ] マクロ一覧から `OpenEditHtml` または `ImportSaveData` を直接実行しても処理を拒否する。
- [ ] 他の利用者の作業中記録やPREPAREDが表示されていても変更せず、読み取り専用の終了確認から正常に閉じられる。
- [ ] 読み取り専用で閲覧しただけの場合、終了時にExcel標準の `変更を保存しますか？` が表示されない。
- [ ] 読み書き可能な状態で開いた場合は、編集・保存ボタンの色と動作が元へ戻る。

## C. JSON再現性

- [ ] ルートpayloadがオブジェクト、配列、文字列、数値、真偽値、nullの各ケースで往復できる。
- [ ] 入れ子、未知項目、空配列、空オブジェクトを保持する。
- [ ] 文字列中の空白・改行・日本語・絵文字を保持する。
- [ ] 数値と数値に見える文字列を区別する。
- [ ] キー順と数値トークンを変えず、文字列外の空白だけを除去する。
- [ ] 20,000文字境界のサロゲートペアを分割しない。
- [ ] chunkCount、jsonLength、CRC32不一致時はHTMLを開かない。
- [ ] 10MiB、10,485,760文字、64階層の各上限を超えるデータを拒否する。

## D. 自動検出と誤操作

- [ ] 新しいJSON名が `DX推進委員会アプリ一時保存_作成日時_作業終了または作業途中_保存者_削除目安日_…json` の順で表示される。
- [ ] 作成日時と削除目安日が日本時間で表示され、削除目安が作成日の1週間後になる。
- [ ] Windowsのダウンロードフォルダ直下から専用JSONを見つける。
- [ ] 以前の `MVP3SAVE_` で始まるJSONは自動検出・ファイル選択の対象にならない。
- [ ] サブフォルダ、`.crdownload`、`.part`、別Excel、別sessionのJSONを選ばない。
- [ ] 自動検出できないとき、ダウンロードフォルダを最初に表示した選択画面が出る。
- [ ] 同じJSONの再ダウンロード・再選択でrevisionを増やさない。
- [ ] 複数の直列保存がある場合、最大exportSequenceを選ぶ。
- [ ] 同じparentSaveDataIdから異なる子がある場合、枝分かれ警告を出してどちらも選ばない。
- [ ] 前回のExcelで作ったJSONを新しいExcel起動後に拒否する。
- [ ] PCへ作成しただけの作業途中の一時保存ファイルを、Excel再起動時に自動回復しない。

## E. 正式保存の確定

- [ ] 一時保存ファイルの取り込み成功時だけ正式保存となり、revision、保存日時、保存者、最新版カードが更新される。
- [ ] accepted原本とダウンロード元のサイズ・CRC32が一致する。
- [ ] workCopy取り込み後、淡い青の状態表示と編集作業の記録が残る。
- [ ] complete取り込み後、編集作業の記録が消えて緑表示になる。
- [ ] 検証失敗、共有サーバー失敗、ブック保存失敗で成功表示にならない。
- [ ] 現在のExcel用だと確認できた不正JSONだけがrejectedへ入る。
- [ ] 無関係なJSONはrejectedへコピーしない。
- [ ] acceptedの同名ファイルが同一なら再開し、内容が違えば上書きせず停止する。
- [ ] PREPARED後に中断し、再起動するとpendingから確定処理を再開する。

## F. 状態と終了

- [ ] 作業中は淡い青背景と通常色の文字で表示され、赤背景・赤字にならない。
- [ ] 正式保存の履歴なしは黄になる。
- [ ] 正式保存済みは経過時間にかかわらず緑を維持する。
- [ ] 前回の正式保存からの経過時間は、状態見出しではなく小さな参考行に表示される。
- [ ] PC時刻を最終保存より前へ戻すと黄になる。
- [ ] 1分更新が二重予約されず、ブック終了後に動かない。
- [ ] タイマー更新だけで不要な保存確認が出ない。
- [ ] 未保存作業の終了確認は既定が「いいえ」である。
- [ ] 保存せず終了しても過去のacceptedと成功履歴は消えない。
- [ ] 保存済み終了時、最新版の日時と保存者を表示する。
- [ ] 保存済みでExcelを終了するとき、最新版が `yyyy/mm/dd hh:mm` 形式で表示され、5桁程度の小数にならない。
- [ ] 旧版で数値化された最終保存時刻が残っていても、終了確認と操作パネルでは通常の日時に補正される。
- [ ] HTMLで `作業終了用に一時保存して終了` を押すと一時保存ファイルのダウンロードが始まり、編集画面とヘッダーが消える。
- [ ] 終了後のHTMLには、Excelへ戻る案内、作成したファイル名、再ダウンロード操作だけが表示される。
- [ ] 終了後のHTMLに `この画面を閉じる` が表示され、押すとページ／タブが閉じる。
- [ ] ブラウザが自動終了を拒否した場合は、タブの×で閉じてExcelへ戻る案内が表示される。
- [ ] 終了後の最小画面では編集を再開できない。
- [ ] `ログチェック（管理者向け）` の画面下部に `閲覧を終了` が表示される。
- [ ] `閲覧を終了` でブラウザが閉じるか、閉じられない場合はExcelへ戻る案内だけの画面になる。
- [ ] `終了する` とウィンドウの×が同じ判定になる。
- [ ] 読み書き可能なExcelでも、`閲覧する` と `ログチェック（管理者向け）` だけを使用して終了した場合はExcel標準の保存確認が追加表示されない。
- [ ] 操作パネル下部に、Excelへの正式保存完了確認後、削除目安を過ぎた本アプリの一時保存ファイルだけを整理する案内が表示される。

## F-2. 閲覧起動時間

- [ ] 同じExcelでMVP2ndとMVP3rdの `閲覧する` を各3回実行し、ボタン操作からHTML内容表示までの秒数を記録する。
- [ ] 2回目以降の閲覧起動がMVP2ndより悪化していないことを確認する。
- [ ] 閲覧起動を軽量化した後も、文字数・CRC32不一致ではHTMLを開かない。
- [ ] 初回だけ遅い場合は、Excel側処理と既定ブラウザの初回起動を分けて記録する。

## G. JUST Calc

- [ ] `Workbook_Open`、`Workbook_Activate`、`Workbook_BeforeClose` が発火する。
- [ ] `Application.OnTime` が使える場合は1分更新、使えない場合は手動契機更新になる。
- [ ] VeryHidden、ブック構造保護、シート保護が維持される。
- [ ] 保護シート上の5ボタンを操作できる。
- [ ] FileDialogまたはGetOpenFilenameのどちらかでJSONを選べる。
- [ ] 共有サーバー上で編集前の書き込み確認が許容時間内に終わる。
- [ ] MVP3rdだけを開いて`終了する`を押すと、ブックとJUST Calcの枠が両方終了する。
- [ ] ほかのブックも開いている状態で`終了する`を押すと、MVP3rdだけが閉じ、ほかのブックとJUST Calcは残る。
- [ ] 終了確認でキャンセルした場合は、ブックとJUST Calcが開いたままになる。
- [ ] `Application.Quit`後も枠やプロセスが残る旧版環境では、JUST Calcの更新モジュール適用後に再確認する。
